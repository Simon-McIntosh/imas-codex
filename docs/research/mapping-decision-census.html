Cypher and reproduction

The queries below ran on the live Neo4j database through GraphClient. The global count establishes that no relationship of the requested type exists, even with another endpoint label. The typed count and row extraction establish the exact cohort whose expressions would be classified. Since that extraction returned an empty list, every facility-slot count and the disagreement count above follows directly as zero. The source-facility query defines the table's facility domain. A new binding requires rerunning the extraction and doing an expression-level slot and COCOS comparison; this empty-cohort result cannot be extrapolated to it. 

MATCH ()-[r:MAPS_TO_IMAS]->()
RETURN count(r) AS bindings;

MATCH (s:SignalSource)-[r:MAPS_TO_IMAS]->(t:IMASNode)
RETURN count(r) AS bindings;

MATCH (s:SignalSource) WHERE s.facility_id IS NOT NULL
WITH DISTINCT s.facility_id AS facility
OPTIONAL MATCH (ss:SignalSource {facility_id: facility})
  -[r:MAPS_TO_IMAS]->(:IMASNode)
RETURN facility, count(r) AS bindings ORDER BY facility;

MATCH (s:SignalSource) WHERE s.facility_id IS NOT NULL
RETURN s.facility_id AS facility, count(s) AS sources ORDER BY facility;

MATCH (s:SignalSource)-[r:MAPPING_CANDIDATE]->(t:IMASNode)
RETURN count(r) AS candidates, count(s.facility_id) AS with_facility,
       count(t.id) AS with_target;

MATCH (m:IMASMapping)-[r:USES_SIGNAL_SOURCE]->(s:SignalSource)
RETURN count(DISTINCT m) AS mappings, count(r) AS links,
       count(s) AS source_endpoints;

MATCH (t:IMASNode)
RETURN count(t) AS targets,
       count(t.cocos_transformation_type) AS labeled_targets;

MATCH (s:SignalSource)-[r:MAPS_TO_IMAS]->(t:IMASNode)
RETURN s.facility_id AS facility, s.id AS source, t.id AS target,
       r.transform_expression AS expression,
       r.source_units AS source_units, r.target_units AS target_units,
       r.cocos_label AS edge_label, r.cocos_source AS cocos_source,
       r.cocos_target AS cocos_target,
       t.cocos_transformation_type AS dd_label, t.units AS dd_units
ORDER BY facility, source, target;

Decisions on selected or escalated candidates

A second live read at 2026-10-08 10:10 UTC classified the edges the decision chain can actually encounter. The cohort is MAPPING_CANDIDATE edges with r.route = true or SignalSource.candidate_route = 'escalated'. It contains 2,958 JT-60SA edges from 151 sources: all 2,958 are escalated and none is selected. JET has no edge in this cohort. A row counts opportunities to settle one slot if its candidate becomes a binding, not observed transforms. The same edge contributes to each slot row.

“Code” is conditional capacity with a known source convention, including source COCOS and the DD COCOS. A recognised DD cocos_transformation_type makes the COCOS sign, its sign component, and its constant factor computable by cocos_sign. An unlabelled target is conservatively open; it might need an identity transform, but this graph does not establish that. The unit slot is code eligible only when the representative FacilitySignal.unit and IMASNode.unit are nonempty and the project's convert_units accepts both 1 and 2 in those raw units. A scalar DD target (ndim = 0) needs no index choice and is code eligible; higher dimensions leave an index-layout judgment. “Judgment” includes absent evidence and does not mean a nonidentity transform is known to be necessary.

Candidate census query

The following Cypher returns every numeric table cell, including JET's zero rows. The literal pair list was obtained from the unit-pair query below by calling convert_units(1.0, from, to) and convert_units(2.0, from, to) without aliases or rewritten spellings; both calls had to succeed. The first query returns the positive-control counts. The query and results are preserved in census_probe.log in the run record. 

MATCH (s:SignalSource)-[r:MAPPING_CANDIDATE]->(t:IMASNode)
WHERE r.route = true OR s.candidate_route = 'escalated'
OPTIONAL MATCH (rep:FacilitySignal {id: s.representative_id})
RETURN s.facility_id AS facility, count(*) AS edges,
       count(DISTINCT s) AS sources,
       sum(CASE WHEN r.route = true THEN 1 ELSE 0 END) AS selected,
       sum(CASE WHEN s.candidate_route = 'escalated' THEN 1 ELSE 0 END) AS escalated,
       sum(CASE WHEN rep IS NOT NULL THEN 1 ELSE 0 END) AS with_rep,
       sum(CASE WHEN rep.unit IS NOT NULL AND trim(rep.unit) <> ''
                THEN 1 ELSE 0 END) AS with_source_unit,
       sum(CASE WHEN t.unit IS NOT NULL AND trim(t.unit) <> ''
                THEN 1 ELSE 0 END) AS with_dd_unit,
       sum(CASE WHEN t.cocos_transformation_type IS NOT NULL
                THEN 1 ELSE 0 END) AS labeled,
       sum(CASE WHEN t.ndim = 0 THEN 1 ELSE 0 END) AS scalar
ORDER BY facility;

MATCH (s:SignalSource)-[r:MAPPING_CANDIDATE]->(t:IMASNode)
WHERE r.route = true OR s.candidate_route = 'escalated'
OPTIONAL MATCH (rep:FacilitySignal {id: s.representative_id})
RETURN s.facility_id AS facility, rep.unit AS source_unit,
       t.unit AS dd_unit, count(*) AS edges
ORDER BY facility, source_unit, dd_unit;

WITH [['%', '1'], ['A', 'A'], ['DEG', '1'], ['DEG', 'rad'],
      ['K', 'K'], ['KA', 'A'], ['KV', 'V'], ['Pa', 'Pa'],
      ['Pa*m3/s', 'Pa.m^3.s^-1'], ['Pam3/s', 'Pa.m^3.s^-1'],
      ['Pam3/s', 'W'], ['V', 'V'], ['au', 'm'], ['count', 'rad'],
      ['day', 's'], ['degree', 'rad'], ['degreeC', 'K'],
      ['g/s', 'kg.s^-1'], ['kA', 'A'], ['kV', 'V'], ['m', 'm'],
      ['m3', 'm^3'], ['minute', 's'], ['mm', 'm'], ['ms', 's'],
      ['msec', 's'], ['oC', 'K'], ['sec', 's'], ['uST', '1']]
  AS exact_pairs
MATCH (fs:SignalSource) WHERE fs.facility_id IS NOT NULL
WITH DISTINCT fs.facility_id AS facility, exact_pairs
UNWIND ['sign', 'constant factor', 'unit conversion',
        'COCOS sign', 'index'] AS slot
OPTIONAL MATCH (s:SignalSource {facility_id: facility})
  -[r:MAPPING_CANDIDATE]->(t:IMASNode)
WHERE r.route = true OR s.candidate_route = 'escalated'
OPTIONAL MATCH (rep:FacilitySignal {id: s.representative_id})
WITH facility, slot, r, t, rep, exact_pairs,
     t.cocos_transformation_type IN
       ['ip_like', 'b0_like', 'tor_angle_like', 'pol_angle_like',
        'q_like', 'psi_like', 'dodpsi_like', 'one_like'] AS labeled,
     [rep.unit, t.unit] IN exact_pairs AS pint_exact
WITH facility, slot, r, pint_exact,
     CASE slot
       WHEN 'sign' THEN labeled
       WHEN 'constant factor' THEN labeled
       WHEN 'unit conversion' THEN pint_exact
       WHEN 'COCOS sign' THEN labeled
       WHEN 'index' THEN t.ndim = 0
     END AS code_settleable
RETURN facility, slot, count(r) AS candidate_edges,
       sum(CASE WHEN r IS NOT NULL AND code_settleable
                THEN 1 ELSE 0 END) AS code,
       sum(CASE WHEN r IS NOT NULL AND code_settleable THEN 0
                WHEN r IS NOT NULL THEN 1 ELSE 0 END) AS judgment,
       sum(CASE WHEN r IS NOT NULL AND slot = 'unit conversion'
                    AND pint_exact THEN 1 ELSE 0 END) AS pint_exact
ORDER BY facility, slot;
