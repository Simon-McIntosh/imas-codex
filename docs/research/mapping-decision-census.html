Cypher and reproduction

The queries below ran on the live Neo4j database through GraphClient. The global count establishes that no relationship of the requested type exists, even with another endpoint label. The typed count and row extraction establish the exact cohort whose expressions would be classified. Since that extraction returned an empty list, every facility-slot count and the disagreement count above follows directly as zero. The source-facility query defines the table's facility domain. A new binding requires rerunning the extraction and doing an expression-level slot and COCOS comparison; this empty-cohort result cannot be extrapolated to it. 

MATCH ()-[r:MAPS_TO_IMAS]->()
RETURN count(r) AS bindings;

MATCH (s:SignalSource)-[r:MAPS_TO_IMAS]->(t:IMASNode)
RETURN count(r) AS bindings;

MATCH (s:SignalSource) WHERE s.facility_id IS NOT NULL
WITH DISTINCT s.facility_id AS facility
OPTIONAL MATCH (ss:SignalSource {facility_id: facility})
  -[r:MAPS_TO_IMAS]->(:IMASNode)
RETURN facility, count(r) AS bindings ORDER BY facility;

MATCH (s:SignalSource) WHERE s.facility_id IS NOT NULL
RETURN s.facility_id AS facility, count(s) AS sources ORDER BY facility;

MATCH (s:SignalSource)-[r:MAPPING_CANDIDATE]->(t:IMASNode)
RETURN count(r) AS candidates, count(s.facility_id) AS with_facility,
       count(t.id) AS with_target;

MATCH (m:IMASMapping)-[r:USES_SIGNAL_SOURCE]->(s:SignalSource)
RETURN count(DISTINCT m) AS mappings, count(r) AS links,
       count(s) AS source_endpoints;

MATCH (t:IMASNode)
RETURN count(t) AS targets,
       count(t.cocos_transformation_type) AS labeled_targets;

MATCH (s:SignalSource)-[r:MAPS_TO_IMAS]->(t:IMASNode)
RETURN s.facility_id AS facility, s.id AS source, t.id AS target,
       r.transform_expression AS expression,
       r.source_units AS source_units, r.target_units AS target_units,
       r.cocos_label AS edge_label, r.cocos_source AS cocos_source,
       r.cocos_target AS cocos_target,
       t.cocos_transformation_type AS dd_label, t.units AS dd_units
ORDER BY facility, source, target;
