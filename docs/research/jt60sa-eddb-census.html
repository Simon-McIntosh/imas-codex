§1 — How it was read

Read interactively over ssh jt-60sa (nakasvr26, host intr26-2) on 2026-10-05 with the EDDB Python wrapper at /analysis/src/eddb/eddb_pwrapper.py and /analysis/lib/libeddb.so, under nice -n 19, using the system python3 (3.5.6; no f-strings). eddbreadShot("E101173") returned exactly one shot, so E101173 is the newest E-shot the catalogue lists; the current pulse at the time was the coil-commissioning shot C082002. Each table below is eddbreadTable(shot, category); the columns are data name, class (T time series, O one-point, P parameter), unit string as stored, and description. Units are free text (KA, DEG, T.m, deg. C) and need a normalisation table before any DD binding.

Call shapes measured the same day: eddbreadTime(shot, cat, dname, "0.0", "0.5") takes string time bounds and returned 2,001 points of MMSYS/curCS1LKAT; with no bounds it returned the full 740,900-point record from −60 s to 125 s. Numeric bounds raise AttributeError: 'float' object has no attribute 'encode'. eddbreadOne is the one-point and PID reader and fails (irc 1015) on a time-series name. eddbreadTable(cat=…) with no shot returns the full catalogue for the category. The UDP id column was empty for every channel read.

The equilibrium magnetics are in PSRC: 34 flux loops magFluxLp1..34 (Wb), 23 poloidal probes magPbTC1..23, 10 calibrated partial fluxes calFP1..10, the surface flux calFX, diamagnetic loop corDmagL1 and the calS1 surface integrals, each with an abnormality flag, plus Ip and calIp in kA. MDAC adds four vessel Rogowski coils curAVVRC1..4, 41 halo Rogowski coils, one-turn voltage, diamagnetic loop voltages and the raw coil-current observations oCS1Cur..oEF6Cur, oTFCur. MMSYS holds the CS, EF, FPPC and TF currents from two measurement chains (HiTec, LKAT) and the coil voltages. FAME holds 100 real-time equilibrium scalars. MAG holds only MHD fluctuation probes.
