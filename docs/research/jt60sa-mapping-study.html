JT-60SA mapping study: agreement across six systems

Six JT-60SA systems were mapped with imas-codex's generated-mapping pipeline and each export was scored by imas-ambix's score-handoff against its hand-built tokamap. This document records, for each system, how many of the generated rows imas-ambix exported, imported, agreed on, could not place, and refused, and traces every disagreement to the pipeline stage it comes from: enrichment, candidates, mapping or hand-off.

The systems are the six iterations of the JT-60SA Mapping Study Expansion plan: §8 coils, §9 magnetics, §10 flux loops, §11 electron cyclotron heating, §12 gas injection and §13 the cryogenic group. Flux loops carry no run of their own — they are mapped inside §9's single magnetics run and scored from its export — and their three disagreed rows are cross-structure rows, resolved below.

Agreement table

The five numbers are exported, imported, agreeing, unplaced and refused. A row is exported when imas-codex writes it to the hand-off document, imported when imas-ambix turns it into a draft mapping rule, agreeing when that rule matches the hand-built map on both target path and index, unplaced when imas-ambix's machine description or member pattern cannot place it, and refused when imas-ambix rejects it outright. An agreeing count of no reference means imas-ambix holds no hand-built map for that IDS, so agreement cannot be scored and only the unplaced and refused columns are meaningful.

Disagreements and their stages

A disagreement is a generated row that imas-ambix reports as conflicting, as landing on the wrong index (a cross-structure row), or as refused for a reason that names a defect in the generated mapping. Each is traced to the stage where its cause lives. Rows that are merely unplaced for a missing reference store are a coverage statement about imas-ambix, not a disagreement about the generated mapping, and are grouped at the end under hand-off.

The four stages are distinguished by what would have to change to remove the disagreement. Enrichment: the signal's description or the facility's own reference does not carry the fact the mapping needs (§9 magPbTC2's lost "tangential probe" text; §10's flux-loop naming, which did not say which store element held the loop). Candidates: the search layer offers a target it should not (§11's deprecated path). Mapping: the source array, target path or index was chosen wrongly (§8's chain, §9's time path). Hand-off: the generated row is sound but imas-ambix's machine description cannot place it (§9 probes 18–23, and every no-store or no-pattern unplaced row).

The flux-loop row is cross-structure

The §10 flux-loop row is scored: 6 exported, 6 imported, 0 agreeing, 0 unplaced, 0 refused. The three rows magFlxLp1, magFlxLp2 and magFlxLp6 are cross-structure: imas-ambix places them on single-loop flux_loop indices 0, 1 and 5, while its hand-built map binds the same raw channels to indices 27, 28 and 32 — the type-6 differential entries of its 53-loop store. MDAC records every loop except 7 as loop N minus reference loop 7, so the two placements are the same physical channel in two store elements. The scale is +1 against −1 at the same magnitude, and the sign is unscored (psi_like, source COCOS undeclared). The channel agrees and only the element differs, so the row carries 0 agreeing and 3 cross-structure rows rather than a value on the agree/disagree axis. The stage is enrichment: the facility fact that would have carried the loop's store element was missing, and is being added to the JT-60SA glossary. The figure draws those three rows in the disagreeing colour and notes them at the bar end as cross-structure.

How to read the result

Three systems imas-ambix can score — coils, magnetics and flux loops — and three it cannot, because it holds no hand-built store for ECH, gas or the cryogenic group. On the scored systems the generated mapping agrees well: 10 of 11 imported pickup-probe rows, 12 of 16 imported coil rows (counting the six "other chain" rows as still naming the right coil), and the three flux-loop rows as cross-structure (same channel, other store element) rather than wrong. The refusals are small and each names a fixable defect — a retired DD path (§11), a value bound onto a time path (§9), the deprecated tf/coil/conductor/current/data (§8's single refusal). The large unplaced counts are imas-ambix coverage: 326 cryo rows and 21 ECH rows have no store to land in. The study's earlier headline expectation — that the cryogenic group would act as a negative control — did not hold: most cryogenic magnet signals do have an IMAS home in operational_instrumentation and calorimetry, so the pipeline mapped about half of them rather than refusing them.
