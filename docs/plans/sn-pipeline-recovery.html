§ Decisions

What happens to the 7,641-line typed-dispatch subsystem under imas_codex/llm/?

Zero production consumers; the dependency arrow points from it into production, never the reverse; wiring it in as-built would disable prompt caching. The review recommends deletion (git retains the history; the LinkML envelope schema can be resurrected if the rescoped context work wants it). Quarantine keeps the code visible at the cost of carrying dead weight through every future refactor and test run.

What cost cap governs the §4 backlog drain?

The prior recovery authorization was $200 with $10.64 spent. The drain covers 255 edit proposals plus a docs-pending tranche; the docs axis was the dominant cost in earlier rotations.
