Workstreams and closure gates

  1. Freeze: executable call-site/template/field inventory, rendered prompt hashes and a human-labelled contamination corpus.
  2. Type: LinkML/Pydantic authority envelope, strict rendering, independent static/dynamic fingerprints and exact token receipts.
  3. Migrate: every active service call site; no legacy dispatcher, permissive undefined field or raw context concatenation remains.
  4. Prove: production-faithful golden rendering, cross-item leakage tests, ninth-plus source coverage, frame/plane preservation and per-seat allowlists.
  5. Release: full service suites and a mechanical inventory comparison show complete coverage before downstream hardening starts.

§ Decisions

How much of the imas-codex LLM surface must migrate before WEST?

The audit found 23 structured-dispatch expressions, 22 active, across Standard Names, DD enrichment, facility discovery, mapping, and benchmark paths. Partial migration would leave the same untyped authority-pollution class reachable elsewhere.

Locked by the lead: every LLM call site must receive a proper review of dynamically injected and templated context before WEST. The migration is project-wide, not a Standard Names-only patch.

What LLM work may proceed while context authority is being rebuilt?

Broad paid generation or review could make graph debt worse before the renderer and authority envelope are corrected.

Locked by the lead. Broad production generation and paid review remain paused until typed context, adversarial goldens, and dispatcher gates pass. Exact gated recovery may proceed only through the hardened path.

Project: imas-codex
Plan: llm-context-integrity

Objective
Migrate every active imas-codex structured LLM call site to a typed, inspectable context envelope and a canonical renderer. This includes Standard Names, DD enrichment/classification, facility discovery, mappings, benchmarks, and any injected-callable adapter. No active call site may be deferred past the WEST review gate.

Required work
1. Rebuild the exact dispatch-expression -> template -> dynamic-field inventory from the current tree and make an executable registry/gate that fails when a reachable call site is missing.
2. Define LinkML/Pydantic authority types for pinned source facts, semantic obligations, non-binding comparators, provenance, owner, carrier, representation, coordinate frame, section plane, locus, axis, unit, family, and reviewer intent. Unknown or conflicting authority must fail before provider dispatch.
3. Build one canonical static-first renderer and one request identity/fingerprint. Remove duplicate templates, silent Jinja Undefined behavior, system/user duplication, stale inline grammar fragments, and lossy key remaps.
4. Migrate all active call sites. Preserve dedicated sn-* model seats for every Standard Names provider call and retain graph-backed claim-before-provider ordering.
5. Add golden and adversarial fixtures covering the known failures: control-surface outline versus normal vector, conductor outline versus circle-arc radius, local arc radius versus tokamak radial coordinate, poloidal cross-section plane, ninth-plus attached paths, mixed benchmark batches, and misleading rich descriptions.
6. Add per-seat allowlists, rendered-context receipts, exact token/cost preflight, and a context-diff inspection surface suitable for RCA without provider calls.
7. Run focused tests, the full relevant service suites, the full Standard Names suite, schema generation, and an independent inventory comparison.

Safety and completion
- Broad production paid generation/review stays paused while this plan is open.
- Local DSv4 may run only offline/advisory against frozen manifests until its benchmark gates pass.
- No graph mutation is authorized by this plan.
- Done only when all active call sites are registered, typed, migrated, adversarially covered, and no context role can silently become naming or attachment authority.
