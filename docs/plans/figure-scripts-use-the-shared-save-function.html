Plan · Figures

Figure scripts save through the shared, checked save function

The plotting package has one save function that refuses to write a figure whose text is clipped or overlapping. Ten older figure scripts still save directly and carry their own copies of that check, or none. This plan moves them onto the one function, after correcting two defects its reviews found.

Where this starts

The save function landed with the signal plotting work in imas_codex/plotting/. Its independent reviews recorded that the exported width is fixed while the height follows the figure, so a figure drawn at another width is exported with a distorted aspect ratio, and that the signal plot's four-entry legend wraps onto a second row. The text check is duplicated: three figure scripts under scripts/ each define their own, and a fourth imports one of those. Ten tracked scripts under scripts/ call the plotting library's save directly, six named for figures and four for JET plots, and between them they rely on export behaviours the shared function does not yet offer: another resolution, a tight bounding box, a raster or animated format, a preview image and a receipt of what was written. The declared slide size and the preview export are written out separately in five of them. Thirteen further scripts under docs/ carry their own text check; they are frozen records of past measurements and are outside this plan.

§1 — The save function exports a figure of any size without distortion

Delivers. A figure saved through the shared function keeps its drawn aspect ratio in the exported file at any canvas width and height, and the file declares a physical size derived from the figure. The default full-width canvas and its declared slide size are unchanged. The signal plot draws its legend on one row for up to six traces. The save function gains no new refusal.

Done when. Tests in the plotting test directory show that for three canvas sizes, one of them the default, the exported width-to-height ratio equals the drawn ratio within one part in a thousand, and that the default canvas still declares its slide size; tests show a four-trace and a six-trace signal plot's legend each occupy one row. Negative control: with the width fixed as it is today, the test for a non-default canvas fails.

§2 — Every figure script saves through the shared function

Delivers. Every script under scripts/ that writes a figure saves through the shared function, and no script defines or imports its own clipped-text and overlap check. The scripts still write every file they write today, in the same formats and with the same drawn aspect ratio, including their previews and receipts. Every vector figure declares the physical size the shared function derives from its canvas; a figure that declared another size, or none, takes the shared one, and the landing record lists each such figure with its declared size before and after. No script keeps a figure-export function of its own, and the slide-size declaration is written in one place. Every figure the scripts produce that is tracked under docs/figures/ is regenerated through it, or the landing record states why a script could not be run and leaves its figure untouched. A figure the check refuses is repaired by moving its labels, never by bypassing the check.

Done when. A search recorded in the landing record finds no direct call to the plotting library's save under scripts/, no function in a script that exports a figure other than by calling the shared one (helpers that save data files are not in scope), one definition of the text check and one of the slide-size declaration across scripts/ and imas_codex/, with the number of public definitions and options the plotting package gained stated; the list of files each script wrote before and after is the same, each figure file's exported width-to-height ratio equals its drawn canvas ratio within one part in a thousand, and the landing record lists every vector figure's declared size and ratio before and after; a file that was exported with a content crop until now is listed with its pixel size before and after, and is exempt from comparison with its earlier ratio, since that ratio followed live content; the landing record lists each script with one of regenerated, refused and repaired, or not run with its reason; each regenerated figure was rendered and looked at, and the count of figures that changed is given; the net change in lines under scripts/ is stated. Any script that reads live data runs on a compute partition (all_debug). Negative control: a script given a label beyond the canvas writes no file.
