§1 — What the release candidate shows, and where each defect comes from

The catalog release candidate v0.4.0rc8 publishes 1,975 names. Each reads well alone and scores well alone. Read side by side, names that state the same concept state it differently, and some names do not say what their definition says. The measurements below were taken on 2026-11-12 over the published files; the scripts and their output are in docs/evidence/fragments/sn-definitions-by-construction/.

Each pattern has a cause in how names are produced.

  • Every definition is written whole, one name at a time, by a language model. A flux-surface average of argon density and one of krypton density share everything but the species, yet each is a separate piece of writing. The grammar library already stores one canonical phrase and equation for 46 concepts, the flux-surface average among them. It reaches the writer as guidance in the prompt, and the rule for an operator is to name the concept and, if an equation is given, to restate the canonical one with the quantity's own symbols. Restating is where the eight forms come from. The check that follows forbids one specific variant in a display equation and passes the rest.
  • A sibling is shown as an example, not used as the text. A family's anchor member is put in the prompt and the writer is asked to match it. Nothing requires the shared sentences to be the same sentences, and no stored fact says which population a species name counts, so the writer decides again for each member.
  • Names already published are not rewritten when the wording is settled. Bringing a family to one wording is a separate, opt-in pass that regenerates each member through the model and its review. sn-catalog-consistency §2 sizes that pass at 279 batches, and each regenerated member is again free to differ.
  • The unit is carried from the Data Dictionary as spelled. There is no rule giving a quantity one spelling, and the unit check covers five special cases.
  • No check compares a name with its own definition. The review checks test the name against the grammar and the description against the source. None asks whether the definition adds a restriction or a normalisation the name does not carry, or whether the unit's dimension fits the quantity the name states.

§2 — The shared parts of a definition are rendered from one stored wording

A definition has parts that belong to a concept shared with other names, and parts that belong to this name alone. The shared parts are the operator applied (a flux-surface average, a volume average, a line average, a derivative), the population counted (which charge states, whether neutral atoms are included) and the locus (the plasma boundary, the pedestal top). Each shared part has one stored wording, with its equation where it has one, and appears in every name that uses it as that wording, with only the quantity's own symbol and words substituted. The model writes what is specific to the name. The stored wording for a concept the grammar library already defines is that library's; a wording this repository adds is recorded where a reviewer can read and change it, and is proposed upstream. A definition whose shared part departs from the stored wording is reported as a further class of the documentation conformance findings the writer already acts on; no new refusal family is added beside them.

The population a species name counts is settled once for the catalog and recorded as a decision on this plan before the node is dispatched: the coordinator brings the lead the Data Dictionary's own definition of the species densities and the split §1 describes and §4 counts.

Done when:

  • for each of the operators flux_surface_averaged, volume_averaged, line_averaged, line_integrated and time_derivative, two names that apply it to different quantities, written by the pipeline on a disposable graph, carry the same operator sentence and the same equation form, differing only in the substituted symbol and quantity words;
  • for a species family of at least five members written by the pipeline on a disposable graph, the description is one wording after the species is substituted, and the population statement is identical across members;
  • the wording census committed in docs/evidence/fragments/sn-definitions-by-construction/, run over those written names, counts one form per operator and one wording per family, and counts more than one on a family planted with a divergent member;
  • a definition whose shared part the model altered or contradicted is never stored as the model wrote it: what is stored carries the settled wording, or nothing is stored. This is shown by a test that feeds such a model answer through the writer's own entry point and reads back what was stored, so it holds on the path the pipeline takes and not only when a check is called directly;
  • at least ten names written this way are put through the pipeline's documentation review beside a control: the published definition of the same name, held in a second seeded copy so that writing does not replace it, and reviewed in the same run with the same context and by the same route; a name the review returns no judgment on in one arm or in both is left out of the comparison, the number left out is recorded for each arm, at least ten names are decided in both arms, and over those the documentation review accepts the written definitions at least as often as the control, and the conformance check this section adds does not stand in for that review, and every written name the review sends back is listed with the review's reason, any reason that names a rendered shared sentence being repaired or listed as a defect of this change;
  • the cost of writing one family member is recorded beside the present per-name documentation cost;
  • the gate runs on a compute partition and its log is committed under the evidence directory.

§3 — One unit spelling per quantity

Names that state the same quantity carry the same unit string, and a name's unit has the dimension its quantity has. Where two spellings are dimensionally equal the catalog uses one, and the choice is recorded per quantity. A difference that carries meaning stays and is listed with its reason: a plasma temperature in eV beside a material temperature in K, an angular frequency in rad.s^-1 beside a cycle frequency in Hz.

Done when:

  • a committed unit census over every live name lists zero quantities carried in two dimensionally equal spellings, or lists each with the reason it stands, beside the count before the change; the torque, torque-density and source-rate cases in §1 are named in it as resolved;
  • the census lists every name whose unit dimension does not fit its stated quantity, and each is either corrected through the signed edit path or passed to §5 as a name that does not say what it is;
  • a name written by the pipeline for a quantity that already has a recorded spelling takes that spelling whatever the Data Dictionary spells, shown on a disposable graph;
  • the census counts a quantity planted with two equal spellings and a name planted with a mismatched dimension, and is silent on a planted clean pair;
  • no unit is changed to a dimensionally different one without a recorded reason naming the Data Dictionary path it disagrees with.

§5 — A check that the name and its definition say the same thing

A definition that adds a normalisation, a counting convention, an integration or a restriction to one device says something the name does not. Either the name gains the qualifier or the definition loses it. The check that finds these runs wherever a name is reviewed, and its verdicts are measured against §4's labels before it is trusted. It joins the named review checks a name already passes through, and its refusal is theirs; it adds no separate gate or command.

Done when:

  • measured on §4's labelled names, with the labels held out from anything the check was tuned on, the check finds at least 80 % of the names labelled as mismatched and flags at most 10 % of the names labelled as agreeing, both figures recorded with their counts;
  • the check's labels were not produced by the check or by the model that runs it, stated in the evidence with who or what produced them;
  • run over every published name, the check's findings are listed by class, and each flagged name is given one disposition: rename, rewrite the definition, hold from the cut, or a recorded reason it stands;
  • an abstract parent is either published with a definition that states one quantity or is not published, and the count of each is recorded;
  • a name that the check flags is not accepted by review without a recorded reason, shown by a test that plants a normalised quantity under an unnormalised name.

§6 — The live catalog rewritten to the settled wording

Every live name is brought to §2's wording, §3's unit spelling and §5's dispositions, through the pipeline's own write paths and never by editing stored text directly. A graph checkpoint is taken before the first write with every graph-touching worker at rest. The full-DD continuation run is paused for the duration, or the names it creates meanwhile are written under §2 and counted in the final census.

Spend is drawn from the USD 250 the lead authorised for this repair on 2026-11-12. This section may use at most USD 150 of it. The first family rewritten measures the real cost per name, and the section stops and reports if that rate projects the whole pass past the ceiling.

Done when:

  • the population statement is the one the lead ruled in §2 on every species name, with any exception listed by name;
  • the unit census of §3 and the name-definition check of §5 are re-run after the last write and their counts recorded beside their earlier readings;
  • no name's documentation review score falls below the publishing threshold as a result of the rewrite, or each that does is listed and held;

  • the census counts a family planted divergent in a disposable graph after the pass as it did before.

§ Decisions

Which population does a bare species density such as neon_density count?

Lead ruling 2026-11-12: a bare species density counts ions, summed over all charge states, with neutral atoms excluded. This matches the Data Dictionary container the sources sit under (n_i) and the core-profiles ion density, documented as summed over all charge states. A name that includes neutral atoms says so in the name.
