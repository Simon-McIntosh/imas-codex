§1 — Why these two survived everything else

The graph-wide integrity programme drove seven of nine declared classes to a measured zero. These two rows survived not because they were hard to find or expensive to repair, but because every available repair would have been a guess about physics, and the fail-closed guards correctly refused to make it. Both are recorded refusals re-verified live on 2026-08-25 rather than carried forward from an earlier census.

Recording that plainly matters for the regeneration strategy: a delete-and-regenerate does not clear these. It re-derives the same candidates from the same sources and poses the identical questions.

§2 — The dual-bound momentum flux

dd:plasma_transport/model/ggd/neutral/state/momentum/flux/radial feeds two live targets: radial_neutral_internal_state_momentum_flux and radial_neutral_state_momentum_flux. The single-valued PRODUCED_NAME invariant is locked, so one must go — and the losing candidate still has exactly one producing source, this one, so releasing it strips its last producer and the guard refuses.

The guard is defending something, and the history says so. A comparable adjudication on this plan chose mass_density over total_plasma_mass_density by testing DD prose for a “total” qualifier, which cannot settle a naming question; the reasoning was overturned, and the scalar repair later moved that mirror to total_plasma_mass_density. A last-producer refusal is evidence about the adjudication, not merely an obstacle to it.

So the work is to decide which identity the source genuinely realizes — whether internal_state carries meaning the shorter spelling drops, or is a redundant peel — and then either supply an authoritative producer for the survivor or adjudicate the loser's disposition explicitly. Not to route around the refusal.

§3 — The reflector centre

dd:spectrometer_x_ray_crystal/channel/reflector/centre/phi still solely targets toroidal_angle_of_measurement_position. The distinction it needs does not exist as an identity: DD 4.1.1 makes centre the local-frame origin while sphere_centre is the centre of curvature, and the only toroidal reflector identity in the graph, toroidal_coordinate_of_reflector, is produced by that distinct sphere_centre source.

Binding both to one identity would conflate a local frame origin with a centre of curvature — the same class of error as the geometry-cardinality confusions this programme has already adjudicated once. The repair is a reviewed identity split through the sanctioned sn edit path, so the new identity earns its acceptance from a fresh quorum score like any other.

This row also carries a related known gap worth resolving in the same pass: radial_coordinate_of_reflector has no description and no embedding at all, which is why it withholds from release rather than failing any semantic check.

§4 — Through the pipeline, never around it

Both rows are fixed by proposing a change and letting review score it, never by a Cypher SET and never by a direct accept. sn edit with a mandatory reason is the only sanctioned path: the reason reaches the reviewer as intent context so a deliberate change is not penalised for differing from a prior variant, and review still scores independently and can reject it.

Acceptance is earned only through a fresh RD-quorum score. If a proposed identity does not clear the bar, that is a result to record rather than a threshold to lower.
