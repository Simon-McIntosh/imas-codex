This section changes names, definitions and documentation only and makes no physics_domain change; agreement of domains across a family is sn-domain-per-family §3's. Only the rename for the two-tip momentum-diffusivity lineage is §4's.

Spend draws on the USD 350 full-DD approval of 2026-11-07, which this pass shares with sn-full-dd-continuation; that plan's run limit is computed after every draw on the approval, this pass's included. The sized estimates use the documentation rate, while sn edit also pays for review, so the first batch this section runs measures the real per-name cost and every later batch runs under a ceiling of that measured rate times its name count, plus a quarter.

The census this section measures with lives today as a script in an evidence directory, with no way to scope it to a population. A census entry point with a population argument may be added for this pass; if it is, it replaces that script rather than standing beside it.
