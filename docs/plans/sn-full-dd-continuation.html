§5 — The documentation backlog the stalled drain left

The documentation drain under sn-integrity-backlog §52 stopped on 2026-11-11 with stop_reason: stalled, after USD 11.14 of its USD 20, and drained nothing on balance. Its record is docs/evidence/fragments/sn-integrity-backlog/sib-docs-drain-after-admission.html, which lands with that run. Read live before and after, accepted names rose from 2,866 to 3,004, while those with accepted documentation fell from 2,368 to 2,028 and those with pending documentation rose from 413 to 926. The run in §4 is scoped by source, so it does not reach this name-level backlog. The cause of the stall and of the fall is under investigation in §52, so this section starts once no §52 run is writing the graph. What lowered accepted documentation is §6's to establish, and this section follows it.

It starts after §4 has taken its post-run reading, so no documentation write overlaps that reading, and its backlog then includes the names §4 created. Spend draws on what remains of the USD 350 approval after §4. Its ceiling is the drain's own rate, the spend per name that newly reached accepted documentation in the drain (USD 11.14 over 21 names, about USD 0.53), times the backlog read at its start, plus a quarter. At that rate a backlog of about a thousand names costs several hundred dollars, more than the approval's remaining balance, so §5 is expected to need the lead's spend ruling, recorded on this section, before it runs.

Done when: among accepted names, the count with accepted documentation is at least the 2,368 read before the drain, and every accepted name whose documentation is not accepted is listed with its stage and the recorded reason it stands; the before and after counts by documentation stage are recorded under docs/evidence/fragments/sn-full-dd-continuation/ with the spend beside the ceiling and the approval's remaining balance; the read-back reports a name planted with pending documentation in a disposable graph as pending, not accepted; §6's guard against unrecorded demotion is in place; the export gate's blocking set stays 0.

§6 — What demoted accepted documentation during the drain

During the 2026-11-11 documentation drain, accepted names with accepted documentation fell from 2,368 to 2,028, while the drain itself brought only 21 names newly to accepted documentation. Something other than the drain's own writes lowered accepted documentation, and §5's restoration would leak while it runs. sn-integrity-backlog §52 is investigating the stall; this section names the mechanism, citing §52's finding where §52 has recorded one and deriving it otherwise. It makes no LLM call.

Done when: the mechanism that lowered accepted documentation during the drain is named under docs/evidence/fragments/sn-full-dd-continuation/ with the writer and the evidence that ties it to the fall; a guard makes that writer record a reason whenever it demotes accepted documentation, or refuses the demotion, by a test that fails when the guard is removed; a read before and after one scoped sn run shows no accepted documentation demoted without a recorded reason; spend is USD 0 beyond that run's own.
