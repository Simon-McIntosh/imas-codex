A reference set says what a right answer is

The blind adjudication of equilibrium judged 208 names from their full source packets: 82 sound, 93 defective, 33 it could not decide. The agent repair that followed got 17 names accepted and listed 109 with the reason each could not be repaired. Both were judged before the lead ruled, on 2026-11-18, that a name identifies and its definition specifies: a name carries what separates the quantity from its neighbours, and normalisations, weightings, conventions and methods belong to the definition. A benchmark needs an answer key read under that rule, and nothing in the catalog is one yet.

Done when: a reference set is committed holding, for each member, its source packet, the right name or the set of names that would be right, the points its definition must state, its unit and its group, and the verdict's reason quoting the source; it is built from the 82 members judged sound, the 17 accepted repairs and the 84 names hand-checked for the reader calibration (44 judged defective, 40 sound), every one re-read under the identity rule by an adjudicator that sees the earlier verdict only after committing its own, with the members whose verdict changes listed beside the rule that changed it; the 52 equilibrium members earlier classed as omitting what their source states are each re-classed as a naming defect, a definition defect or sound, with counts; members that cannot be decided are kept out of the set and counted; at least 100 members are in the set, and at least 20 of them are defective under the rule so a generator that copies the incumbent scores below one that repairs it; a check fails when a reference member's packet digest no longer matches the stored one. No stored text or graph property changes. The evidence is committed under docs/evidence/fragments/sn-case-file-generation/.

Every name has a case file built by code

The cause behind most of equilibrium's shared defects is that the stage composing a name was never shown the text of the structures enclosing its source. The agent repair worked where a worker could read everything, and stalled where it could not see a name's neighbours or the vocabulary it was allowed. What a generator is given decides what it can get right, so the case file is a product of its own, built by code and never by a model, the same for every model that reads it.

Done when: for any live name or unnamed source a case file is produced that holds the text of every source bound to it and of each enclosing structure up to the root, the units and coordinates the sources declare, the other names of its family with their definitions, its nearest neighbours in the catalog by subject and by locus with what separates each from it, the grammar's segments and the vocabulary and registry entries a name for this quantity may use, the conventions the catalog has ruled, the incumbent name, definition and documentation where one exists, and any adjudicator's reason recorded for it; a case file is one record that carries its content, its digest and its own completeness verdict together, and it is the single thing the reference set, the benchmark and generation read, none of them collecting the same text again; one is produced for every equilibrium member and for each of the 84 names the reader calibration hand-checked, which are the populations the reference set is drawn from, and the evidence reports its size in tokens as a distribution; a recorded run shows a member whose enclosing-structure text is withheld carrying an incomplete verdict that refuses its use, and a member with no family or no neighbour stating that plainly instead of an empty block; building the files for all equilibrium members makes no model call and changes nothing stored; the whole tests/standard_names directory adds no failure at head against base, run as a job on a compute partition.

A benchmark chooses the structure and the model

Two questions are open and are measured, not assumed. Whether a name's whole record, definition first and the name derived from it, with its documentation, unit and group, is better written in one pass by one author than in stages. And which model can do it from a large case file: the local model, the Kimi model on the new B300 server when it is running, the subscription worker lane, or a frontier model as the ceiling. Lead ruling, 2026-11-18: benchmark first, and iterate on the case file and the prompt until the pipeline is tuned and its failures understood.

Done when: each arm, a structure crossed with a model, generates a record for every member of the reference set from its case file, and a blind adjudicator that knows neither the arm nor the incumbent scores each record against the reference as right, wrong or blocked; the evidence reports per arm the share right with a 95 % interval, the share blocked by type, the share where the arm changed an incumbent that was right, cost and time per name, and the tokens read; at least two rounds are run in which the case file or the prompt is changed in answer to the previous round's failures, each change stated with the failures it answered and the result, on a development half of the set, the final figures being taken once on the held-out half; an arm that cannot be run, the Kimi model before its server is up among them, is reported as not run with the command that will run it, and adding it later rescores nothing else; the arms' rights and wrongs are compared member by member so a difference smaller than the interval is not called a win; two control arms run beside them and must separate, an arm that returns the incumbent unchanged, which the defective members of the reference make score below a repairing arm, and the best arm run again with the enclosing-structure text withheld from its case files, which must score lower on the members whose right answer rests on that text, and a benchmark in which neither control separates is reported as measuring nothing; the result is put to the lead as a choice of structure and model, with the measured figures beside each option, and the ruling is recorded here; spend is stated beside a ceiling of USD 25. No stored text or graph property changes.

A name is generated or its blocker is queued

The agent repair listed 109 of 126 names because what stopped each one had nowhere to go: 33 needed a term the grammar lacks, 33 had source text that does not decide the answer, and the rest met a registry definition, a protected spelling or a collision. Each stopped one name at a time and waited for a person. Lead ruling, 2026-11-18: every name is regenerated with its incumbent as a candidate, kept where it is right and succeeded where it is wrong, and names judged sound are frozen as the reference.

The grammar gains what the whole dictionary needs, once

Equilibrium's repair met 33 grammar gaps. Read under the identity rule they reduce to a short list. In the name: locus terms for the effective plasma boundary (ruled 2026-11-18: plasma_boundary stays the last closed flux surface, a boundary the source selects that is not the true boundary is the effective plasma boundary, and separatrix is not used for the true boundary), the pressure pedestal top, the main x-point, the geometric axis of a flux surface and the signed minimum of the safety factor; flux expansion as a quantity; and a way to say a shape parameter is measured relative to a stated locus. In the definition, through named conventions the definition cites: the reference-field normalisation of parallel current density, the reciprocal-major-radius weighting of the toroidal current-density average, the li(3) normalisation of internal inductance, the toroidal-flux-coordinate form of magnetic shear, and averaged measurement positions. Equilibrium is one group of 29, so the list is not complete. Lead ruling, 2026-11-18: equilibrium proves the pipeline while about 200 names sampled across the other groups are run to report blockers only, and the grammar changes once.
