§1 — Why this is its own plan

The WEST catalog cannot cite a grammar that exists only as a fork commit. Every standard name in that batch is composed against the ISN vocabulary, and the published catalog records which version of that vocabulary judged it. Today imas-codex pins ISN by git SHA at two sites in pyproject.toml, the catalog tracks the fork's main, and upstream ISN carries sixty-seven release-candidate tags with no stable version. A catalog published on that footing is not reproducible by anyone outside this machine.

This is a different subject from preparing a review batch, in a different repository, with its own lifecycle and its own audience: the release is a public Python package that other projects install. It blocks sn-west-review-rehearsal but outlives it, which is why it is tracked here rather than as a section there.

§3 — Releasing, and what the tag actually does

Tagging is not a local act. Upstream's release.yml fires on tags matching a semantic version, including release candidates, and runs a publish-pypi job using trusted publishing into https://pypi.org/project/imas-standard-names/. Tagging therefore publishes a public package release under the ITER organisation, and a version number once published can be yanked but never reused. The lead authorised this explicitly on 2026-09-01, including the PyPI publication.

Because the pull request lands on upstream rather than on the fork, the correct tag is the stable v0.8.0 and not a release candidate. The sixty-seven rc tags were fork-side prototyping and stay there. After the release publishes, three pins move from fork SHAs to that version: two dependency declarations in the imas-codex pyproject.toml with the lockfile regenerated, and the catalog repository's own dependency, which currently tracks the fork's main branch.

The pin bump is not cosmetic. imas-codex currently resolves ISN at 93195dd, which predates the minimum_absolute_safety_factor locus rename, so the exporter still judges identities against the pre-rename vocabulary and reports a collision that the vocabulary no longer has.
