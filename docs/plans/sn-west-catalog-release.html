A worker ran imas-codex sn release --batch west_production_dd_paths --dry-run in its own worktree at 07:52:54Z. Each dry run consumes a version number that names no release, which is very likely how rc2, rc3 and rc4 came to sit in the reviews directory at all.

The repair is to make the dry run inert: compute what it would mint, report the RC it would take and the roster it would write, and write neither. A dry run that mutates the tree is not a dry run, and the RC counter must only advance for a release that happens.
