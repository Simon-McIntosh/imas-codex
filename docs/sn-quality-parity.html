Every change proves itself against the holdout; nothing regenerates sound content wholesale. §5 — Turn the surviving presence checks into physics checks

The gate-role decision deleted the four gates that tested for a word. Six survive, and two of them are still only presence checks that a well-formed but wrong document would pass. Both can be grounded in data the graph already holds authoritatively, which is the property that separates a real check from a pattern match — the template is the logarithmic-unit rule landed in the release-readiness plan: a contradiction between two authoritative facts, deterministic, no judge, and unable to regress.

  • Dimensional consistency of the defining equation against the DD unit. defining_equation currently passes on the presence of =, \int or \propto. The DD-declared unit is authoritative and reaches the item already; the equation's dimensions are computable. A document whose stated relation cannot produce its own declared unit carries a real physics error that no amount of well-formed prose hides. Deliverable: the gate fails such a document, with a test built from a genuine unit/relation mismatch.
  • sign_convention made conditional on the COCOS transformation type. The gate checks canonical sentence form but cannot tell whether a sign convention was required, which is why absence had to be treated as permissible. Corrected 2026-08-23 by the prior-art scout: HAS_COCOS does not supply the transformation type. That edge returns the convention node and its parameters; the transformation class lives on IMASNode.cocos_transformation_type and is copied to StandardName.cocos_transformation_type (sources/dd.py:359-385, workers.py:8499-8517, schemas/standard_name.yaml:1098-1115). The earlier wording conflated the edge whose name was fixed in §2 with the property that answers this question, and an implementer trusting it would have wired the gate to an edge that cannot answer it. Deliverable unchanged: required when the quantity is COCOS-dependent, forbidden when it is not, with tests for both directions — read from the property, not the edge. Lead ruling, 2026-08-23, and it makes "COCOS-dependent" measurable: the Standard Names COCOS is uniformly 17, following DDv4, so the convention number is a property of the dictionary version rather than of any individual name and there is nothing per-name for a document to state. The transformation class (psi_like, ip_like, …) is graph metadata only — it must never surface in a catalog entry. The HAS_COCOS edge itself is endorsed: explicit beats implicit, and the scout's correction is about which of the two answers "what transform applies", not a criticism of the edge. Measured against the live graph the ruling resolves the gate condition exactly: of 981 names carrying a transformation type, 957 are one_like — COCOS-invariant, so a sign convention is forbidden — and only 24 are sensitive (dodpsi_like 6, ip_like 5, psi_like 5, b0_like 5, pol_angle_like 2, q_like 1), which is the same 24 the holdout pinned. The gate therefore keys on not-null and not one_like, never on the mere presence of an edge, and it additionally pins the metadata boundary as an invariant: no accepted documentation may name a COCOS number or a transform label. That currently holds at 0 of 2,748 accepted documents, so the check preserves a property rather than repairing a breach.
  • A third gate state is a prerequisite for both, not an extra. The scout's sharpest finding: a boolean vector cannot distinguish missing authority from contradiction. A gate returning False for "no declared unit to check against" and False for "the stated relation contradicts its declared unit" has merged an absence with a defect, and every mean computed over it becomes uninterpretable — the same class of error as the lexical gates the gate-role decision deleted, and it would be built in from the start. So not_evaluable lands with structured physics context threaded through DocumentationGateScore, score_documentation, holdout row scoring and aggregation. Blast radius measured: 14 call sites, 2 runtime/evaluator and 12 tests.
  • The comparator is a composition, not new machinery. No LaTeX-relation-versus-declared-unit capability exists today, but nine pieces of one do, and the scout named the order: resolve_dd_unit → normalize_unit_symbol/unit_registry → ResolvedDDContext.unit → canonical_or_none → _unit_dimensionality/_unit_dimensions → _dimension_container algebra → _dimensions_overlap. Only the relation parser and the authoritative symbol-to-unit binding are genuinely new. Full map with 28 cited candidates (11 fit, 14 partial, 3 fail): ~/.local/share/imas-codex/receipts/standard-names/snqp-physics-gates-reuse-map.md.

Why these two and not a rewrite of the deleted four: scope, physical_meaning and exclusions have no authoritative counterpart in the graph to check against, so any version of them remains a judgement about prose. These two do. That is the whole distinction, and it is the criterion for admitting any future gate.

Sequencing: independent of each other and of the cohort refresh, so either order, and neither blocks §3. Both are additive to a gate set that is already green at 6,653 passing tests.

Should generated documentation carry a hard maximum length?

Production documentation with real injected context exceeds the 250-word hard bound on 22.4% of holdout rows (19/85) and 15.1% off-holdout (8/53) — consistent across populations, so it is a property of richly-contexted generation rather than one sample. The curated catalog this plan is trying to match exceeds the same bound on 76.5% of its own rows. A binding cap reallocates content rather than truncating it: an earlier iteration measurably traded symbol definitions away to fit newly required content.

Locked by the lead 2026-08-23: a hard word cap is an anti-pattern; remove it. This extends an already-established principle rather than introducing a preference — the naming rule holds that a name is as short as possible while fully retaining semantic meaning with no arbitrary character cap, and records the former length soft cap as an anti-pattern already removed. The evidence supports it: the cap only stopped binding when documents had no content to state (100% conformance on the context-starved arm, 77.6% once real context arrived), and the reference standard sits mostly above it. Retained deliberately: the minimum word floor, so a document must still say something, and the separate one-sentence description character limit, which governs a different field.
