The documentation axis: what failed, and what the accept-rate check should have been compared against

The documentation arm of the inverse switch dry run left 76 of its 219 eligible items undecided, and that is what fails the check. 72 of those items carry no route row at all, and 4 carry a shadow row whose failure reason is the deciding call's own text. Neither cause is a defect in the item and neither is the cascade choosing to abstain: the first is the run's budget cutting the batch short before those items were reached, and the second is a deciding call failing once with no retry. The accept-rate shortfall against the calibration-matched target is a separate question, and the accept-rate check is comparing against the wrong baseline for it.

A cohort drawn to a different mix can produce the whole shortfall against it.; against the dry run's rate over eligible items — An undecided item counts against that rate, so the documentation figure is dominated by the items the run never reached. It measures the run's budget alongside the route.

What each finding implies for the switch

  1. The undecided count is a run fault before it is a routing fact. On this cohort 72 of 76 undecided items were never offered to Jev at all and 4 failed once and were not retried, because an empty fault message is classified non-retryable. Turning the switch on with the deciding path as it stands makes an item whose call fails take no route silently; give the fault an honest message and a retry, and give the run a budget that reaches every item, before the switch is flipped.
  2. Do not read the accept-rate check as a statement about Jev's operating point. Over the items both routes judged the two accept rates differ by +0.2195, with an interval spanning [+0.1220, +0.3171] — a different question from the one the check asks against a target measured on the panel's own pool. Recompute the target on the cohort, or gate on the paired difference instead.
  3. The refine-versus-accept set is not yet evidence either way. 15 of the 49 sit on the cutoff, and the remaining 34 cannot be classified without the incumbent's reason line, which that arm did not persist. Until it does, the set cannot distinguish a real defect caught from a mechanical hold, and the switch should not be classified on it.
