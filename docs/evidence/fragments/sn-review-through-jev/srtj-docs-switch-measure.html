Method

Each row was rebuilt the way the cascade expects it: documentation, name and unit from the sheet the labeller saw, the remainder (description, links, DD source text, related neighbours) from the archived export record.archive, loaded into a disposable scratch Neo4j. The sheet's documentation matched the archive for all 77 rows (0 mismatches), so the measurement runs on the text that distinguishes the switch. Each item then went through the product path: review.cascade._docs_judgment (state build, docs question table, _route) for the Jev route and any route hold, plus the error-severity lint findings (run_house_style_checks + run_documentation_gate_checks) that the lint cap in review/pipeline.py turns into a docs_lint_error hold. A row is accepted only when the route accepts and no hold is open. The Jev calls ran twice (model typesafe/jev-1.13).

Positive control: the deterministic instrument fires on an injected bare snake_case bracket (link_hygiene: bare bracket names a standard name but carries no link), so the absences below are not an unrun instrument.
