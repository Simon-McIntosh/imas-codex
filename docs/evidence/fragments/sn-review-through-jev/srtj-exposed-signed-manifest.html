The replay failure is a receipt-cohort check against rows that do not exist yet. _load_error_sibling_authority builds its authority with rows=(); the error-sibling rows are attached later, in _build_preview, which runs after _replay has already compared cohort_admitted_ids against a receipt map built from _runtime_authority_rows. At base that map is empty, so every admitted row fails the name comparison and replay reports the cohort as incomplete. The check itself is sound — it is what makes the replay receipt authoritative — so the fix resolves the rows before the check instead of weakening it: _replay populates runtime_rows for the error-sibling adapter from the admitted ids, and _error_sibling_rows selects by those ids without the parent-orphan recheck that made a post-quarantine row invisible. The quarantine is exactly what removes a row from that predicate, so re-applying it during replay asks the graph to confirm the state replay is about to measure.

The six stub failures are the deletion guard refusing its own signed cohort. _delete_derived_parent_nodes deletes a derived parent only when sn.needs_composition = true, a guard that exists so a structural delete cannot take an unflagged node. The lifecycle-less stubs these tests seed carry no such flag — legacy placeholders never did, which seed_parent_sources states explicitly — so every signed deletion deletes zero rows and _apply_lifecycleless_stub_reconcile raises. The tests are correct as written: a manifest that signed a stub for deletion should be able to delete it. The fix stamps the flag on exactly the signed cohort inside the reconcile transaction and refuses when the stamped count differs from the cohort the manifest named, so the guard keeps its meaning: an unflagged node is still never deleted, and the only nodes newly deletable are the ones the receipt accounted for.

Neither test file was modified. Both failures were resolved in signed_manifest.py at the function that owns the behaviour, and every assertion the tests make — the write-free replay measurement, the rollback counts and the preview-hash invalidation — is still asserted.
