The checks

All live in tests/standard_names/test_facade_closure.py, plus the replaced guard in tests/standard_names/test_graph_ops.py:

  • test_service_bridge_resolves_only_wired_names — the declared roster equals the attribute set scanned from the store's own AST (both get_services().x chains and the injected services parameter and its aliases), and a moved name outside it raises naming its owner.
  • test_entrypoint_refuses_moved_symbols — no callable the owner map places in a store module resolves on graph_ops or workers, with a positive control on the witness set (it must not be empty).
  • test_owner_map_entries_resolve_at_their_owner — a stale entry, or one that resolves somewhere other than the named module, fails.
  • test_owner_map_covers_every_public_definition — the store's module set is enumerated from graph_store/*.py rather than from the map, so a module the map omits fails outright; and every public name a store module defines (AST, excluding logger and the graph_foundation wiring module, which siblings import directly) is in the map.
  • test_facades_define_no_delegating_forwarder — a function whose body only returns a call that lands on a moved store symbol or a worker_tasks symbol is a forwarder however it is described, including through an import alias in either spelling.
  • test_forwarder_scan_catches_absolute_import_delegation — the detector itself is exercised on planted source: an absolute import (from imas_codex.standard_names.graph_store.graph_catalog import … as _impl) and a relative one must both be caught. The absolute spelling is the repository's common one, and a scan that knew only the relative form accepted it silently.

The aliased-import control is why the forwarder check reads imports as well as callee. A first version keyed only on the callee name, and a delegation written as from .graph_store.graph_catalog import write_standard_names as _impl; return _impl(...) passed it — the shape a reintroduced façade actually takes. That first alias reader understood only relative imports, which left the repository's dominant spelling — the same delegation written from imas_codex.standard_names.graph_store.graph_catalog import write_standard_names as _impl — passing it again. Both the mapping and the guard are now exercised in both spellings, the absolute one by a test on planted source and by a control run against the live entrypoint.

What the first gate run caught

The first head arm added eleven ids, all in the structural-authority path. The store reads services.__file__ to fingerprint the module it lives in, and the declared roster had been built with the scan filtered of dunder names, so the bridge refused __file__. The roster and its scanner now carry the name; the eleven pass, which is why the declaration is checked against the store's reads rather than written once.
