Blind labels for the refine comparison's sheet

One label and one reason for each of the 124 rows of the blind refine sheet (srtj-refine-ab-label-sheet.json), written by a fresh worker that never saw which arm produced a row or whether a row's source was recovered. The labels are the ground truth the two refine arms are scored against, so each row was judged alone from the row's own fields: the DD source path, its description and unit, the ancestor name, the refined name and its description.

The criteria as applied

Each refined name was judged against four criteria, in this order:

  1. It parses under the grammar. All 124 refined names were parsed with the grammar package the repository pins (imas_standard_names.grammar.parser.parse(name, strict=True)) against the shipped vocabulary. All 124 parse — no row's label turns on grammatical validity. This is a check that could have failed: the same oracle rejects a name with an out-of-vocabulary token or segments in non-canonical order, and had it rejected one, that row would be a 0 on this criterion alone.
  2. It names exactly the quantity the source carries — nothing missing and nothing added. This decided every 0 written. The failure modes seen: the owner or zone changed (at divertor targets → the whole divertor assembly); a distinguishing qualifier dropped so the name collides with a sibling (the emitted wall flux named simply an ion_particle_flux_at_wall); the direction reversed (the emitted flux named incident); the cause swapped for a different physical mechanism (a potential-phi contribution named due_to_perturbed_parallel_magnetic_field); or a restriction added that the source does not state (minimum_absolute_safety_factor for a plain minimum safety factor).
  3. It follows the naming conventions. Segments in grammar order, one quantity per name, the object carried through of_, the location through at_ and the cause through due_to_, and a verbosity no greater than naming the quantity requires. Verbosity alone was never a 0: a long name that states the quantity exactly (surface_integrated_flux_surface_normal_net_plasma_energy_flux_at_plasma_boundary) was accepted.
  4. It agrees with how the catalog names its siblings. Where the ancestor name is a catalog name for the same quantity, an unchanged or equivalent refined name was accepted; where the refined name collides with a distinct reserved quantity the catalog already names (confinement_time is the catalog's energy-confinement quantity, not the duration of plasma existence), the row was a 0.

A 1 means the name survived all four. Each reason names the criterion that decided a 0, or the criterion weighed most for a 1.

Worked examples

Accepted — row-058

Source dd:breeding_blanket/module/time_slice/power_incident_neutron, unit W: "Total incident neutron power on a single breeding blanket module." Refined name: incident_neutron_power_of_breeder_blanket_module. Label 1. It parses (incident qualifier, neutron_power, of_breeder_blanket_module); it states the incident neutron power and its owner with nothing added or dropped; and it uses the same tokens as its siblings (incident_neutron_power_of_breeder_blanket_module beside nuclear_heating_power_of_breeder_blanket_module). The criterion weighed most was agreement with siblings, because the ancestor incident_power_of_breeder_blanket_module names the same physical quantity: naming the carrier (neutrons) is the refine's whole contribution and it is correct.

Rejected on meaning — row-072

Source dd:wall/description_ggd/ggd/particle_fluxes/ion/emitted/values, unit m^-2.s^-1: "Array of values for emitted." Refined name: incident_ion_particle_flux_at_wall. Label 0. The source is the ion particle flux emitted from the wall through surface emission; the refined name states the flux incident on the wall, the opposite direction, and so names a different quantity — the criterion that decided it. Because emitted and incident wall fluxes are distinct DD quantities, the reversal is a defect and not a paraphrase, and the name as written would collide with whatever name the incident flux takes.

Rejected on conventions and meaning — row-018

Source dd:spectrometer_visible/channel/grating_spectrometer/wavelength_calibration/gain, unit m: "Gain coefficient for the linear pixel-to-wavelength calibration of a grating spectrometer channel … wavelength = k × gain + offset." Refined name: spectral_factor_of_spectrometer_channel.

Label 0. The name parses, but the source is a calibration gain converting pixel index to wavelength; spectral_factor_of_spectrometer_channel names the channel's spectral response instead, a different quantity, and its own refined description makes that substitution explicit ("converting a channel input emission spectrum to detector count rate"). Had the refine written spectral_calibration_factor_of_spectrometer_channel — which another row's refine did — the same source would have been accepted.

One criterion per source

Two rows that share a DD source_path carry the same quantity, so their labels must follow one criterion rather than two. The sheet holds 56 distinct source paths. Every one was checked: 48 groups are homogeneous (all rows share a label) and 8 groups carry mixed labels. Each of the 8 is resolved under a single criterion, stated here once, and each row's reason records it.
