One disposable-Neo4j convention for the standard-names tests

Outcome

Two test files demanded opposite values of NEO4J_URI, so no session could run both: test_source_refresh.py refused any endpoint equal to the project graph, while test_panel_audit_sample.py demanded NEO4J_URI name the disposable one. Worse, the refusing guard resolved the “project graph” through NEO4J_URI, so once a run pointed that variable at a disposable endpoint the guard compared the endpoint against itself and refused everything. The five source-drift tests therefore errored at setup in the merged graph gate.

One session-scoped fixture in tests/standard_names/conftest.py now owns the convention for the package: it attaches to a supplied disposable endpoint or starts an empty instance of its own, names that endpoint in both NEO4J_URI and IMAS_CODEX_TEST_NEO4J_URI for the test's duration, and refuses loudly when the endpoint is the project graph’s. Both files’ local guards are deleted. The five drift tests run and pass.

The convention

ElementWhat it does
disposable_neo4j_uri (session)Attaches to IMAS_CODEX_TEST_NEO4J_URI when a run supplies one and it carries IMAS_CODEX_TEST_NEO4J_EPHEMERAL=1; otherwise starts an empty Neo4j through imas_codex.graph.temp_neo4j. Sets NEO4J_URI, NEO4J_PASSWORD, IMAS_CODEX_TEST_NEO4J_URI and IMAS_CODEX_TEST_NEO4J_EPHEMERAL, restores the previous values afterwards, and copies the server log to IMAS_CODEX_TEST_NEO4J_LOG when that is set.
disposable_neo4j_empty (function)The same endpoint with every node removed, so each test starts from a known-empty graph.
The refusalResolves the project graph’s own address with NEO4J_URI withheld — both the loopback spelling a login node uses and the scheduled service node a SLURM step uses — and fails the run if the endpoint is either one. Resolving it with the override in place is what made the old guard vacuous.
Profile checkAfter the environment is set the fixture re-resolves the profile and fails if it does not land on the disposable endpoint, so a test that builds its own GraphClient() cannot be written outside the instance it was given.

An empty instance carries no DD-resolution authority, and the drift scan reads one to stamp each source snapshot. The scan’s Cypher is what those tests prove, so test_source_refresh.py’s graph fixture serves the authority from the package’s synthetic rows — the same boundary the mock tier uses — while every query still runs on the disposable graph.
