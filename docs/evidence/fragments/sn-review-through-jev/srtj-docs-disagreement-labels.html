The rubric criteria as I applied them

A documentation is acceptable only when every check passes, and the failing label records the first check that fails. I applied the six checks as the sheet allowed:

  1. subject — the text documents the quantity the name denotes, and the DD source_path/source_unit measure that quantity. A provenance mismatch fails even when the prose reads well.
  2. physics — definitions, equations and statements are correct; the dimensions agree with the unit symbol.
  3. scope — the text claims no more and no less than the name (it is not narrowed to one machine or widened into a general quantity).
  4. house_style — applied only where the sheet lets it be: the rubric's house-style checks (a conventions-registry entry, a forbidden spelling, a COCOS number) key on the row's conventions field, which the sheet's pinned seven-field shape does not carry, so no row was failed on this check alone. The catalog's template_opening rule compares the first line against a template held in the conventions registry; that registry is not in the sheet and I did not reach it, so I did not fail a row on template opening either. I flag both as unapplied rather than guess.
  5. links — every name: link points at a name whose meaning matches its link text, and a bracketed phrase with no link target fails because the published entry shows the reader a reference that leads nowhere. A link to the row's own name presented as an example of something else also fails. This is the check most of the disagreements trip.
  6. complete — nothing is truncated, a placeholder, unresolved or self-contradictory. No row was failed on this check: no placeholders or truncations were found.

Three worked examples

Example 1 — S0003, label 0 (links)

Name ion_charge_state_energy_flux_at_wall_due_to_recombination, source wall/description_ggd/ggd/energy_fluxes/recombination/ion/state/incident/values. The prose is well-formed and the two leading links (ion energy flux at the wall due to recombination, energy flux at the wall due to recombination) resolve. The last sentence reads:

It is the energy-weighted counterpart of [particle flux at the wall due to recombination] for the same surface recombination source.

The bracketed phrase [particle flux at the wall due to recombination] carries no (name:…) target. A published entry would show the reader a reference that leads nowhere, which the rubric names explicitly as a links failure. Label 0.

Example 2 — S0058, label 0 (subject)

Name tilt_angle_of_passive_loop, source pf_passive/loop/element/geometry/oblique/beta, whose DD description is “Inclination of second angle”. Its sibling for the same geometry, alpha_angle_of_plasma_filament, is generated from …/geometry/oblique/alpha and described as the first-angle inclination of an oblique cross-section. The text for S0058 instead defines an element reference-axis orientation and states it “is analogous to the orientation defined for a tilt angle of a plasma filament” and “not an inclination parameter defining the shape of an oblique cross-section”. The source node is exactly that oblique second angle, so the source does not measure the quantity the text describes. Provenance mismatch → subject. Label 0.

Example 3 — S0002, label 1 (acceptable)

Name helium_4_density_at_pedestal_top, source summary/local/pedestal/n_i/helium_4/value. The text defines the charge-state-summed helium-4 density with a correct equation, its symbols all defined, sums over the two ionized states and excludes neutral helium, and locates the quantity at the pedestal top. Every link (normalized_poloidal_flux_coordinate_of_pedestal, density_at_pedestal_top, helium_4_density_at_plasma_boundary, helium_3_density_at_pedestal_top) resolves. Subject matches the source, dimensions agree with m^-3 and the scope is neither narrowed nor widened. Label 1.
