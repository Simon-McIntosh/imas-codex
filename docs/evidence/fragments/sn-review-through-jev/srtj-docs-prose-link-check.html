The rule

Two defects, both checked inside the existing link_hygiene gate (_link_hygiene_result, imas_codex/standard_names/docs_gates.py), so the one link parser in doc_links.py remains the only one:

  • Bracketed prose. _bracketed_prose_phrase reports the first bracketed phrase that names no standard name. The rule is one predicate: a bracket holds prose when its content carries at least one letter, is not a numeric interval ([0, 1]), and is either more than one whitespace-separated token or carries a digit or an operator, so a unit or symbol sequence ([m^-3], [K], [m^2 s^-1], [m/s]) is notation and raises nothing. Brackets inside $…$, $$…$$, \(…\), inline code, and the label of an already formed Markdown link are masked before the scan, by the same _masked_spans the reference parser uses.
  • Self-referential link. A name: link whose target is the documented name's own id is a hygiene failure, read from find_name_links through find_self_links. score_documentation takes the documenting name as documenting_name; with no name supplied the check is silent rather than guessing.

Every failure reason names the offending construct, so a refiner acts without re-reading the document. Two recorded defects reproduce verbatim:
