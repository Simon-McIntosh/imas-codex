Where the incumbent's lint cap acts (question 1)

  • The cap: _cap_docs_scores_for_lint_errors at imas_codex/standard_names/review/pipeline.py:1963, which holds any name carrying an error-severity lint finding below DEFAULT_MIN_SCORE.

  • The docs path the cascade wraps applies no such cap. process_review_docs_batch (imas_codex/standard_names/workers.py:11150) calls prepare_docs_review_request (workers.py:10712) and then adjudicate_review("docs", ...)   • The Jev route builds its own report. _docs_judgment (imas_codex/standard_names/review/cascade.py:519) calls jev_review.build_docs_audit_report (jev_review.py:623) with catalog_names=[item] and known_ids = {item} ∪ siblings (cascade.py:535).
