Exclusion collects every string a golden fixture carries and splits on ::, because the fixtures key a name unit under unit, canonical_unit or copy_group and some pack a pattern and a name into one string. That is a superset of the units they name, so no held-out case can be one the goldens already label. Sheet check, and its negative control

The check reads the committed sheet, fails if any row carries an unexpected field or any field that would disclose the arm or the sheet-to-case mapping, and then plants a row carrying arm and requires that the detector catch it — an empty or over-permissive check would otherwise report a safety it does not provide.
