Stored decision score and unchanged rubric

For selected Jev score s, cutoff c, and consumer threshold m = DEFAULT_MIN_SCORE = 0.85, the stored score is:

below cutoff:       m × s / c
at cutoff:          m
above cutoff:       m + (1 − m) × (s − c) / (1 − c)

This is monotone on 0..1 and places the cutoff exactly at the consumer threshold. The strict lower branch is capped at the representable float immediately below m to prevent roundoff accepting an item below cutoff. Endpoint cutoffs use only the nonempty branch. An explicit consumer min_score is mapped in the same way. A documentation contradiction caps only the mapped scalar below m. winning_score carries that decision score; winning_scores retains the original four 0-to-20 dimensions. The selected raw score, reference logistic probability, rubric and named failed-check evidence remain available. The mapped value is an operating score, not a calibrated probability.
