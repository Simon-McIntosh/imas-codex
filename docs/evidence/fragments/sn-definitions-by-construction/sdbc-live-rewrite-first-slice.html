Why no live name could be brought to accepted text

imas_codex/standard_names/worker_tasks/worker_review_docs.py:891 resolves _name_definition_note through _worker_dependency(), whose registry in imas_codex/standard_names/workers.py carries no such entry. The function is defined locally at worker_review_docs.py:699 and takes the resolver as its first positional, so the lookup raises KeyError: '_name_definition_note' on the first item and the pool retries the same item forever: 31,430+ identical error lines in one 17-second window, with no model call made in the loop. The call was introduced by a42c54b8d.
