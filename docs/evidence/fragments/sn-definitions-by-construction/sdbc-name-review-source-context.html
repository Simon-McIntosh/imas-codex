The two source-support checks read the DD leaf the name is bound to. For accumulated_carbon_equivalent_electron_count_due_to_gas_injection the leaf is summary/gas_injection_accumulated/carbon/value, whose documentation is Value; its parent is Carbon; the structure above both is Accumulated injected gas since the plasma breakdown in equivalent electrons. What the review now reads

Review enrichment walks HAS_PARENT from each bound source path to depth four and attaches every documentation/description statement it finds, with its path, to the exact source group it belongs to. The name state gains those statements as an observed channel, neighbourhood.dd_enclosing_structures, beside the leaf text. enclosing_structure_support then reconciles the name's grammar qualifiers against leaf plus structures: when every qualifier is stated somewhere and at least one is stated only by a structure, the two source-support checks are answered zero and the stating structure is recorded on the check. A qualifier no leaf and no structure states leaves the answer to the judge, so an unsupported qualifier still records its failure.

How the code decides that a structure states a qualifier

The name is parsed with the canonical grammar and its qualifier tokens are read off that parse — accumulated, carbon, equivalent_electron for the carbon name, and operators such as line_integrated and flux_surface_averaged are not qualifiers and are never examined. Every text the review holds is then collected into two sets: the leaf documentation of each bound source path, and the statements made by the structures above it — anchored at each bound path, read by the one HAS_PARENT*1..8 walk the extraction enrichment already owns, nearest first, with each structure's documentation and description both read (documentation first), whitespace collapsed, a structure stating nothing dropped and a repeated sentence kept once. A qualifier is stated when every word of its token appears in one sentence as a stem — case-folded, with a plural or suffix-stripped form accepted when at least four letters remain, so equivalent_electron matches equivalent electrons and gas/ion keep their own form. A structure states a qualifier only when that sentence neither negates nor contrasts it (not, never, without, rather than, instead, other than) and does not name another quantity by its physical base instead. The check settles only when all of the name's qualifiers are stated by leaf-or-structure and at least one is stated only by a structure; otherwise it returns nothing and the judge's own answer stands.

Worked example, a label chain: for accumulated_carbon_equivalent_electron_count_due_to_gas_injection the leaf summary/gas_injection_accumulated/carbon/value says only Value, its parent says Carbon, and the grandparent says Accumulated injected gas since the plasma breakdown in equivalent electrons. carbon matches the parent, while accumulated and equivalent_electron match only the grandparent's sentence; all three are stated and two are stated only by a structure, so both source-support checks answer 0.0 and carry that sentence.

Worked example, a sentence rather than a label: for trapped_fast_ion_charge_state_torque_density_due_to_collisions the only structure that states trapped is distributions/distribution/profiles_2d/trapped, whose text is Flux surface averaged profile evaluated using the trapped particle part of the distribution. The match is made against the word trapped inside that sentence, not against the path's final segment, and the check settles on it the same way.

And the case the rule must not absorb: line_integrated_neutral_beam_radiance_at_spectral_line is bound to charge_exchange/channel/bes/radiances (leaf: Calibrated intensities of the 9 splitted lines…), whose structures say Derived Beam Emission Spectroscopy (BES) parameters and Set of channels (lines-of-sight)…. Those statements exist, but neither states neutral_beam — Beam Emission Spectroscopy carries beam and no neutral — so the rule returns nothing, and across three repeated judgements the judge's own answers stood: 0.38 / 0.35 / 0.40 on over_qualified_modifier and 0.47 / 0.47 / 0.49 on source_fidelity_unsupported_qualifier, none settled. A statement that exists is not a statement that answers the question.
