What DBSEL selects

/analysis/bin/dbsel is a C shell script; a source-tree copy is /analysis/src/SAselene_v2.0_forPSRC/RUN/dbsel. Its usage is dbsel SHOT TIME [1:Display]. It passes the shot and time to /analysis/bin/getseldata, links EFIT95.DATA as fort.95, then invokes /analysis/exec/SAselene.ex with the optional display flag and fixed mode arguments 1 -2 'mgt', reading fort.96. The getseldata wrapper calls /analysis/exec/getseldata.ex with that shot and time; its source under /analysis/src/getseldata_v4.2 accesses EDDB and writes the SELENE inputs. Thus DBSEL selects a shot/time slice for a SELENE run; it is not an EQDB server chooser. The script was inspected, not executed, because it deletes and creates files in its current directory.
