JT-60SA discovery excludes user home and absolute work paths as prefixes

In imas_codex/config/facilities/jt-60sa.yaml the absolute excludes.directories entries (/tmp, /var/tmp, /work/edas) move to excludes.path_prefixes, /home is added there, and /home leaves discovery_roots. tests/config/test_jt60sa_exclusions.py asserts should_exclude is true for /home/u/x and /work/edas/x and false for /analysis/src/x, and that /home is not a discovery root. Measure: uv run pytest tests/config — 33 passed (EXIT=0). Negative control: the same test against a scratch copy whose path_prefixes omit /home — 1 failed (EXIT=1), first failure test_home_subtree_excluded, assert False is True.
