Document status writers report a failed write

mark_document_failed, mark_document_deferred and mark_document_failed_or_deferred in imas_codex/discovery/wiki/graph_ops.py no longer wrap their write in except Exception and log a warning: a status write that does not reach the graph now raises. The callers handle it explicitly — defer_failed_documents counts only the writes that landed and re-raises on a failure, and the deferral sites in imas_codex/discovery/wiki/workers.py and the terminal-record site in imas_codex/discovery/wiki/pipeline.py log the failed write and re-raise.
