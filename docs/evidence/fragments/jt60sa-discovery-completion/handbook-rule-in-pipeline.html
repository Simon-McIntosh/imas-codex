The wiki ingest path marks dynamic handbook tables itself

WikiIngestionPipeline.ingest_page now applies the dynamic-page rule where a page's chunks are written: it resolves the databases a table fronts from the ?db= links its sibling pages carry, stubs the header-only chunks before embedding, and writes WikiPage.fronts_database in the same persist. The stub text is embedded, not the empty form, so a fresh ingest marks the page without an operator call. The page-id-keyed apply_dynamic_page_rule is replaced by mark_dynamic_handbook_pages, applied at the end of ingest_pages, which reads the stored linking chunks and so marks a topic whose own ingest was skipped for lack of content. A failure of that marker is raised out of the run, not logged away, so a complete ingestion is never reported while the dynamic-page guarantee did not hold; the marker also sets the page's status to ingested in the same write.
