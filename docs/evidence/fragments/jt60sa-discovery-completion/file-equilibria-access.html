Equilibrium fields read by format

The EDAS scanner now returns two additional JT-60SA DataAccess methods alongside its existing EDDB method. ScanResult.data_accesses sends both through the same persistence writer before their signals are ingested. The EQDB method resolves a local record through $EQDB_FILE or a root, shot and time under $EQDSK_DIR or $HOME/LOCALDB/EQDSK; the G-EQDSK method resolves a producer's filename template under its root. Each template takes root, shot, time and field, and the G-EQDSK template also takes the producer's filename template. The EQDB access description records the compiled client's network route through dbsvr17p:/JT60SA_EQ/EQDB as an alternate for when that server becomes reachable.

The scanner creates 22 code-keyed FacilitySignals: SELENE and TOPICS each have #GEO/RG, #GEO/ZG, #GEO/NSR, #GEO/NSZ and #EQU/PSI, matching the facility's .bf declarations. SA, LIUQE and CHEASE each have G-EQDSK r, z, psirz and the COCOS declared by their example file (2, 7 and 17 respectively). A signal's identity and path name the producing code and format field; the file path is an example in its description, not the signal anchor.
