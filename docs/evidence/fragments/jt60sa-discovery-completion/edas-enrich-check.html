EDAS census-category enrichment and access check

The five EDAS census categories (MAG, MDAC, PSRC, FAME, MMSYS — 764 signals) were enriched and access-checked under a USD 8 cap. Enrichment and the check both scope by category through a new --category claim filter on discover signals, backed by build_category_predicate in imas_codex/discovery/signals/parallel.py. The predicate reads the leading path segment of the signal's data_source_path, not its name, because enrichment rewrites the name.

Two repairs made the check read the right catalogue row. The EDAS scanner's check() (imas_codex/discovery/signals/scanners/edas.py) split s.name on "/" to recover the EDDB category and data name; after enrichment name is an English label (PSRC/calIp becomes Plasma Current (Ip)), the split yields one part, the category sent to the host is empty, and every read returns EDDB irc=1031 (no data for that category). check() now reads the catalogue key from data_source_path, which survives enrichment, and falls back to name only when the path is absent. The check call site in parallel.py now passes data_source_path and data_class into the FacilitySignalModel it hands to check(), so the row arrives with the field the scanner needs.

The check ran against reference shot E101163, not the criterion's E101173. At E101173 only MMSYS/curCS1LKAT reads back; PSRC/calIp returns irc=1015 (no data for the name) over both a short and a wide window and for every data class, and shots below E100873 return irc=1013 (shot absent). A bounded probe of three EDDB reads walked E101173 → E101168 → E101163 and found E101163 carries the census data (eddbreadTime ntime=41), so the check ran with --reference-shot 101163.

Outcome: all 764 in-scope signals carry an English description and a physics_domain; 763 of 764 are access-checked. Per-category checked counts: MAG 18, MDAC 273, PSRC 325, FAME 100, MMSYS 47. Successful CHECKED_WITH edges at E101163 by category: MAG 10, MDAC 147, MMSYS 47, PSRC 321 (FAME 0); the remainder are genuine success=false / error_type='no_data' reads for their catalogue names at that shot. All four named signals — PSRC/calIp, PSRC/magFluxLp1, PSRC/magPbTC1, MMSYS/curCS1LKAT — are checked with a success=true edge at E101163, so the four-signal pass criterion is met. Total recorded llm_cost across the census is USD 1.32, well under the USD 8 cap.
