4–5. Equilibrium and 2D map reads

The current SELENE file is a big-endian Fortran sequential file: three record markers close at lengths 252, 452904 and 3248 bytes. The first record gives shot, time, EQ31 and an EQSLG title. The next record begins with six integers, ending 129 and 129, followed by 129 R coordinates, 129 Z coordinates and 129 × 129 ψ doubles. This order is consistent with inc/#AAA (IRDM=129, IZDM2=129), inc/#GEO, inc/#EQU and eqdbput.f:203-219. The read asserted matching record trailers, increasing R and Z, finite ψ and a nonzero ψ range, so the result is more than a readable header.

ssh -F /home/ITER/mcintos/.ssh/config -o BatchMode=yes -o ControlMaster=no -o ControlPath=none jt-60sa 'python3 -' <<'PY'
import hashlib, math, struct
from pathlib import Path
p=Path('/home/a114004/LOCALDB/EQDSK/10/1011/101163/005000')
b=p.read_bytes(); pos=0; records=[]
while pos<len(b):
    n=struct.unpack_from('>I',b,pos)[0]
    assert struct.unpack_from('>I',b,pos+4+n)[0]==n
    records.append(b[pos+4:pos+4+n]); pos+=n+8
assert [len(x) for x in records]==[252,452904,3248]
h,body,_=records
shot=struct.unpack_from('>i',h)[0]; t=struct.unpack_from('>d',h,4)[0]
nr,nz=struct.unpack_from('>6i',body)[-2:]
assert (nr,nz)==(129,129)
r=struct.unpack_from('>{}d'.format(nr),body,24)
z=struct.unpack_from('>{}d'.format(nz),body,24+nr*8)
psi=struct.unpack_from('>{}d'.format(nr*nz),body,24+(nr+nz)*8)
assert all(math.isfinite(x) for x in psi)
assert all(a<b for a,b in zip(r,r[1:])) and all(a<b for a,b in zip(z,z[1:]))
assert max(psi)-min(psi)>0.1
print('file',p)
print('sha256',hashlib.sha256(b).hexdigest())
print('shot',shot,'time_s',t,'grid',nr,nz)
print('R_m',r[0],r[-1],'Z_m',z[0],z[-1])
print('psi_min_max',min(psi),max(psi))
PY
