Chunks of files no longer ingested are removed

The node set is every CodeFile whose status is not ingested that carries chunks through the traversal CodeFile <-FROM_FILE- CodeExample -HAS_CHUNK-> CodeChunk, minus any file holding a live ingest claim. The claim timeout is the shared DEFAULT_CLAIM_TIMEOUT_SECONDS (300 s) from imas_codex/discovery/base/claims.py, so a file whose claimed_at is within the last 300 s is excluded — no file was excluded at run time (zero live claims). Deletion renders the reset targets' own cascade, _CODE_CHUNK_CASCADE from imas_codex/discovery/base/reset.py, over the planned node set; the traversal is not spelled anew. The ids to delete were written to to_delete.json before any deletion, and a later code change may retire the inline copy in clear_facility_code but that is not this node's work.
