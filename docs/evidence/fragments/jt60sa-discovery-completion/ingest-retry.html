Root cause — a product defect, outside this node's scope. _check_already_ingested (imas_codex/ingestion/pipeline.py) reports a file as already ingested when a CodeExample with its facility_id + source_file exists — which is exactly the collision node left by the earlier concurrent run (verified: all 29 failed files carry a CodeExample whose source_file equals the file's path). With every path so reported, ingest_files reaches if not paths_to_ingest: return stats (line 413) and returns before stats["outcomes"] = outcomes (line 643), so the caller receives no per-file outcomes. The batch handler in imas_codex/discovery/code/workers.py then treats every claimed file's missing outcome as a failure at _mark_file_failed(f["id"], "no ingestion outcome recorded"), and all 29 are written back to failed. This is the failure mode §31 item 2 set out to remove — one file's outcome decided by another's — reappearing through the early-return path, which violates the contract the same file states at lines 361–363 (“every path asked for ends with exactly one outcome”). The node holds a no-code-change fence, so this is reported, not repaired.
