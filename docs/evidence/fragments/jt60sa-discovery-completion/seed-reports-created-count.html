Root seeding reports the rows it created, not the rows it processed

GraphClient.create_nodes gained a default-off create-only option in an earlier change so an additive caller could seed without resetting an existing row, but it still returned only processed. seed_facility_roots therefore could not tell how many roots it had actually created and printed every configured root as added. The create-only branch now marks the rows MERGE creates, aggregates that mark into the statement's returned row and clears it in the same query, so the returned created count is the rows newly created and the mark never persists. create_nodes returns created under create-only; seed_facility_roots returns that count for its canonical and alias rows. The default upsert path is unchanged and reports no created key.
