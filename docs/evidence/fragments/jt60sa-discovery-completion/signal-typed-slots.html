Typed slots on FacilitySignal

FacilitySignal carries data_class, shot_range and pid as typed LinkML slots, beside keywords and aliases. The EDAS scanner writes the EDDB catalogue values to the slots; its check() reads data_class back from the slot instead of parsing keywords.

New enum SignalDataClass: time_series (EDDB class T), one_point (O), parameter (P). An unknown EDDB letter leaves the slot unset.
