Every requested path carries an outcome, including the already-ingested ones

The JT-60SA code pass re-failed 29 admitted files whose examples and chunks already existed. ingest_files in imas_codex/ingestion/pipeline.py recorded each already-ingested path's outcome in a local outcomes mapping, but the “All files already ingested” branch — taken when every requested path is already in the graph — returned stats before stats["outcomes"] was ever assigned. The code ingest worker in imas_codex/discovery/code/workers.py reads ingest_stats.get("outcomes", {}) and marks any claimed file with no entry failed with reason no ingestion outcome recorded, so a cleanly skipped batch was reported as a batch of failures.

All four exits from ingest_files now route through a single settle() helper that assigns stats["outcomes"] and the failed / skipped_files summaries derived from it. Already-ingested paths carry {"status": "ingested", "reason": "already ingested"} on both the early-return path and the mixed path, so the worker marks them ingested rather than failed. The fetch-failed bookkeeping was moved ahead of the “No files to process” return, so a path the fetch never returned is also recorded there instead of silently unrecorded.

The defect was reproduced on the unfixed tree and quoted: there the new all-already-ingested test failed with KeyError: 'outcomes' at assert stats["outcomes"][PATH]["status"] == "ingested", while the mixed-batch test already passed — the loss is specific to the early-return path. With the change the gate uv run --no-sync pytest -p no:cacheprovider tests/ingestion/test_code_ingest_idempotent.py tests/discovery/test_code_ingest_settles.py tests/discovery/test_code_pipeline.py exits 0 (105 passed) on the fleet compute node 98dci4-clu-2018 (run in place, no srun). The two new tests pin the contract the worker depends on: a batch whose every path is already ingested reports ingested / already ingested for each requested path with nothing written to the graph, and a mixed batch reports both the already-ingested path and the newly written one. No discover run and no graph write were performed.
