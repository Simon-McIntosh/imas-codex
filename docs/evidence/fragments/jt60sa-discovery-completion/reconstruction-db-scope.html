Code discovery's triage question set gains a fifth scope question, reads_or_writes_reconstruction_db, in imas_codex/llm/prompts/code/triage.md. The nouls sit outside the template's with_content guard, so one addition reaches both arms: the names arm and the content arm ask the identical set. The wording separates the reader, writer or interface that loads or stores reconstruction-result records — the EQDBMS EQDBGET interface, the eqrdNN readers, the eqwtNN writers and the _BF field-list includes that name the stored fields — from computing the reconstruction itself, which the simulation question already marks. Reading a stored equilibrium or q-profile as an input to analysis or mapping is in scope and is explicitly not the same as computing it.
