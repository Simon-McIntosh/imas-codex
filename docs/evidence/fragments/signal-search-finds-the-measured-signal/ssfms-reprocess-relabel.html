Re-reading the pre-existing labels on grouped members

The reprocess rewrote every JT-60SA description, so a label graded against the text a signal used to carry may name a quantity that text no longer describes. The labels most exposed to that change are those on grouped members — signals whose SignalSource carries more than one member, whose description changed from the group's shared template to the member's own channel. 1,321 pre-existing labels sit on 1,168 such signals. Each was re-read by an agent from the signal's current name, unit and description against its question's intent, under the fixture's own grading rule: 3 a measurement of the queried quantity; 2 a commanded, reference or setpoint value of it, or the same quantity at an adjacent point; 1 related hardware; 0 read and judged irrelevant. No rerank question and no decide_batch was used — a set graded by the arm it measures would agree with that arm by construction. 11 labels changed, every one of them 3 to 1, all under one question. Labels on single-member signals were not re-read, because their descriptions were not template-derived and the reprocess left their meaning alone. The pre-reprocess descriptions were not kept, so the old text is not shown. Every changed label is listed below.
