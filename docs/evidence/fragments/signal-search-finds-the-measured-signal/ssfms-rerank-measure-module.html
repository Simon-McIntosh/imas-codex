A measurement module for the signal search

This node builds tests/llm/measure_search_rankings.py, the module that scores, for a given number of passes, the signal arms and the two ported measurements, together with the harness changes the module rests on. It runs as python -m tests.llm.measure_search_rankings [passes] [--section signal|docs_code|embed_text]: signal scores the fused order alone (rrf) and both rerank arms over the passes, each rerank arm building its candidate state with the product's _signal_rerank_state (the generic arm judged on the generic relevance question, the role-aware arm on the role-aware one); docs_code ports section 4; embed_text ports section 5. Only the two Jev sections spend on the discovery-relevance seat, and each reports the spend read from the response usage the judged call layer returns.

Section 4 reproduced. The port retrieves the 18 JT-60SA docs and code questions in tests/llm/fixtures/docs_code_search_questions.json live and reranks them live, then scores labelled-only nDCG@10 at pool 60. The embedding figure reproducing to the digit shows the fixture and the label rule are faithful; the residual is the judge's ordering over repeats, which is what the band absorbs.
