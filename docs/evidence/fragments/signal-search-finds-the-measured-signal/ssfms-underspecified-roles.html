An underspecified signal carries no stored role

Outcome: the change this record was written to describe was withdrawn. This node first admitted underspecified to the shared role predicate and had the enrich worker judge a role for every signal it marked underspecified. The blind re-measurement of that judgement scored 26 of 30, below the 27 needed to keep the roles, so the change is withdrawn and replaced by its opposite: an underspecified signal carries no role, and the marking clears any role it held. The account below is kept as the history of what was built and measured; the evidence for the reversal is in the closing section.

As first built. A signal enrichment marks underspecified carries the same stored description a searcher reads, but the role predicate admitted only enriched and checked, and the enrich worker judged a role only on its enriched branch. So an underspecified signal was reachable by text and invisible to a role= filter, and the sweep that backfills missing roles never saw it. The withdrawn change admitted underspecified in the shared predicate and had the enrich worker judge any signal it marked underspecified as it already did for one it marked enriched.

The shared predicate now admits only the two statuses that carry a judgement, enriched and checked, with a non-empty description and a null signal_role. The sweep and its census still share that one predicate, and the store test drives its graph double from the Cypher the production sweep and census issue rather than from a predicate of the test's own, so the two are required to agree by construction: the double selects exactly the rows the statement it receives names.

Three tests hold the invariant, one per way it could be lost, and each has a recorded red arm. test_underspecified_signal_is_not_a_role_candidate fails when underspecified is re-admitted to the predicate; test_enrichment_does_not_judge_an_underspecified_signal fails when the enrich worker judges a signal it marks underspecified; and test_mark_signals_underspecified_clears_a_stored_role fails when the marking statement drops its role clear. The blind gate failed, and the roles were cleared

The gate is the blind re-measurement, whose record is ssfms-underspecified-roles-blind.html. A separate node drew a fresh seeded sample of 30 of the 225 JT-60SA underspecified signals, labelled each from its name, unit and description alone with no model call and no stored role in view, and compared only afterwards: agreement was 26 of 30 against a keep threshold of 27 (90%), so the verdict was fail. Four signals disagreed, each a case where the description names a quantity the six definitions place in a different slot from the one the model chose — a constraint count read as derived_or_computed where the hand reads configuration_parameter, a radial coordinate array read as measured where the hand reads derived_or_computed.

On that failing verdict the blind node cleared every role the backfill had stored: all 225 JT-60SA signals with status='underspecified' had signal_role set to null, 225 enumerated and 225 nulled with 0 remaining, as its record's census table shows. The live underspecified population is 225, not the 210 the withdrawn run counted, because the population grew between the two measurements.

Withdrawn. The changes this record's earlier sections describe — the shared predicate admitting underspecified and the enrich worker judging a role for every signal it marks underspecified — are withdrawn, because a role judged from a description the worker itself found too thin to enrich agrees with a blind hand-read on 26 of 30 such signals, below the rate at which the roles are worth storing. The predicate admits only enriched and checked again, the enrich worker judges nothing for a signal it marks underspecified, and the marking clears any role the signal carried so no stale role survives the status change. A signal marked underspecified is invisible to a role= filter by design; it remains reachable by text, which is the only evidence a reader has for it.

This measures that underspecified signals carry no stored role on this workstation's JT-60SA population, that the marking clears a role a signal already held, and that the shared predicate no longer admits them. It does not measure how a searcher's role= filter behaves against a cleanly re-enriched population: the cleared signals were judged from descriptions that remain too thin to judge, so their absence from a role filter is the intended state rather than a regression.
