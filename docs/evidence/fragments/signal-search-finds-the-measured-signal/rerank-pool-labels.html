Labelling the RRF top-60 pool on every golden question

The golden harness scores four ranking arms over 22 graded questions. The rrf arm fuses a 100-candidate vector pool with a 50-candidate full-text pool, keeps the eligible candidates in that fused order, and hands the first 60 to a rerank stage. A later rerank arm is scored on whatever order it chooses over that pool, so every one of the 60 must carry a grade 0-3 before either arm can be scored, since a candidate with no label makes the arm refuse rather than score. The harness's own gate inspects only an arm's top-10, so the pool was previously unguarded past rank 10 — the surface this node exists to close.

The pool is recomputed live, not cached: vector search over the production description embedding, full-text search over the same descriptions, both fused by reciprocal rank fusion, filtered to the eligible population (facility jt-60sa, enriched at or after the 2026-10-11T21:08:54Z cutover; 14,312 signals) and cut at 60. Across the 22 questions that is 1,320 pool slots holding 464 candidates that carried no label — 396 distinct signals, some appearing in more than one question's pool.

How each grade was chosen

Every candidate was read from its signal id, name, unit, source and description against the question's declared intent, under the fixture's grading rule: a grade-3 signal measures the queried quantity itself; a grade-2 signal is a commanded, reference or setpoint value of it, or the same quantity measured at an adjacent point; a grade-1 signal is related hardware — a status flag, a configuration value, or a neighbouring measurement on the same circuit; a grade-0 signal was read and judged irrelevant. The rule is stated once in the fixture description and is what the earlier pooled labels already used, so this node adds to one label set rather than introducing a second convention.

The check, and its negative control

check_pool_labels.py recomputes each question's RRF top-60 pool live and asserts that every pool member carries a grade in the fixture's relevant map. Run after the last label it exits 0, reporting 60 pool members and 0 unlabelled for all 22 questions. Its negative control removes one label from a scratch copy of the fixture — a pool member at index 45 of plasma-current-total that is in the RRF top-60 but outside the harness's top-10 gate — and the check then exits 1, naming plasma-current-total::jt-60sa:general/psc_1625_a003. The golden harness's own four-arm table run over the same mutated copy passes, which is the point: the gap this check closes is invisible to the top-10 guard.
