The fused head scores 0.5136, which is 0.0315 above the recorded 0.4821 — outside the ±0.02 band, but in the improving direction: fusion did not regress the docs and code search, it raised it. The band cannot be applied cleanly because the recorded baseline is no longer reproducible: with the additive rule restored in a scratch copy, run the same day through the same judge, the same measurement gives 0.3297, not 0.4821. The retrieval and label population have drifted since 2026-10-07. On the like-for-like comparison that the two arms do support — same head, same day, same judge, same labels, only the ranking arithmetic differing — fusion lifts labelled-only nDCG@10 from 0.3297 to 0.5136, and on the prototype's own label set from 0.3297 to 0.4025.
