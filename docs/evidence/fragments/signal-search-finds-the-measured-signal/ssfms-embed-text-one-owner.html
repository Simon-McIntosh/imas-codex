ssfms-embed-text-one-owner — one owner for the signal embed text

The description writer derived its embed text through a private _default_embed_text while the re-embed sweep's hash predicate and the census recomputed it through signal_embed_text. Two functions expressed the same description-only choice, so a change to one would desync the vector the writer stores from the hash the census expects, and the census would report freshly written rows as stale. Consolidated to signal_embed_text as the single derivation in imas_codex/discovery/signals/parallel.py: the writer takes signal_embed_text as its default embed_text, the sweep (reembed_stale_signal_descriptions) passes it explicitly, and the census's predicate (find_signal_hash_mismatches) calls it. _default_embed_text is removed. Added test_writer_and_census_share_one_embed_text_derivation, which moves the derivation and asserts the writer's stored hash and the census's expected hash move together, and the graph-marked test_census_statement_runs_against_the_live_graph, which runs the real read-only census statement.
