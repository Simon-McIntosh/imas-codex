Shared evaluation module, and one AUC owner

imas_codex/discovery/base/evaluation.py now owns the metric primitives (scikit-learn roc_auc_score, accuracy_score, f1_score, confusion_matrix, cohen_kappa_score) and what the library lacks: copy-group-aware resampling, the paired difference over canonical units, an operating point chosen on the calibration split and refused on that split, the stability figures, and the fixed fixture-row loader. The hand-rolled pairwise AUC loop in discrimination_metrics is folded onto the module's roc_auc, so one AUC owner remains.
