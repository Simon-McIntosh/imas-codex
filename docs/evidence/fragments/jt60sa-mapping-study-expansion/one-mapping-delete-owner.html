One owner deletes a mapping, whichever command asks

What changed. The whole-mapping delete moved into one function, delete_mapping(facility, ids_name, gc) in imas_codex/ids/graph_ops.py, beside clear_mapping_bindings. It removes the mapping's MAPS_TO_IMAS bindings (through the existing binding owner), its sources' MappingEvidence nodes and the IMASMapping node, and returns {"mappings": n, "bindings": n, "evidence": n}. Both imas map clear (_clear_mapping in imas_codex/cli/map.py) and the engine's --clear branch (clear_mappings_for_ids in imas_codex/ids/workers.py, formerly binding-only) now call it. The engine logs its three counts unconditionally, so a clear that deletes nothing logs the zeros instead of staying silent.

Unit measure — both callers reach the one owner. tests/ids/test_map_run_clear.py installs a single shared spy on the graph_ops owner and drives both entry points: workers.run_mapping_engine(MappingDiscoveryState(clear=True)) and map_cli._clear_mapping both reach it for ("jt-60sa", "magnetics"). A separate test pins that the engine logs Cleared 0 mappings, 0 bindings, 0 evidence for jt-60sa when the owner returns zeros. Gate: tests/ids/test_map_run_clear.py tests/ids/test_mapping_edge_ownership.py → 17 passed, EXIT=0.

Live-graph measure. tests/ids/test_mapping_delete_graph.py (marked graph) seeds a throwaway facility zz-delete-owner-test with one IMASMapping, one SignalSource, one MAPS_TO_IMAS binding and one MappingEvidence node; a positive control asserts all three are visible before the clear. It then calls the engine path clear_mappings_for_ids(FACILITY, [IDS_NAME]), which returns {"mappings": 1, "bindings": 1, "evidence": 1} and leaves the graph with {"mappings": 0, "bindings": 0, "evidence": 0}. Run with -m graph on the fleet node: 1 passed, EXIT=0.

Negative control, and it held. Making the engine path skip the evidence delete (the MappingEvidence DETACH DELETE removed from delete_mapping, the owner the engine path calls) made the graph test fail: 1 failed, EXIT=1, with {'evidence': 1} != {'evidence': 0} — the binding and the mapping node were gone but the evidence node remained, exactly the defect the section records. The mutation was reverted and the gate re-run green.
