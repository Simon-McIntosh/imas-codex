The assign phase ends when only handled sources remain

A source whose target choice raises, or which has no shortlist to choose from, is released with its route left as escalated. The assign phase's pending-work check counted that released source as remaining work, so the phase never reported done, the map loop waited on it forever, and validation never ran. has_pending_assignment_work in imas_codex/ids/workers.py now takes handled_source_ids, and assign_worker excludes the sources it has already handled when it checks whether the pass is complete — the same exclusion the map pass already carries.
