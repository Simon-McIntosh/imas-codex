Hand-off rows carry the target's COCOS label and its source

build_mapping_handoff in imas_codex/ids/handoff.py resolves each signal row's cocos_label and cocos_label_source from the target itself or its nearest ancestor along HAS_PARENT that carries cocos_transformation_type. A time coordinate is never COCOS-transformed, so a target whose final segment is time carries none for both keys whatever its ancestors hold, while its sibling data and error fields keep the inherited label. Both keys are additive, so format_version stays 1. Any other target with no labelled node on that chain carries the DD absence token none for both. The export no longer reads the binding's own cocos_label; it reads only the repaired graph label.
