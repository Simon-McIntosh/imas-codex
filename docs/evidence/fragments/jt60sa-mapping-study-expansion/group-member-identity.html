The TC probe group re-individualizes after a re-propagation

propagate_source_enrichment writes a representative signal's description onto every follower in its SignalSource. It left the source's members_described flag set, and individualize_source_descriptions selects only sources whose flag is unset — so a source a later run re-enriched its representative for kept the representative's copy on every member, and nothing replaced it. A census of the live graph found twenty JT-60SA sources marked members_described whose members shared exactly one description, 1,220 of them written by signal_source_propagation. The fix clears members_described as the copy is written, re-arming the individualization pass.
