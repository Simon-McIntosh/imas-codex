Declined, with what the repair would have cost

The prototype's unit rule duplicates name_unit_consistency_check.
The prototype is a frozen measurement: its arms were scored once, and the E2 arm's verdicts are part of the published table. Replacing the arm's unit rule with the repository checker changes which names the arm flags, so the published scores would have to be re-derived, and the checker answers a different question (name against a declared unit in a DD entry) from the arm's (unit words in the name against the definition's quantity). The reuse cap and the frozen scores are both reasons not to move it; it is recorded here instead of silently kept.
The prototype's gate log names the parent commit's tree.
The log is a record of a run that happened at that revision, and the script that produced it now refuses to start in this tree because its question run is gone. Rewriting the log to name the delivered head would state a run that never took place. The report itself was regenerated from the committed scores and is verified against them; the log is marked as what it is here rather than corrected.
The labels gate and four committed extracts sit outside the reviewed node's declared write paths.
The measure for this node requires the gate repair, which cannot be made inside the four paths the earlier node declared. The earlier node's manifest declared four paths that exclude its own gate, which is the defect; this node records the write and its reason rather than editing another node's manifest.
The family-wording coverage check compares the report with itself.
The count it compares against is built from the progress records the report is built from, so a report that overstates coverage and a builder that drops the same names agree. An independent count needs the live graph, which the verify phase already reads for nine other facts; that phase is where the independent coverage check belongs, and the default suite cannot run it. The report's own coverage sentence names the records it counts, so the reader can see what the figure is.
The family-wording verify phase runs only by hand.
It cannot run in this tree at all, and that is measured: invoked here it exits before its first check with FileNotFoundError on census-before-pass.json, the snapshot that node's own run kept under its own home.
