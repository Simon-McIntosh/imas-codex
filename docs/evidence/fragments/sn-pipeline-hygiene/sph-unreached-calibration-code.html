The calibration module carries only code something reaches

Twelve of the eighteen module-level definitions in imas_codex/standard_names/review/cascade_calibration.py had no caller: the axis fitters that once produced the review cutoffs, and the golden fixture paths and receipt reader they alone used. Those fitters are deleted and the module is 100 lines, down from 375. What remains is the rate matcher the test keeps cross-checking against cascade.map_decision_score, the metric helpers the undefined-precision test asserts, and the receipt reader whose refusal test names the path it could not read. A test now fails when a module-level definition loses its caller.

Reachability listing, before and after. 

The listing comes from the same guard the test runs: calibration_reachability() in tests/standard_names/test_cascade_calibration.py parses the module, takes every module-level function, class and constant, roots reachability at names read from a caller file in imas_codex/ or tests/, and closes over the references found inside reached definitions. Module-level assignments are recorded as referrers but confer no reach, so a constant kept alive only by another unreached constant is reported unreached. The instrument is shown seeing the module rather than an empty read: it reports 18 definitions before and 6 after, and names the live rate matcher in both.

The guard fires on a callerless function.

Two default-tier tests hold this. test_every_module_definition_is_reached_from_code_or_a_test asserts the unreached list is empty; it was red at base over exactly the twelve names above. test_reachability_flags_a_function_nothing_reaches appends a synthetic callerless definition to the module source and asserts the instrument reports precisely that name, so the guard is falsifiable without editing the module. The external control was the real thing: a callerless _refit_cutoffs appended to the module turned the first test red with assert ['_refit_cutoffs'] == [] and EXIT=1. It was then removed.

Stored cutoffs and review-path behaviour unchanged.

No threshold value is touched: imas_codex/standard_names/review/cascade_thresholds.json is unmodified (SHA-256 a0aa1e74be4b0a50c182de10f6da72e9974e3f04568736e3ddb2c13e3578024a at base and at head). The surviving functions are byte-identical in body to the base revision apart from the module docstring; only definitions that no caller reached are removed.
