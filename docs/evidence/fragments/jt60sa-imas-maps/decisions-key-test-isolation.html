Decisions-key test isolation

Seventeen tests in four files drove a Jev decisions caller while relying on the ambient OPENROUTER_API_KEY_IMAS_CODEX. Since judgment.rerank_pool and the candidate stage skip their calls when the key is absent, each such test now installs its own dummy key with monkeypatch.setenv, so the run no longer depends on the environment. The empty-key run over the twelve listed files reports the same single failure as the key-present run.

Before the change the empty-key run over the twelve files reported 18 failed (17 key-dependent above plus the one follow-on); after it, 1 failed, 208 passed, 59 skipped against 1 failed, 253 passed, 14 skipped with the key present. The two runs fail the same single id, tests/test_imas_search_scoring.py::TestCodeExampleVectorSearch::test_graceful_on_missing_index (Exception: Index not found), which fails with and without the key. The empty-key run's extra skips are tests/discovery/test_signals_pipeline.py's 45 graph-reachability probes, which need the Neo4j credential that PYTHON_DOTENV_DISABLED=1 also removes; a skip is not a failure and those tests do not drive a decisions caller.
