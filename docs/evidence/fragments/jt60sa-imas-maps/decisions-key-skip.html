Decisions-key skip

judgment.decisions_key_present, built on get_api_key, gates both callers of the Jev decisions endpoint. rerank_pool returns the embedding order with a note naming the missing variable and a cost of 0.0; the candidate stage leaves every source unjudged and every source is released for a later retry, with a single warning for the stage. No call is made to the unconfigured endpoint, so an unset key costs nothing rather than one failed request per source.
