One-member sources for signals grouping leaves ungrouped

Change

detect_signal_sources created a SignalSource only for an accessor pattern with at least min_instances members. A signal in a smaller pattern carried no source, and every mapping stage keys on a SignalSource, so such a signal could never be mapped. The function now runs a final pass: each signal the threshold leaves ungrouped becomes a one-member source keyed by the signal itself, with the signal as its representative, created through the function's own MERGE so the threshold is unchanged. The unused create_signal_source in imas_codex/discovery/base/grouping.py, which had no caller, is deleted; detection now owns source creation.

Measure

uv run --no-sync pytest tests/discovery tests/ids -p no:cacheprovider exits 0 — 1772 passed, 5 skipped, 4 deselected. New unit tests assert a lone signal forms a one-member source with itself as representative, and that a sub-threshold pattern forms no shared group.
