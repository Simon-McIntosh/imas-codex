EDDB unit spellings — parsing the catalogue's free text

The EDDB catalogue writes units as human text: letter case varies (KA, Mpa, DegC), digit exponents are glued to the symbol (m2, m3), and products are glued (Pam3). The alias file now resolves these without claiming a name instead use @alias: a case variant keeps the original offset unit, so 20 degC, 20 DegC and 20 oC each convert to 293.15 K. A glued form is a new unit carrying the canonical symbol, so a spelling and its native form collapse to one string. A bare n is not defined: it shadows the nano prefix's parse space and breaks count itself, so the neutron-yield spellings stay unresolved with a reason.
