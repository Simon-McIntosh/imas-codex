Enrichment context — ranking the prompt's code and wiki chunks by relevance

Signal enrichment fills its prompt with a handful of retrieved code and wiki chunks. Both fetches previously took the nearest embeddings as the relevant ones. Each now retrieves a 30-candidate pool above its existing score floor (parallel._fetch_code_chunks at 0.45, wiki.fetch_semantic_wiki_context at its caller's floor), passes the pool, the enrichment query and each candidate's text to judgment.rerank_pool, and keeps the reranked top k — 3 for code, the caller's k for wiki. When the rerank returns no ordering the fetch keeps the embedding order and logs why, because ranking is not a gate.
