One benchmark-harness compose call completes on the local seat

The benchmark harness compose call in imas_codex/standard_names/benchmark.py passed temperature=0.0 to acall_llm_structured. The production compose worker in imas_codex/standard_names/workers.py passes no temperature for the same seat. Every other parameter the two calls reach the provider with was already identical. With temperature=0.0 the local seat never returns within the shell's wall bound; with the parameter omitted the same request returns. The fix removes the argument, so the harness sends what production sends.

The two calls rendered through the shared kwargs builder (_build_kwargs), for one source (distributions/distribution/ggd/orbit_frequency_tor/values), comparator_block=True, 48,977 message tokens. Only temperature differs.

Sending each request once under the same shell bound, with identical messages, reproduces the defect at the parameter level: the production arm returned EXIT=0 in 266.3 s with 59,081 completion tokens; the harness arm did not return and was killed at 540 s (EXIT=124). The router was not congested for either (9 of 12 requests in flight, none waiting). After the fix the harness path itself — not a hand-built request — is the production request. Sent through _run_model with the fix in place and timeout 540, the fixed path returns every time: EXIT=0 at 390.4 s with 67,731 tokens and one candidate, and again at 142.3 s with 57,563 tokens and no candidates. The candidate count follows the model's own output; completion under the bound is the property the fix restores, and no batch errors were recorded in either run.

Gate tests/standard_names/test_benchmark*.py: 124 passed / 0 failed at head against 121 passed / 0 failed at base — the three added bounds tests are the whole delta, with no added failures. The bounds test fails with the fix reverted (EXIT=1, two failures: test_harness_compose_call_omits_temperature and test_harness_compose_request_matches_production), so the pass is not vacuous.

The brief framed the divergence as reasoning settings, bounds and timeout. Measured against the production call for the same seat, those three were already identical; temperature was the only parameter the harness set and production omitted, and it alone separates the two wall-time outcomes.
