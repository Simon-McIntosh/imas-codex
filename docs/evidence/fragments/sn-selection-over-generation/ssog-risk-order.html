Recall of known defects in a Jev risk order

For each golden item the named checks of its axis are read from the review taxonomy. A check's failure probability is its defect probability: a Noul's true-case probability, one minus a Choice's acceptable-form probability, or one when an audit finding class is present. The item's risk is the maximum over its checks, ties broken by the mean; the mean is carried as a sensitivity order. The incumbent order reads each item's stored review score lowest-first from the graph (reviewer_score for names, reviewer_score_docs for documentation).

Name axis: 28 Jev checks and 4 audit checks; the audit checks not decidable without a full catalog audit were excluded: duplicate_catalog_identity, grammar_round_trip_failure, lexical_convention_violation. The axis carries 737 name rows and the run assigns every one of them exactly one status: 718 reuse a frozen judgment, 19 were judged here to fill the gap, 0 were asked for here and returned no answer, and 0 carry no judgment at all. The four sum to 737 by construction, and the run does not stop judging until every pending name holds one of them, so a name cannot be asked for and then left out of the record. Documentation axis: 174 names, of which 32 reuse a frozen judgment, 128 were judged here, 0 were asked for here and returned no answer, and 14 carry no documentation in the graph; the four sum to 174 by the same construction. Each axis stores that status per id under status in the results JSON and the reason for each failure under errors; verify recomputes the four counts from those rows and fails if they do not sum to the axis total. The documentation composite omits the checks whose answer is a flag rather than a scored probability, so they contribute no defect probability: claim_contradicts_source. Spend: USD 0.002547 for the name gap and USD 0.017846 for documentation, 0.020393 in total, of a USD 0.50 ceiling.

The scorer's recall is checked against two orders whose recall is known in closed form: an order with every defect first must reach min(count, D)/D and one with every defect last max(0, count - (N-D))/D, at each read fraction. Every cell lands on its analytic value on all four golden and split pairs. A scratch copy whose recall is taken from the tail of the order instead of its head puts six cells per split off their value and exits non-zero, so a recall computation that stopped reading the order cannot pass the check.
