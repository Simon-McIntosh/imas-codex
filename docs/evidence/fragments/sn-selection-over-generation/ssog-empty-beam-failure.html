An empty beam is recorded as that item's failure

When every expansion for one slot fails, _search_slot yields no path for that slot and select_segments hands the missing slot to the render, which refuses a name with no physical base and records the refusal on that item alone. A test now drives select_segments with the decisions call stubbed so that one source's every call for the physical-base slot returns None while the same source's other slots and a sibling source all answer. The failed item carries the refusal naming physical_base and renders no name; the sibling item renders electron_density with no failure. The selection tests go from 4 to 5 passing at head, and the check fails when the hand-off is altered in a scratch copy to drop the missing-slot failure.
