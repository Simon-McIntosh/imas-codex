The benchmark harness carries the production comparator block and draws a named source list

BenchmarkConfig gains comparator_block (default off) and source_paths (default unset) in imas_codex/standard_names/benchmark.py. When comparator_block is on, _run_model builds the nearby-name block through the production helpers _collect_nearby_name_comparators and _rerank_comparators_for_compose in imas_codex/standard_names/workers.py, and passes it as nearby_existing_names the way production does, so the compose rerank switch now moves the harness prompt. Any rerank spend is charged to the model result's compose cost. When off, the rendered prompt is byte-identical to the base revision. When source_paths is set, _extract_candidates composes exactly those paths through the existing extraction.
