The documentation hold compares only against DD source text

Defect. _documentation_contradiction_note in imas_codex/standard_names/workers.py compares authored documentation claims with the DD text a name is bound to. Its fallback branch held a name whenever it carried any source path or binding, so a name whose sources are all derived names with no DD path — for which no DD text was ever fetched — was held with DD source text unavailable; claim comparison could not run. Documentation review clamps a held name below DEFAULT_MIN_SCORE, so the anchor comparison held 14 of its 15 rewritten members and halted after its first batch. Any later regeneration of a derived parent's documentation reaches the same branch.

Reproduction at the base revision (fe3c8b79e), driven through the function directly with the graph and the model stubbed, so the run spends nothing: power_of_divertor_due_to_recombination with source_paths=[] and one binding {source_type: derived, source_id: derived:power_of_divertor_due_to_recombination} returned 'DD source text unavailable; claim comparison could not run' (log repro_base.log). The same probe on a manual-only item returned the same note at base; the DD-bound items returned the missing-text note 'DD source text unavailable at equilibrium/time_slice/profiles_1d/psi'. After the repair the derived-only and manual-only items return no note and the three DD cases are unchanged (repro_head.log).

Change. The fallback now asks _has_dd_source_reference(item), which reports a DD source when _bound_docs_review_dd_paths yields a path, or when a dd:-prefixed entry appears in source_paths or among a binding's dd_path, source_id, path or id. The second clause matters because a binding of another source type can still carry a dd: path, and _bound_docs_review_dd_paths only consults source_paths when no dd binding exists. Everything else in the function is untouched: a DD binding whose text is missing or empty, and a dd:-prefixed source path with no binding, are still held, because for those the comparison genuinely cannot run.
