Why the name re-review did not go through sn edit as the brief preferred. No sn edit mode re-reviews a name in place: a --hint on the name axis enters GENERATE_NAME (a regeneration, which could respell the ruled name), --rename changes the spelling and its same-name form is refused ("a StandardName … already exists"), and --docs touches only the documentation axis; sn rescore refuses a drafted name ("rescore only recovers exhausted or reviewed names"). The pipeline's own rotation was therefore the only route that judges the name as it stands without renaming.

The third steering edit named the offending paragraph verbatim, and the paragraph came back anyway — because a writer re-inserts it. For this name the concept is outboard_midplane, and the appended text is character for character the paragraph the hint asked to delete.
