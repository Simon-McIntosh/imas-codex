Documentation regeneration refreshes its source snapshot

Generated and refined documentation now call stamp_source_snapshots(sn_ids=[sn_id], gc=gc) after a successful guarded write. The stamp copies the current producing DD source's path, unit, documentation, raw fields, and resolution provenance into the name's source_* snapshot. A mismatched claim never reaches the stamp.
