One check at the acceptance point

process_review_docs_batch calls conformance_findings, the same function the audit report uses, on the reviewed document before persist_reviewed_docs. A template_opening, forbidden_equation_variant, forbidden_locus_gloss or non_canonical_equation finding clamps the score below the accept threshold, as the link-label demotion does, so the name is refined. The finding text is appended to the review comments and recorded under registry_conformance in the per-dimension comments, which is what the refiner reads. The quorum score is untouched on a conforming document, and a forbidden-symbol finding stays out of the decision. A name the grammar cannot parse selects no registry entry and is accepted on score.

The non-canonical-equation finding

docs_gates.py gains NON_CANONICAL_EQUATION, produced beside the forbidden-variant check from the same selected concepts. A display equation is an equation for a concept when it performs the operation named on the left-hand side of the concept's canonical equation. It is then compared with that canonical equation token by token, spacing and sizing commands aside, the declared symbols standing for the quantity's own. A match is the converged statement and is never reported, whatever the entry's restates_equation value. Any other form is a finding, except one a forbidden variant already matches, which is reported once as that variant. All 21 live flux_surface_averaged_*_density_at_plasma_boundary documents write the average in a non-canonical form and each produces the finding; each of the 46 registered concepts' own canonical equation passes the matcher.
