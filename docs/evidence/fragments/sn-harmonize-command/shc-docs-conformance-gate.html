Reviewed documentation is accepted only if it conforms to the registry

The documentation axis accepted on the review score alone, so an opening that followed none of its selected templates, a forbidden equation variant, and an equation written for a concept the registry names and links all reached acceptance at a score of 1.0. The worker now decides those from the registry before it persists the review. One check at the acceptance point

process_review_docs_batch calls conformance_findings, the same function the audit report uses, on the reviewed document before persist_reviewed_docs. A template_opening, forbidden_equation_variant, forbidden_locus_gloss or restated_equation finding clamps the score below the accept threshold, as the link-label demotion does, so the name is refined. The finding text is appended to the review comments and recorded under registry_conformance in the per-dimension comments, which is what the refiner reads. The quorum score is untouched on a conforming document, and a forbidden-symbol finding stays out of the decision. A name the grammar cannot parse selects no registry entry and is accepted on score.

The restated-equation finding

docs_gates.py gains RESTATED_EQUATION, produced beside the forbidden-variant check. For a selected concept whose entry has restates_equation: false, a display equation is a restatement when it performs the concept's operation, identified by the operation commands on the left-hand side of the canonical equation (or the whole equation when the left-hand side names none), or when it contains the canonical equation. Spelling is immaterial: all 21 live flux_surface_averaged_*_density_at_plasma_boundary documents, which write the average in many forms, produce the finding. A concept with restates_equation: true is never reported, so the equation the registry requires is not penalised.

The prompt clause

For a concept with restates_equation: false the conventions block now reads "name the concept and link to it; write no display equation for it, in any form, and do not restate it in prose". The "unless needed to define this quantity" exception is gone.
