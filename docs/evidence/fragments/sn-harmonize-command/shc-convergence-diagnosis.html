Smallest deterministic route to one converged apply

  1. Enforce the written opening and equation at the docs boundary. Instantiate the selected density template with the member's subject and place the canonical flux-surface-average equation in one fixed form; reject or refine a generated document if either required passage is changed before acceptance. The current warning leaves 16/17 mismatches accepted, while restates_equation=False leaves all 17 forms free. A refusal alone prevents a false acceptance but cannot guarantee a one-pass result; deterministic insertion plus validation supplies it.
  2. Resolve link targets against the graph-wide name index in the report. The observed 19 targets are all valid. This removes a false convergence obstacle without deleting useful cross-family links. Write-time target validation would catch genuine inventions, but cannot repair this scoped-report counting defect.
  3. Pin the chosen anchor for a run and its continuation. Score ranking is legitimate for an initial choice, but resetting that member makes a replan select another. Persisting the run's choice would make recovery reproducible; it would not by itself fix openings, equations, or the neon halt.
  4. Add graph-wide link validation at write only if a real missing target reproduces. None of the 19 reported targets is missing, so this ranks last for this family.
