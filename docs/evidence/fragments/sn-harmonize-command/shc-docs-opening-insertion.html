Documentation writes use the selected opening and registry equation

The generation and refinement writers call one formatter before persistence. It uses conventions_context_for and AppliedConventions for selected templates and concepts, _template_opening_pattern and _opening_line for the opening, and _DISPLAY_MATH_RE, house_style_findings, and _is_canonical_equation from docs_gates.py for display equations. It substitutes a parsed subject or locus only when every template placeholder can be filled. The existing non-canonical and forbidden equation findings identify displays to replace with the selected concept's canonical equation. Concepts marked restates_equation gain their canonical equation when none is present; optional concepts gain none.

process_generate_docs_batch passes the formatted text to persist_generated_docs; process_refine_docs_batch passes it to persist_refined_docs. Registry content was read unchanged.
