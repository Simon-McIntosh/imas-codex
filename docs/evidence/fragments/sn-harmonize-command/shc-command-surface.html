One read-only family surface: sn harmonize

Replaces the family routes of sn run and sn review with one read-only report over pattern families. Write paths: imas_codex/cli/sn.py, imas_codex/standard_names/harmonize.py, imas_codex/standard_names/review/audits.py.

The report

  • sn harmonize takes exactly one scope of --batch <roster>, --family <seed>, --concept <id> or sn harmonize --all. Zero or more than one scope is a usage error (exit 2).
  • Per pattern family in scope it prints the members, the documentation anchor, the drift metric and the lint finding counts by class, then a scope total. --json emits the same rows as JSON.
  • Row assembly lives in harmonize.report_family_rows; the CLI only prints. The lint is the composition of audits.run_lint_checks (lexical, house style, documentation gates) plus audits.run_link_integrity — the report never calls run_all_audits, whose embedding preflight re-embeds and writes.

One family-enumeration mechanism

harmonize.fetch_pattern_families is the single family enumeration: it groups live names by the invariant grammar signature, with an optional seed filter and an optional member predicate. build_worklist's parentless bucket now delegates to it through _PARENTLESS_MEMBER_FILTER instead of carrying a second inline grouping, so the parentless bucket and the report list the same families. build_worklist is still the sn status drift surface; only its duplicate block is gone.

Deleted family routes

  • sn run --families — option and handler removed; the flag is now an unknown option (exit 2).
  • sn review --target groups — removed from the --target choice and its branch; --target now accepts names and docs only.
  • Helpers reached only by those routes: _refuse_grouped_review_scoping and _report_drifting_families in sn.py; mark_families_for_regen and lint_links in harmonize.py. Kept: mark_members_for_regen, assemble_family, restamp_harmonized_families.

Negative control

Declared mutation: point the report at run_all_audits and the no-write test fails. The command is exercised against a stub graph with the embedding preflight replaced by a raise; with the report on its own lint composition the invocation succeeds and no query writes. The negative control test swaps the report's lint for audits.run_all_audits and shows the same invocation now fails on the writing preflight — the guard is not vacuous.
