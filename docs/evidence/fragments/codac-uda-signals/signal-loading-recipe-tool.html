Why the example is executed and not only printed

Each test builds the example from the text the tool returns, so editing the served example without editing what runs cannot pass. The only step the test replaces is the archive transport, with a recorded reader receipt; the configuration, reader construction, bounded reads, cache write and array decoding all run as written.

Private host, selector and pulse values are held only in the run's private receipts and the private cache; the served text, the skill, the tests and this fragment use invented names.
