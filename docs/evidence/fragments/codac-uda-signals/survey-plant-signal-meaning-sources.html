3. Pulse and time-window requests

Files read: packages/iplotDataAccess/udaAccess.py, packages/mint/models/accessModes/mtAbsoluteTime.py, mtPulseId.py, and packages/mint/data/help/manual.md. The installed UI supports absolute time, relative time and pulse selection. The absolute-time model retains whole seconds and a separate nine-digit nanosecond fraction; the pulse model accepts comma-separated identities and start/end offsets with seconds, minutes, hours or days converted to seconds.

get_uda_params() accepts varname, pulse, nbp (default 1000), decType, tsS, tsE, tsFormat (default absolute), extremities and retType. convert_to_nanos() converts ISO strings containing a fractional second to UTC epoch nanoseconds. get_data_i() builds the following query shapes and the fetch methods pass them to UCR.fetchData():

variable=<selector>,tsFormat=<format>,decSamples=<count>,startTime=<ns>,endTime=<ns>
variable=<selector>,tsFormat=<format>,decSamples=<count>,pulse=<identity>,startTime=<seconds>S,endTime=<seconds>S

Optional fields append extSamples, decType and retType. A pulse end may be omitted. Pulse reads first resolve getPulseInfo2() for start/end and status; terminal number 0 means latest, and negative numbers step back from getLastPulse2(). Ongoing pulses use an end computed from the current time and bypass the completed-pulse cache. get_pulses_df(pattern="*:*/*") calls getPulses2() and returns six columns: Pulse, Time From, Time To, Duration, Status and Description. search_pulses_df(text) translates location/folder/number input to that pattern; get_pulse_categories() calls getPulseCategories(). This survey issued zero listings and makes no new pulse/category count claim.

Sampling semantics matter when reusing this language. Envelope reads set decType="env"; get_archive_window() tries a 100,000-point read and falls back on the specific server limit error to an envelope of 1,920 buckets unless overridden. The ordinary read path can add held boundary values and clamp pulse endpoints. A plotted MINT trace is therefore not automatically a record of untouched native samples.

4. Processing expressions an agent can share with MINT

Files read: packages/iplotProcessing/tools/parsers.py, default_modules.json, core/signal.py, core/bobject.py, math/pre_processing/grid_mixing.py, packages/iplotlib/interface/iplotSignalAdapter.py and the manual. The packaged module list has 2 entries, numpy as np and scipy.*, and 0 user entries. IPLOT_PMODULE_PATH selects an alternate default_modules.json; it is not a signal catalogue.

Parser.set_expression(), replace_var(), substitute_var() and eval_expr() implement Python expression evaluation with ${selector-or-alias} references. A bare reference selects .data; .time explicitly selects time. Envelope references select .dmin, .dmax or .davg. Invented examples are ${input_a} + ${input_b}, ${input_a} * (-2) + 10, np.max(${input_a}.data) * np.ones(${input_a}.data.size), and ${input_a}.time - 5s. Time literals become NumPy timedeltas. Variable, x, y and z columns can carry expressions; x/y allow value-versus-value plots. An input with an empty stack can feed an expression without being drawn.

Arithmetic, array indexing, reductions and imported NumPy/SciPy functions are the useful common language. The parser rejects **, text containing for or if , double underscores and several empty literal/call forms, then checks compiled names against injected members. Do not infer expression support from all the operator overloads on Signal: the parser's narrower validation is also applied.

Unequal time bases are aligned on their union. Although the manual describes previous-value interpolation, the installed ParserHelper.resolve_alignment_kind() uses an explicit signal preference first, then in automatic mode chooses linear only when every dependency is raw and has an observed rate of at least 100 Hz; otherwise it chooses previous-value interpolation. This is an observed-rate heuristic, not an archive sampling-kind declaration. BufferObject.__array_ufunc__() clears result units, so derived units need an explicit decision. These are source-level findings; no processing expression or live read was evaluated.

from collections import Counter
from hashlib import sha256
from html.parser import HTMLParser
import json

class SurveyRecord(HTMLParser):
    def __init__(self):
        super().__init__(convert_charrefs=True)
        self.stack = []
        self.blocks = {}
        self.metrics = []
        self.series = []
        self.headings = []
        self.headers = []
        self.paragraphs = []
        self.roots = 0
        self.ranked = 0
        self.tables = 0

    def handle_starttag(self, tag, attrs):
        attrs = dict(attrs)
        if tag == "table":
            self.tables += 1
        if tag == "li":
            self.roots += any(a.get("id") == "meaning-search-roots" for _, a, _ in self.stack)
            self.ranked += any(t == "ol" for t, _, _ in self.stack)
        self.stack.append((tag, attrs, []))

    def handle_data(self, data):
        for _, _, parts in self.stack:
            parts.append(data)

    def handle_endtag(self, tag):
        if not self.stack or self.stack[-1][0] != tag:
            raise ValueError("Unbalanced HTML at " + tag)
        _, attrs, parts = self.stack.pop()
        text = "".join(parts).strip()
        if "id" in attrs:
            self.blocks[attrs["id"]] = text
        if "data-meaning-metric" in attrs:
            self.metrics.append((attrs["data-meaning-metric"], text))
        if "data-meaning-series" in attrs:
            self.series.append((attrs["data-meaning-series"], text))
        if tag == "h4" and text[:1] in "123456" and text[1:3] == ". ":
            self.headings.append(text)
        if tag == "th":
            self.headers.append(text)
        if tag == "p":
            self.paragraphs.append(text)


def check_survey(document):

    record.feed(document)
    record.close()
    if record.stack:
