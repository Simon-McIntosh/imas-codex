Fixed-hash hand reading and freshness limits

The sample is the thirty entries whose UTF-8 name SHA-256 digests sort first in ascending order, with name as a tie-break. No substitution was made. Informative means the description identifies a physical quantity, equipment state, configuration field or operational role beyond an opaque identifier. Generic includes a repeated code/selector or an unqualified analogue-input label. Wrong means an observable contradiction with the name, unit or type. The result is 21 informative (70%), nine generic (30%), zero demonstrably wrong; it is not an engineering-drawing validation or a guarantee about unsampled entries.

The response records insertion and update timestamps on all 2,912 rows, spanning 2026-08-04 to 2026-11-09. There are four distinct insertion timestamps and four distinct update timestamps; two rows have an update timestamp different from insertion. These are per-record stamps without an explicit timezone. The payload has no version or refresh schedule, and the HTTP response supplies neither ETag nor Last-Modified. Its Date header timestamps this request only. There is evidence of recorded updates, but automatic refresh cadence, current completeness and a versioned feed contract are not established.
