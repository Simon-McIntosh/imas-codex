Bounded graph-identity signal loading with sampling evidence

imas_codex.remote.codac_uda.ArchiveSignalLoader resolves a FacilitySignal through its DATA_ACCESS binding, data source and HOSTED_BY_ARCHIVE endpoint. It resolves graph pulse identities to bounds, then uses ArchiveReader and the facility-aware run_python_script wrapper to run the packaged reader. The same reader's check method supplies the catalogue validity path; no prototype subprocess bridge or graph template is executed.

The result contains typed time/value arrays, signal identity, unit, description, time base, issued queries and sampling evidence. Raw reads report decimation as unknown unless an independent cadence check supplies evidence; envelope and binned results report aggregation. String-valued record fields are retained. Request-keyed atomic caches include archive, endpoint, selector, bounds and sampling settings, and configured budgets apply before cache lookup or reader execution.
