Most pulse category names carry a plant code in a whole delimited part, and no hand-read category named the wrong system

The graph holds 744 pulse categories, and every one was read. Each name was split into its maximal runs of letters and digits, so a hyphen, colon, underscore, space or punctuation character separates parts. A part that equals a plant code already in the graph is a delimited match; a code that occurs only inside a longer part is counted separately and never as a delimited match. The measurement interprets no code and writes no link.

711 of 744 names (95.565%) carry a plant code as a whole delimited part, so a rule on delimited parts would link that share. Seventeen names carry a code only inside a longer word, and sixteen carry no code at all. Those three groups partition every category, and the second and third are the negative control for the first: a rule that widened to inside-word matches, or that split on too few characters, would move categories out of the first group, and the figure shows the small sizes the rule avoids.

Hand reading of a sealed sample

Twenty categories the delimited rule would link were chosen before any verdict, stratified so every carried code is represented, and written to a private file. Its SHA-256 is f9c782a1cb2a636ac95237bff7178bfbcdc64ba7fc41766a2e3c4eaf425f5158. Each was read against its pulses' own descriptions, with one verdict and reason recorded privately, and no substitution was made. The reading judged 5 right, 0 wrong and 15 undecidable.

No sampled category's pulses named a system other than the one its name's code names, so the rule produced no wrong link in the twenty. The reading's power is limited by the descriptions themselves: fifteen of the twenty pulse descriptions are test labels or bare words, so they identify no plant system and the verdict is undecidable rather than a confirmation. The twenty support the claim that the rule did not name a wrong system; they do not establish that it names the right one in most cases.

What was and was not changed

The measurement writes zero links and changes zero search behaviour. The only product change is a module of pure functions that classifies a name and counts the results, plus its tests; nothing reads it at runtime. No real host, category, pulse, variable, description or code name appears in any tracked file, test, report or commit message: the tests use invented names, and the real per-category table, sealed selection, verdicts and descriptions live only in a private directory outside the repository.

The focused tests pass. The deliberate negative control counts an inside-word occurrence as a delimited match and collapses two delimited codes into one; the committed classifier fails four of them, and the log is named by the manifest.
