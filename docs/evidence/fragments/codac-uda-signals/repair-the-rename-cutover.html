1. Evidence keeps its data and prose bytes, and its Python is renamed

docs/evidence is now a kept path with "include": ["*.html", "*.json", "*.md"], the same split already made for docs/figures, where the rendered figure and its raw measurement JSON are kept and the figure script is renamed. The measurement is the reason: 186 Python files live under docs/evidence, 152 of them import the package by its old name at module level (731 import lines), and together they carry 1,219 old-name hits. Under the old kept entry every one of those bytes stayed behind while the package they import disappeared.

Two consequences follow, and both are now guarded. First, the closing search counts a hit in a Python file under docs/evidence as a leftover rather than as kept evidence: with the corrected list, a planted docs/evidence/fragments/probe/planted.py containing from imas_codex.graph import GraphClient is reported as leftover: docs/evidence/fragments/probe/planted.py: 1 old-name hit(s) in a covered file and check exits 1. With the include removed from the same entry the identical planted file is absorbed into the kept total (kept 196,030, leftover 0) and check exits 0 - the defect, reproduced. Second, narrowing an include would have let the rename pass move a directory under docs/evidence whose name carries the project name (docs/evidence/imas-codex-s10 and docs/evidence/imas-codex-replan both exist and hold kept prose), relocating the kept bytes it holds; the pass now refuses to move any directory whose subtree holds a file the kept list covers.

The open question: why the rehearsal's renamed arm added no failure

None of the four suspected causes holds: the arm did run the tests, and the tests that load evidence code load scripts that never import the old package name. The tests that load or reference docs/evidence are 18 files; run on both arms they report 286 passed, 4 skipped, 35 deselected with the same identifiers and exit 0. Two of those files execute an evidence script by path:

  • tests/standard_names/test_anchor_ab_aggregate.py - 13 tests, all pass in both arms. It loads docs/evidence/fragments/sn-selection-over-generation/ssog-anchor-ab-aggregate-run.py at module import; that runner imports only argparse, json, os, pathlib and time and is not among the 152 that name the product.
  • tests/standard_names/test_rerank_label_sheet.py - 3 tests skipped at lines 66, 95 and 124 by the module-level skipif ("archived evidence runner is bound to its recorded revision"), so the runner it would load is never imported. The fourth skip is the whole of tests/docs/test_documentation_layout.py, at line 5, because reckon is not installed in the arm's environment.

None of the 45 failures on the base arm is a test that references docs/evidence; the 35 deselected items are the default markers' graph and slow exclusions, and the same 35 are deselected in every arm. So the answer is not "deselected", "skipped in the way that hides a load", "already failing" or "not run": the collected tests ran and passed. The 152 evidence scripts that do import the old name (731 import lines, 1,219 hits) are not collected tests at all - they are owner-run gate scripts, and the default tier never executes them. The result therefore holds, and it was never evidence that the kept list was safe.

The kept-evidence arm proves it directly: with all 186 pre-rename evidence scripts restored into the renamed tree, the same 18 files report 286 passed, 4 skipped, 35 deselected - identical to the corrected arm - while check reports 1,206 leftover hits in 172 of those restored files and exits 1. Deleting the restored scripts returns check to exit 0.
