Roles decided across the plant from the field-code table

The ITER catalogue holds 97,525 archive signals in the graph, 30,031 of them carrying a field code. The closed-vocabulary assignment that ran on the 1,766-signal pilot system now runs over all 97,525, with the field-code table as the field-pattern source for the role axis. Values are stored only where a source states them: a linked signal-list row, the controls metadata a signal carries, the unit the archive reports, or the table's entry for the signal's field code and component kind. Each axis carries one outcome per signal, and on every axis the decided, in-conflict and undecided counts sum to 97,525.

Quantity and unit keep their population consensus, so the quantity column credited to the field-code table is that consensus, not the table.

Signals decided as each role

Of the 1,732 signals whose role is decided, 1,436 are measurement, 101 state, 86 command, 63 setpoint and 46 alarm. The setpoint count is a property of the sources rather than a target: the table states a setpoint role for seven of the forty codes it examined, and those seven codes decide 56 signals; the controls metadata states a setpoint for 7 more.

The readings that could have failed

  • Every one of the 29 pilot values this section changed was listed privately and read by hand against the signal's own sources: 29 verdicts, all right, 0 wrong. The file carries one written verdict and one reason per value, and the reasons name what the own source does and does not state.
  • The sample of newly-decided roles was drawn before the storing run and written to a private file whose digest is b9619b6e2cf91aa44aef87ad92a33fe5ad8f0b80f98ecbc3c26f33cb30590997. It holds ten signals credited to the controls metadata and ten credited to the field-code table, which is every source that credits a newly-decided role: no signal-list row credits one. The storing run recomputed the sample and its digest is unchanged. Twenty signals were read by hand, one verdict and reason each: 20 right, 0 wrong, against the allowance of two wrong.
  • The reading is not a script. A file with one identical reason for every item, an empty reason, an omitted item or a verdict outside the three admitted values is refused. Six tests cover it, five of them refusals; the same file reloaded from JSON is still refused.

Checks that could have failed

  • The write stored 96,348 signals in 482 batches; a read-back compared 6,201 assigned values with the assignment and found 0 mismatched. A second assignment read the catalogue again, reassigned it and reported 0 changed signals.
  • The 2,114 decided units were compared with 3,157 source spellings through the shared unit authority: 0 disagreements, so two spellings of one unit (KA against kA) agree. A unit written two ways does not become a conflict.
  • The catalogue holds a setpoint: 56 signals in one plant system and one in another. A server search for the setpoint role on the system holding 56 returned 56, every item carrying the role, and a search on a system that holds none returned 0 with an empty page.
  • The unit arm passes at revision dfb280edb70c: 69 passed, 1 warning in 5.54s over the assignment rules, the store path and the reading machinery. The count is the whole selection the arm names, and every test in it is one this section adds or extends.
  • The graph-marked statements pass at revision dfb280edb70c: 14 passed, 1 warning in 54.75s, including the catalogue read and its control query, the table-driven write, a code without a table entry storing no role, a repeated assignment changing nothing, the role filter and its MCP route.
  • Removing the table as the role source and falling back to the population consensus fails two tests that pass at the unmutated head, and the failing ids are recorded in the negative-control log.
  • The declared negative controls hold: a signal whose code has no table entry and no other source stays undecided (a unit test and the 226 catalogue codes with no entry); a pilot value contradicting its own source is reported as changed (a unit test drives a hand-changed value through the comparison); and a scripted reading file is refused.
  • The changed and added tracked files were searched for real signal identities and for the archive's accession prefixes: no signal name, accessor, or document identity appears. The private receipts and both readings files live outside the repository.

What stays undecided

95,793 roles and 95,167 quantities have no source that states them. The controls feed describes many channels only as an analogue input or a signal value, the signal list has one row per component, and the table establishes an entry for 33 of the catalogue's 259 field codes. The rule fills none of that gap with a default: a code the table does not establish and no other source states leaves the role undecided, which is what the negative control requires.
