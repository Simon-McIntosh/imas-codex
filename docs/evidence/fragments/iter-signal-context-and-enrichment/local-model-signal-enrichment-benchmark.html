Sample and execution

The sample contains 200 already-enriched JT-60SA signals, selected before either arm in round-robin order over 26 stored physics domains. Each has a nonempty catalogue source description. Twenty ten-signal batches passed through the production enrichment worker with its normal facility configuration, tree, wiki and code retrieval. All twenty prompts contained catalogue descriptions, wiki retrieval and code retrieval; none contained tree-node descriptions. Stored model-written names, descriptions, keywords and classifications were removed from the model inputs.

The normal-context pass ran once and its exact final messages were frozen. Every local and paid batch has the same prompt digest as its corresponding context batch: all forty comparisons passed. Both arms used the same temperature, token bound, timeout, schema, result matching and context. Only the description seat's environment override changed. Graph write, claim, propagation and role sinks were replaced with private sinks, and the replay's graph client rejects mutation queries. All measurement jobs ran on rigel.
