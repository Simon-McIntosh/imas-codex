Closed vocabulary on the pilot signals

1,766 ITER pilot signals carry a quantity, unit and role decided by rule from four sources in precedence: a linked signal-list row, the controls metadata the signal carries, the unit the archive reports, and the field pattern of the signal's name. Each axis has one outcome per signal; the three outcomes on an axis sum to 1,766.

The vocabulary

Quantity (16): current, voltage, temperature, pressure, flow, valve_position, position, resistance, strain, frequency, energy, force, power, speed, duration, ratio.

Unit (22): kelvin, degree_celsius, volt, ohm, millibar, bar, megapascal, ampere, kiloampere, millimetre, percent, gram_per_second, kilogram_per_minute, millisecond, microsecond, second, kelvin_per_hour, microstrain, kilovolt_ampere, hertz, kilowatt_hour, newton.

Role (5): measurement, setpoint, state, alarm, command.

Outcome (3): decided, conflict, undecided; exactly one holds per axis per signal. Source (4), in precedence: signal_list_row, controls_metadata, archive_unit, field_pattern.

A dash marks a source the axis does not consult: the archive unit gives the unit only, as the plan declares. Of the 190 signals with a linked row, 225 rows are attached; a row states a value only when the link names the selector, the component has one row, or the row carries the signal's own field code, so a sibling channel's row cannot decide a signal.

Why the field-pattern rule is not a guess

The field-pattern source reads the population: other signals that share the field code contribute the value their own sources decided, and the pattern states a member only when at least three of them agree unanimously. The signal itself never contributes, so no value is supported by itself. Where the pattern disagrees with a signal's own source the result is a conflict — the four quantity conflicts and one role conflict are that case, plus two unit conflicts between controls metadata and the archive unit.

Checks that could have failed

  • 1,156 decided units compared against 2,188 source spellings through the shared unit authority: 0 disagreements. A source writing the same unit another way (KA against kA) agrees rather than conflicts.
  • A second assignment wrote 0 signals and changed 0; the write sets all nine slots explicitly, so a member that no longer applies is removed rather than left behind.
  • 108 values read by hand (sample digest c7d7be9f6c2a6b1cc479656a945f87ca2364067d4d03b69d2eecc466238ec738, chosen before the run): 15 per credited source and axis, 3 where fewer. 0 disagreements.
  • A served search for quantity current and role command returned 20 signals, all 20 carrying both and all inside the pilot; the same query unfiltered returned 20 of which 0 carried both, so the filter changes the page it serves.
  • Mutating the assignment to guess a default member and to resolve a disagreement silently fails 16 of 40 tests in the two vocabulary suites, including the declared negative controls.
  • 2,792 real accessors, component codes, document titles and row prefixes searched across the tracked tree: one match, the generic function-category phrase "Temperature Transmitter" in a pre-existing fixture, and no signal name, component number, document identity or row content.

What stays undecided

1,020 quantities and 1,563 roles have no source that states them: the controls feed describes many channels only as an analogue input, a field code or a signal value, and the signal list has one row per component rather than one per archive variable. The rule set does not fill that gap with a default; a signal absent from the feed, the row and a unanimous pattern stays undecided until a source states the value.
