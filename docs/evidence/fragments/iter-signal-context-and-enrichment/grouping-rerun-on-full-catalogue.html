The statement that performs the retirement is not part of persist_archive_grouping: the module's own RETIRE_UNUSED_GROUPS_QUERY strips pattern links from unreferenced components but keeps the pattern node, which is why the product-only arm stays red. The re-run retired the nodes through the statement below, logged at grouping-measure.log, and the product change is reported for a follow-on dispatch rather than worked around silently.

MATCH (p:ArchiveFieldPattern {facility_id: $facility})
WHERE NOT EXISTS {
  MATCH (:PlantComponent)-[:HAS_ARCHIVE_FIELD_PATTERN|HAS_ARCHIVE_CATEGORY_PATTERN]->(p)
}
WITH collect(p) AS stale
FOREACH (p IN stale | DETACH DELETE p)
RETURN size(stale) AS deleted
