Reproduced defects and guard evidence

The archived defect reproduces as an unsupported pressure-transducer and gas-circuit interpretation of DCSV/ppDIVL, whose catalogue says “Lower Diverter Control PT(DIV_L)” and whose data class is binary. The reused paid description preserves a lower-divertor control-point configuration payload. The new holdout has the same failure pattern: CryoMag/m1E4D01 is described as radial displacement at EF04–TF ST01, but the local baseline invents a strain gauge and turns EF04 into a toroidal-field coil; the supported alternative retains the source identifiers and displacement in millimetres.

The optional citation guard assembles descriptions only from statements with nonempty references to supplied context items. It checks reference existence, not semantic entailment. A separate optional local pass removes or corrects draft statements against the same context. Drops, revisions and sentence-limit removals are counted separately. Other seats keep their request behavior; the default call path preserves description text and messages exactly.

A real citation response returned bracketed references such as [context-185]. The initial guard incorrectly recognized only the unbracketed form.
