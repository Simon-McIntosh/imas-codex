JT-60SA path judgment prototype

The preassigned sample has 142 labelled JT-60SA paths: 70 under /analysis, 66 under /home, and six under /work. Labels mark facility-relevant code, data, documentation or a directory worth exploring as positive; generic utilities, build artifacts, empty directories and historical archives are negative. The 136 graph rows have both Jev answers and a stored language-model composite (118 positive, 18 negative). The six /work rows came from bounded listings on intr26-2: /work/edas links to /home/ap/EDAS_work, where four per-shot directories were observed. They have Jev answers but no stored composite, so the paired AUC and threshold table exclude them.

Each path received one Jev decision with the schema-derived path_purpose Choice, eleven facet Scores, and a children-worth-listing Noul. All 142 calls returned all 13 answers. The exploratory code/data scan gate is the maximum of nine Score positions divided by their top level; it excludes the visualization and documentation Scores, and leaves the children Noul for expansion. On the 136 paired rows, gate AUC is 0.807 against 0.677 for the current stored language-model composite. Jev AUC on all 142 labelled rows is 0.799. The gate definition was selected on this sample, so these figures need a separately labelled validation set before deployment.
