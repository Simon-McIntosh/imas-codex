The change

The signed supersede postcondition matched only the edge whose target was the signed successor and grouped its rows by receipt_id. The successor relation is also rebuilt from the superseded_by scalar, so a predecessor can carry a second, unstamped HAS_SUCCESSOR edge beside the signed one. The grouped query returned one row per distinct receipt_id, each with count = 1, and the check read whichever row came first — so "exactly one successor edge, carrying this receipt" was not enforced. The query now counts every HAS_SUCCESSOR edge from the predecessor, without grouping, and requires the single edge to carry the minting receipt's id.
