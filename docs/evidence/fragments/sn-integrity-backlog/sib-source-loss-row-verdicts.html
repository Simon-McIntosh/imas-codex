How a row is judged

  • unverified loss — no live holder and matching units, but the path's description does not carry the name's words, or the path list came from an ancestor's entry. No rebind is proposed; the lead reads both descriptions.
  • questionable move — a live name outside the lineage holds the same path with agreeing units; the row carries the one-sentence question the lead must answer.
