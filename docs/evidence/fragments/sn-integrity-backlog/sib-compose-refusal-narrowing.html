sib-compose-refusal-narrowing — two over-broad error paths in the compose batch

The batch-isolation repair stopped one bad candidate from discarding a paid response, but it caught more than the failure it was written for. Two error paths were broad enough to swallow outcomes they did not own: the per-candidate grammar catch took every Exception, and the compose call wrapped acall_llm_structured in a second retry loop of its own. The first retired a source for a defect in this code; the second multiplied the LLM layer's attempt bound by its own, so one transport fault could cost twenty-five attempts and about six minutes of backoff per batch.

The compose catch now names the two failures a malformed proposal actually produces: the ValueError from the ISN round-trip and pydantic's ValidationError from the candidate model. A ValueError is still recorded on its own source and the batch's valid siblings still persist. An AttributeError from the composer is this code's defect and now leaves compose_batch, so the batch is recorded as failed instead of retiring a source for a reason that is not about the source.

The duplicate transport loop is gone. acall_llm_structured decides a fault by type before reading its message, using the module's own _transient_transport_errors() set, so a httpx.ReadError with an empty message and a bare httpx.ConnectError are retried inside the loop that already bounds the attempt count. The fault set is read from its owner rather than restated, so the two seams cannot drift.

Evidence. The new tests fail on the base revision and pass at the change. At base a0a536030, with the two test files placed over it, three tests fail: the AttributeError propagation test and both parametrised transport-retry tests; the ValidationError recording test and the deterministic-error test pass at base, since they pin behaviour the repair must not lose. At head 1a2238e4b all six pass. The declared negative control restores the bare Exception catch on the head tree: exactly one test fails, the AttributeError propagation test, which is the guard this node adds.
