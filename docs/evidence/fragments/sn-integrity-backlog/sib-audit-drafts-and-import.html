sib-audit-drafts-and-import — the audit reports sourceless drafts; the import binds every published leaf

The source audit split live sourceless names into two buckets, dormant (exhausted) and blocking (everything else), so a live draft with no producer either refused a release it could never affect or went unreported. The split now follows whether the stage ships. A name in accepted or approved still blocks the cut; a draft is listed on the report with its stage and leaves the release outcome alone, because a draft does not ship. The reported set is confirmed through find_sourceless_live_names, so the audit and a refused write agree on what "sourceless" means.

The catalog import bound only each entry's single source_id, and only for dd or signals types. It now binds every published DD path an entry carries, read from source_id and from the union list in source_paths. A STRUCT_ARRAY resolves to its /values leaf and a STRUCTURE to its single component leaf, the reduction the extraction path applies; both run inside the pairing read the writer already issued, so a write costs no extra query. Each bound leaf carries its StandardNameSource, its PRODUCED_NAME edge and its FROM_DD_PATH edge, which is what makes the name genuinely sourced rather than only projected. A path that cannot be bound is returned on the write result (unbound_paths, reason no_bindable_leaf or attachment_refused) and logged, never dropped.
