A claim is vetoed only when no binding supports it

The veto misfired one layer above the clause. The review-docs note built one judgment state per DD source and returned a hold when any single source set contradiction_veto, so a base name spanning seven bindings had its three scope sentences answered seven times, once per narrow binding, and the answers were ORed into a hold. The clause now asks one question per (claim, binding) and folds the readings by support: a claim contradicts only when no binding supports it, and any unanswered binding leaves the claim unknown.
