What the property means

The slot is now declared on StandardName as an optional boolean, described by its lifecycle rather than by the plan that motivated it: true while the name is a structural parent placeholder that still waits to be composed from its children, cleared to null once the derived-parent materializers write its composed content. Absent or null means no composition is outstanding. The three repository readers agree with that reading — the HAS_PARENT edge pass sets it for projection, coordinate and unary-postfix operators on a name whose name_stage is still pending; both derived-parent materializers clear it as they write the parent's content; the placeholder-stub deletion requires sn.needs_composition = true before removing a bare parent; and the orphan sweep selects on sn.needs_composition IS NULL.

The adjudication row is gone
