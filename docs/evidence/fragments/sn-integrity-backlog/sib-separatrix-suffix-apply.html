Separatrix name convention — applied

The lead ruled one suffix per data-dictionary locus (comment c-s49-lead-ruling-convention): a value at the separatrix is X_at_plasma_boundary; a separatrix average is flux_surface_averaged_X_at_plasma_boundary. This record applies that ruling through the sanctioned rename writer (imas_codex.standard_names.edit.apply_edit), which mints the successor, supersedes the predecessor, carries the producing sources and raises if any source is left behind.

Method

Locus is derived from each name's producing DD path, not from the census's locus label. That matters for one row: the census labels normalized_toroidal_flux_coordinate_at_plasma_boundary a diagnostic distance although its only path is summary/local/separatrix_average/position/rho_tor_norm, a summary path and the average locus. Deriving from the path puts that name under the same rule as its sibling.

Tritium — retire and compose blocked on a lineage conflict

The ruling retires the bare toroidal_tritium_velocity stub with a signed receipt and composes toroidal_tritium_velocity_at_pedestal_top and toroidal_tritium_velocity_at_plasma_boundary. The graph does not allow the second target to be composed: it is a superseded tombstone whose lineage runs four links deep,

toroidal_tritium_velocity_at_plasma_boundary
  → toroidal_flux_surface_averaged_tritium_velocity_at_plasma_boundary
  → toroidal_tritium_velocity_flux_surface_averaged_at_plasma_boundary
  → flux_surface_averaged_toroidal_tritium_velocity_at_plasma_boundary (live)

and every link terminates on a name at the average locus. Composing the separatrix value under the ruling's spelling would revive a tombstone; composing it onto the live tip would file a local value under an averaged name. Both are forbidden by this section's own constraints, so the retire-and-compose is reported for a ruling instead of written. The bare stub is still live and still carries both paths.

Live read-back

The graph was re-read after the apply: 86 of the 98 census names now end in the ruled suffix for their own DD locus (separatrix 33/40, separatrix_average 39/44, unresolved 8/8, mixed 4/4, diagnostic 2/2). The twelve that do not are the rows above. A separate observation: the live graph holds 118 names whose id carries separatrix or plasma_boundary against the census's 98 — the census bounded its population by produced source path, and that gap is recorded here rather than resolved.
