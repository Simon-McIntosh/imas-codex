Method and caveats

  • Compose calls follow the queue (remaining sources / configured batch size 25); every other phase's call count is the measured 90-day calls-per-distinct-name ratio applied to the expected name count.
  • The 30-day window holds 738 LLM calls across 70 runs and cannot support per-name ratios on its own (one phase has 6 distinct names); it is reported because the brief names it, and the 90-day window is the basis for the projection.
  • SNRun.names_composed under-reports throughput: the 30-day counter sums to 3 while 9 names were created in the same window. Throughput therefore uses names created, not the counter.
  • The two yield arms bracket reuse: the catalog arm assumes new sources mostly bind to existing names; the window arm assumes fresh names.
  • No write and no LLM call: USD 0. Every number is a graph read plus the dry-run log.
