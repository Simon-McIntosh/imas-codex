The two mechanisms

Per-candidate grammar refusal. compose_name() is now called behind a guard. A refusal is recorded on its own source through the existing pre-validation failure path — status failed, last_error carrying candidate pre-validation failed (grammar validation: <validator message>): <base token>, and the claim token and sequence from the batch item — and the candidate is dropped. The guard sits where the exception was already leaving the function, so the sibling candidates from the same response still reach the persist step.

Transport fault. The compose call now runs through _acall_retrying_transport_faults, which retries httpx.TransportError (covering ConnectError, ConnectTimeout and ReadError) under the LLM retry policy already in use elsewhere — DEFAULT_MAX_RETRIES attempts at DEFAULT_RETRY_BASE_DELAY doubling each retry, both imported rather than restated. The fault needed its own retry because acall_llm_structured decides retryability from the error message: ReadError carries an empty string and ConnectError a host phrase its patterns do not match, so the exception left that loop on its first occurrence rather than being retried inside it.
