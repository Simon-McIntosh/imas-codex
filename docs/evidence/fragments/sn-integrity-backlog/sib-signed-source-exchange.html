Signed DD source exchange

The dd-source-exchange adapter in signed_manifest.py accepts a canonical authority built by build_repair_authority. Every signed row names a live giving name, its current DD producer, a DD producer to take, and optionally a live name to receive the given source. The caller supplies both trusted authority digests and the exact guard set. Preview derives a transaction-local graph closure and a manifest digest; apply re-derives and compares that closure before writing.

Refusals and postconditions

A row is refused before any write when the giving name is absent, exhausted or superseded; its given source does not produce exactly that name; the taken DD path is absent or removed from the current DD; the taken source node does not exist; a live name already holds the taken source; the receiving name is absent, exhausted or superseded; or the given DD path is absent or removed when there is a receiver. A taken source with any existing producing edge is also refused, since it cannot meet the exact ownership postcondition. Overlapping signed rows and an authority digest mismatch refuse before graph mutation.

The single transaction binds the taken source to the giving name, detaches the given binding, optionally binds the given source to its receiving name, records one StandardNameChange per row, then checks every touched name has a producer, the resulting source ownership is exact, and the shared require_producing_sources invariant holds. Without a receiver, the given source is left unbound and extracted. Any failed check rolls back the bindings, source state and receipt together. An applied row's deterministic change id makes replay a write-free refusal.
