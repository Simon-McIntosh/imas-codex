How many chain-cap identities have no sourced ancestor now

Re-derived read-only on the live graph through imas_codex.graph.client.GraphClient from the run worktree, against the active codex graph. No mutation was performed: every statement is a MATCH/count. The definitions are reused verbatim from the 2026-09-01 record (unsourced-ancestry.md) and the 2026-09-17 re-measure (unsourced-cohort-partition.md), so the numbers are comparable:

  • chain-cap — sn.chain_length >= 3.
  • unsourced — NOT EXISTS { MATCH (:StandardNameSource)-[:PRODUCED_NAME]->(sn) }.
  • has a sourced ancestor — EXISTS { MATCH (sn)-[:REFINED_FROM*1..10]->(a:StandardName) WHERE EXISTS { MATCH (:StandardNameSource)-[:PRODUCED_NAME]->(a) } }.

Every query names its row set (the StandardName label, filtered by chain_length and the unsourced predicate); the ancestry walk is depth-bounded at *1..10, which the short REFINED_FROM chains never reach. Counts are identity counts, not row counts: the producer and ancestry predicates are expressed as EXISTS subqueries, so each StandardName contributes exactly one row.

The bounded queries

// chain-cap total
MATCH (sn:StandardName) WHERE sn.chain_length >= 3
RETURN count(sn)  -- 174

// unsourced (independent total)
MATCH (sn:StandardName) WHERE sn.chain_length >= 3
  AND NOT EXISTS { MATCH (:StandardNameSource)-[:PRODUCED_NAME]->(sn) }
RETURN count(sn)  -- 102

// has a sourced ancestor at any depth (depth bound 10)
MATCH (sn:StandardName) WHERE sn.chain_length >= 3
  AND NOT EXISTS { MATCH (:StandardNameSource)-[:PRODUCED_NAME]->(sn) }
  AND EXISTS { MATCH (sn)-[:REFINED_FROM*1..10]->(a:StandardName)
               WHERE EXISTS { MATCH (:StandardNameSource)-[:PRODUCED_NAME]->(a) } }
RETURN count(sn)  -- 10

// has no sourced ancestor at any depth
MATCH (sn:StandardName) WHERE sn.chain_length >= 3
  AND NOT EXISTS { MATCH (:StandardNameSource)-[:PRODUCED_NAME]->(sn) }
  AND NOT EXISTS { MATCH (sn)-[:REFINED_FROM*1..10]->(a:StandardName)
                   WHERE EXISTS { MATCH (:StandardNameSource)-[:PRODUCED_NAME]->(a) } }
RETURN count(sn)  -- 92

Result

102 unsourced chain-cap identities: 10 with a sourced ancestor, 92 with none. The 2026-09-01 figures (78 unsourced, 72 with none) have drifted; the live graph now matches the 2026-09-17 re-measure exactly (174 / 102 / 10 / 92), so the population has been stable since 2026-09-17. The ten "has a sourced ancestor" identities are unchanged from that re-measure's list. Every query finished in under 0.07 s, far below the ten-second ceiling, and the split closes against the independent total.
