Landing record: the export accounting the C4 tests disagree with

The five C4 ids pass at head. Four of them were not stale assertions at all: the export entrypoint itself was broken. run_export reaches the source audit through the storage layer, whose collaborators come from a composition root installed only when graph_ops is imported. Invoked as an entrypoint — by the CLI, or by a caller outside the graph facade — nothing had installed it, so every export refused with Graph services are not wired; import graph_ops first and the CLI exited 3 before any gate ran. That is the defect added by 5efabce2f, which put the audit call into run_export without wiring the root. The fix installs the root at the start of the export's graph work, and the empty-graph doubles in three export tests now answer a count query with its zero row. 46 lines across 4 files.
