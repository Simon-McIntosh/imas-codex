— none of which is the catalog repository. The release needs to write there for the publish lock (imas_codex/standard_names/publish.py:375, lock_path = isnc / ".sn-publish.lock", with no path override) and again for the review branch, its commit and the release tag. Even --dry-run takes the lock, so the block is not a dry-run artefact. This is an authority boundary, not a defect in the release tool: the tool reports the filesystem truth, and no flag would make a read-only checkout writable.
