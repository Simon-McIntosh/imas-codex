Candidate-stage Jev spend routes through PipelineCost

route_ids(description, *, gc, model, service, cost) and judge_candidates(source, facility, candidates, *, model, service, cost) now take an optional cost: PipelineCost — the run's cost tracker from CandidateDiscoveryState.cost. Each decisions request's transport-reported usage.cost is added to it under a step name as the request is made (candidate_route for the IDS Choice, candidate_judgment for the batched same_quantity call), the way the map pipeline's _acall_llm(..., cost=...) does. The shared _call_judgment helper carries the add, so a helper that is not passed a tracker still runs unchanged. candidate_worker passes cost=state.cost on both calls. The _capture_decisions_cost context manager is deleted: nothing in production replaces imas_codex.ids.candidates.call_decisions or assigns any module attribute of candidates, removing the global mutable state that double-counted under concurrency and collided with tests patching the same symbol.
