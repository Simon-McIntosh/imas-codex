DD candidate retrieval moved into ids/candidates.py

retrieve_candidates(sources, ids_by_source, *, gc, k, dd_version) -> dict[str, list[Candidate]] is the new deterministic shortlist builder. Each source description is embedded once, then searched once per routed IDS through hybrid_dd_search; the arms are merged by score and deduplicated on path, and Candidate composes the returned SearchHit (no field copied) with the arms that produced it and the parent node's documentation. K = 20. gather_ids_context now builds source_candidates through retrieve_candidates; the cluster expansion and the ClusterSearcher load in gather_shared_context are deleted, and compute_semantic_matches now supplies only the wiki and code bridges.
