Why DD path domains echo their IDS

The DD build overwrites an existing path's physics_domain with its IDS default, while leaving domain_source and domain_classified_at intact. The subsequent classifier selects only paths whose domain_source IS NULL, so it skips those overwritten paths. A prior LLM classification remains visible in metadata even though its domain value has been replaced.
