The build's path upsert keeps a classified domain

Confirmed from the code, not assumed. The path upsert in imas_codex/graph/build_dd.py:3583 writes the IDS default domain only where the node has no classification yet: 

path.physics_domain = CASE
    WHEN path.domain_source IS NULL THEN p.physics_domain
    ELSE path.physics_domain
END,

So a rebuild over a classified path leaves its physics_domain alone. The reset deliberately clears physics_domain, domain_source, domain_model, domain_classified_at and domain_input_hash for embedded (imas_codex/graph/dd_graph_ops.py:595), so re-classification starts clean.
