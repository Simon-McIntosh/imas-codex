Declared domain selector

select_primary_domain selects the lowest rank in the declared 32-domain table from the distinct supplied domains. The table keeps general last. Empty input returns None; an unknown value raises with its name. The rule does not read the graph and is unchanged by source order, duplicate entries, or a name's stored primary domain.

pick_primary_domain and domain_key now call the selector, carrying catalog import, export, and pure review grouping with them. Consolidation's _resolve_physics_domains also calls it and retains the sorted distinct source-domain union. The graph writer in graph_ops.py still calls the compatibility maybe_promote_domain adapter; its set-based rewrite belongs to the graph-writer node. The cluster-weighted index was removed.

The old cluster-index assertions in test_priority_high_outranks_medium, test_graph_unreachable_returns_empty_index, test_cache_query_is_one_shot, test_tied_importance_breaks_alphabetical, and TestGraphPriorityWins.test_graph_index_overrides_fallback were replaced by declared-order, graph-isolation, and vocabulary-coverage tests. The alphabetical assertions in test_unranked_domain_falls_back_to_alphabetical, test_empty_graph_falls_back_to_alphabetical, and test_domain_key_list_unranked_alphabetical_fallback were replaced by the table selection and unknown-value refusal. The empty-list assertion test_pick_primary_empty_list_raises now follows the selector's None result. test_domain_key_list_picks_priority now asserts the declared table. The old unknown-rank cases in TestDomainRank and TestMaybePromoteDomain.test_promotion now require refusal.
