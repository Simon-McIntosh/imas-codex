The pipeline's own domain writers route through the one writer

Four paths outside the graph-ops module authored a name's domain. Each now sets none of its own: the composing path asks the stored Jev decision for every name it persisted and writes it through imas_codex.standard_names.domain_decision.write_name_domain, and the three read paths read the stored value rather than deriving one.
