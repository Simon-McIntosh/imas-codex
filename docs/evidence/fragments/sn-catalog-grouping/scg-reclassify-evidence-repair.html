scg-reclassify-evidence-repair — the DD re-classification record, made durable

This node repairs the evidence left by scg-dd-reclassify-finish, whose review scored durability 9. It spends nothing and writes nothing to the graph: every query it makes is a bounded read. Five repairs, below, and one deduplication.

1. The score's denominator

_score divided by the number of graph rows, so a labelled path the graph does not hold would have dropped silently out of the denominator and raised the score. It now divides by the number of labelled paths and counts an absent path as a miss, recording the labelled count, the graph-row count and the absent count side by side. On this graph the three agree — 201 labelled, 201 graph rows, 0 absent — so the repaired figure is unchanged at 184/201 = 0.915, now with the denominator it is actually measured against.

2. A negative control a reader can open

The pre-repair instrument read each labelled entry as a bare domain string against a label file that maps every path to a record, so it could not match anything. It is kept as a runnable mode, readback --instrument bare-string, and re-run: it scores 0 of 201 on the same graph. The corrected instrument is re-run once against each label set. Each run has its own log carrying the literal command on its first line and EXIT= on its last.

3. The estimate beside the result

The plan's 0.89 estimate now sits beside the 0.915 result in both the fragment and the results file, so the result is read against the expectation it was commissioned under rather than alone.

4. The six unclassified grid coordinates

core_profiles/profiles_1d/grid/rho_pol_norm and five siblings carry node_category = 'coordinate' and a null domain_source, because _query_unclassified_paths (imas_codex/graph/dd_domain_classifier.py:1517) selects WHERE n.node_category IN $categories against CLASSIFIABLE_CATEGORIES (dd_domain_classifier.py:85), which holds quantity, structural, representation, geometry and fit_artifact — and not coordinate. The exclusion is right for a grid axis. What failed is the Tier-2 inheritance meant to cover coordinates, which requires ancestor.domain_source IS NOT NULL (dd_domain_classifier.py:535, in _inherit_from_parent_by_category at line 491): both ancestors of these paths are structural with a null domain_source, so nothing is inherited and the IDS default stands. No product code changed.

6. One pass driver, not two

The pass invocation now lives once, as run_pass in scg-dd-reclassify-run.py, which the readback driver imports by path. The sibling gained the single flag the later node needed (--stop-after-classify) and its default timeout path is byte-for-byte the one the first run used, so the earlier pass logs and their recorded figures still describe the code that produced them.
