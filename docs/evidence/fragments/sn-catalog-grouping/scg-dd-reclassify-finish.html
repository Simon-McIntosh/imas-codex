A first figure of USD 31.78 was recorded for this node, and it was wrong. It summed 234 cost lines from the pass logs, but only 215 of those are per-call bills (cost=$X, model=…); the other 19 are running subtotals (batch N/M done (cost=$Y)) that restate the per-call lines, so the sum counted the same spend twice and read as an overrun that did not happen. The corrected sum reads only the per-call lines, cross-checks each log's last LLM heartbeat … spend=$ figure, and is re-produced by the driver's spend subcommand at EXIT=0 (passes/spend.log, passes/spend.json). The heartbeat total, USD 11.79, sits just below the per-call total: it is a lower bound, because a pass is stopped after its classify phase and its final calls land after the last heartbeat, never above it.
