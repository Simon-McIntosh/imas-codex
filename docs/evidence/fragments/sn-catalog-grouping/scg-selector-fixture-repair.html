Repair fixtures that pass an IDS name where a physics domain belongs

The declared-order domain selector raises ValueError: Unknown physics domain on a value that is not a PhysicsDomain member. Twelve tests that passed at the selector's base (ef9f71261) failed at its head because their fixtures gave a name an IDS name where a domain belongs: eleven fed core_profiles, one fed magnetics. Both are IDS names, not members of the 32-value PhysicsDomain vocabulary. The selector is correct to refuse them; no selector, allow-list or error handler was changed. Each fixture now carries a valid, fitting domain.
