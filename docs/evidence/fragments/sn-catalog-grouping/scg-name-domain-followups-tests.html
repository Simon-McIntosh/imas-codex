5 Every suite carried its own copy of the domain-state answer helper and its own recording client, so a change to how a statement is captured had to be repeated in each copy. answer_domain_state now lives once in tests/standard_names/conftest.py and the five suites that carried a copy import it. The local recording clients are built on tests/recording_graph_client.py's RecordingGraphClient: the routing-reconcile forwarding recorder records through its superclass rather than appending to calls itself, and the metadata-invariant recording client subclasses it instead of keeping a parallel statements list.
6 test_bootstrap_transaction_rolls_back_partial_parent failed inside a multi-file -m graph run while passing alone. The test asked for disposable_neo4j, which does not wipe the shared graph, and then created its nodes with CREATE under the fixed ids electron_temperature and maximum_of_electron_temperature. A prior graph file leaves electron_temperature behind, so the second CREATE minted a duplicate node and the rollback assertion read two rows — its own and the neighbour's. Reproduced by running the follow-ups file before this one in one session ([{'name_stage': 'drafted', 'origin': 'pipeline', 'unit': 'eV'}, …] against the expected single empty row). The test now takes disposable_neo4j_empty, so it starts from a wiped graph and measures its own write. The same two-file run then passes.
8 _stored_domain_decisions returns an undecided decision for a name with no stored choice, but its docstring and DomainDecision | None annotation still said such a name maps to None. The contract now matches the code: the annotation is dict[str, DomainDecision] and the docstring states that a name with no stored choice maps to an undecided decision that keeps its candidates. The three call sites already test membership rather than None, so no behaviour moved.
