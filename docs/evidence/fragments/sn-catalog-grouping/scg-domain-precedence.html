One domain precedence, used as the classifier's tie-break

The order below is declared once in imas_codex/definitions/physics/domains.yaml as precedence, band by band. load_domain_precedence() flattens it and refuses an order that misses, repeats or invents a domain of ISN's vocabulary. standard_names/domain_ranking.py and the rendered questions in graph/dd_domain_classifier.py both read it, so a standard name and a DD path settle the same overlap the same way.

The order, band by band

rankbandrationaledomains (in order)
0–7core_physicsThe plasma's own configuration, state and macroscopic behaviour. A quantity that is a property of the plasma column outranks any system that measures it or acts on it, so this band is asked first.equilibrium → magnetohydrodynamics → transport → core_plasma_physics → turbulence → gyrokinetics → fast_particles → runaway_electrons
8–10heating_current_driveThe actuators that add energy, momentum or current and the wave physics that carries their power: central to a discharge, but below the plasma state they drive.auxiliary_heating → current_drive → waves
11–14edgeThe boundary plasma and the material surfaces it meets: resolved at the edge of the column rather than the plasma as a whole, so it ranks below the core.edge_plasma_physics → plasma_wall_interactions → divertor_physics → fueling
15–22diagnosticsMeasurement systems and their responses, below the plasma state they observe, so a profile derived from a measurement outranks the instrument that inferred it; magnetics leads as the backbone sensor.magnetic_field_diagnostics → plasma_measurement_diagnostics → particle_measurement_diagnostics → electromagnetic_wave_diagnostics → radiation_measurement_diagnostics → mechanical_measurement_diagnostics → spectroscopy → neutronics
23–28operations_engineeringControl, scheduling and the engineering plant: a command or a component, ranked below the physics it acts on.plasma_control → plasma_initiation → machine_operations → magnetic_field_systems → structural_components → plant_systems
29–30dataData products and computational infrastructure: assembled or reference data, ranked below the direct measurement or state it summarises.data_management → computational_workflow
31generalThe last resort, for quantities that genuinely carry no single subject.general
