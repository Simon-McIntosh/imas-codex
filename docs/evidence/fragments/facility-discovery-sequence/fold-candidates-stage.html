fold-candidates-stage

Extracted run_candidates_stage(facility, options) and the frozen CandidatesStageOptions dataclass from the discover map click command in imas_codex/cli/discover/map.py, which is now a thin wrapper that builds the options and delegates. The stage drains the sources the signals stage seeded, so it has no seeding half: --scan-only runs no worker, --flush and the default run the draining worker, --limit caps the sources judged, --focus is refused with a message stating the mechanism (the claim query takes no item filter), and --topic is carried onto the stage. Measure: pytest tests/cli/test_discover_candidates_stage.py tests/cli/test_discover_map.py passes 18, with the negative control failing 1 (the --flush test) when the stage is mutated to treat --flush as the seeding half.
