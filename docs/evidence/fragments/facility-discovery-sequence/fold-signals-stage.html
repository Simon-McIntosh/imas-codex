Fold the signals domain behind a stage function

Extracts run_signals_stage(facility, options) and refactors it to a frozen SignalsStageOptions, leaving the click command as a thin wrapper that builds options and calls the stage. Write paths: imas_codex/cli/discover/signals.py, tests/cli/test_discover_signals_stage.py.

Settled option surface

  • --scan-only → scan_only (engine discover_only=True): the seeding half only.
  • --flush → flush (engine enrich_only=True): the draining half only. Replaces --enrich-only, retained as a deprecated visible alias so the old command tests keep passing before the runner lands.
  • --topic TEXT → topic, passed to the engine's free-text focus= argument: the steer the old free-text --focus reached.
  • --limit N → limit (engine signal_limit): caps items. Replaces --signal-limit and -n.
  • --focus ITEMS → focus: refused with a message naming facility-discovery-sequence section 7, because the signals claim query takes no item filter yet.
  • --reenrich deleted (deprecated alias).
