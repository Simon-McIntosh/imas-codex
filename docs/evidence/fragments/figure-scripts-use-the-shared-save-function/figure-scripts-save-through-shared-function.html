Every figure script saves through the shared, checked save function

All ten tracked figure scripts under scripts/ now export through imas_codex.plotting.style.save_figure. No script calls savefig directly, none defines or imports a clipped-text check, and none writes the slide-size declaration. Fifteen tracked figure files were regenerated through it, the four JET plots are left untouched because the live graph carries no JET geometry to draw, and the worst declared-versus-coordinate ratio error across the twelve regenerated vector files is 3.57e-4 against the 1e-3 limit.

The plotting package gained one public function, use_style(), which applies the packaged data-ink style plus the caller's rc overrides, and one module-level declaration of the slide size as a pair of constants. save_figure gained four options — dpi, animation, fps and clear_of — and now returns a receipt (path, format, export_dpi, pixel_size, bytes, and declared_cm for a vector file). It gained no new refusal: every refusal it raises was already there. Animated exports need the Animation and write a GIF.

What moved to satisfy the check

  • ICP town labels carried a second Text artist as a white halo, which the check saw as overlapping text. The halo is now a withStroke path effect on the label itself. The three stage files shrink from about 45 000 to about 12 000–14 000 lines (icp-map-a 1 126 752 → 389 316 bytes) and render within 0.07% of the earlier pixels; only the halo path set changed.
  • The knowledge-graph title strip and the mapping-flow strip stayed reserved through the check's clear_of, given a transparent full-width rectangle over the strip, so a label drifting into the slide's title area is still refused.
  • The ICP arrowheads reach the same check as clear_of marks, so an arrowhead drawn over a verb is still refused.
  • The four JET plots lost their titles above the canvas (the default y is inside it) and their tight crop, and three of them reserve a slightly smaller axes rectangle so their outermost tick labels sit on the canvas. plot_jet_epoch_evolution.py also stops paying for a tight layout it no longer uses.
  • figures_discovery_to_mapping.py keeps a save() helper, but it only calls the shared function twice and composes its existing receipt from the returned pixel size and byte count.

The content-cropped files

The four JET plots were the ones exported with a content crop (bbox_inches="tight"), so their pixel size followed live content rather than the canvas. No tracked file among them was regenerated, because the graph holds no JET geometry: the seven PNGs plot_jet_epoch_evolution.py writes (jet_wall_limiter_evolution, jet_magnetics_evolution, jet_passive_circuit_evolution, jet_pf_coil_evolution, jet_component_overview, jet_epoch_summary, jet_limiter_contours), the three jet_poloidal_p*.png files and jet_limiter_comparison.png from plot_jet_poloidal.py, jet_limiter_epochs.png and jet_composite_geometry.png keep the pixel sizes they had before this change, and no before/after ratio comparison is claimed for them.
