The judge stage offers the forms as words, not as patterns

The judge stage built its Choice by handing Jev the registry's forbidden_variants as written forms, but those are regular expressions — the plasma-boundary pattern is the separatrix and the flux-surface-average pattern is a display-equation matcher. In the first live run the boundary gloss was classified forbidden for all four fixtures, including the entries written as the last closed flux surface. The stage now offers an authored form vocabulary per judged concept (_CONCEPT_FORMS): a Choice whose options describe the forms in words, and a mapping from the chosen form to the verdict the registry's pattern states. The registry's patterns never reach the model — neither in the question's options nor in the state the stage builds.

Judged concepts are grouped by token so each concept's question offers only its own forms, and every group is judged through the shared decide_batch owner. The stage is also decoupled from --skip-audit: skipping the deterministic audits no longer skips the judge, so the cases the registry states as equivalence classes are still judged. A concept that carries forbidden variants but no authored form vocabulary is left unjudged rather than judged by sending its pattern.
