The documentation gates now reach the reviewer's report

run_all_audits in imas_codex/standard_names/review/audits.py now calls the deterministic documentation gates through run_documentation_gate_checks, beside run_house_style_checks. Each documented name supplies the physics context a gate reads: its COCOS transformation type decides whether a sign-convention paragraph is required, and its declared unit anchors the defining equation. A gate with no field to evaluate against is not evaluable and raises no finding; each gate that contradicts the name adds one LintFinding whose finding_type is that gate's name, so sign-convention, defining-equation and symbol-definition decisions are visible on the AuditReport the review pipeline reads.

One opening, several templates

_template_opening_findings reports a template_opening finding only when the documentation opening matches none of the selected templates. A name selecting two templates is no longer flagged for the one its opening did not follow, which removes the over-firing the single-template registry has not yet exercised.
