The conventions block is guarded where it is wired

The prompt-level tests hand a template its conventions directly, so a render site that stops supplying the context key leaves them green while the block silently drops out of the live prompt. Four tests now drive each render site itself with render_prompt stubbed and assert the context the site passes carries the conventions the registry selects for the item — the generate, refine and single-item-review workers in imas_codex/standard_names/workers.py and the batch reviewer in imas_codex/standard_names/review/pipeline.py.
