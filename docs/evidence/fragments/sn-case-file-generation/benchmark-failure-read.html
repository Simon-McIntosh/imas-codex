Questions

(a) Does the prompt show the incumbent and ask the generator to keep it unless it is wrong, and does the output let it say 'keep'?

Shown, not asked, and with no way to say keep. The case file opens with the block 'Incumbent name, definition, documentation:', so the text is in front of the generator. The instruction is 'You write one standard-name record for the quantity a case file describes. Return the name, the definition (the description) of the quantity, one paragraph of documentation, the unit and the physics group.' It never mentions the incumbent, and the schema the model answers with carries name, description, documentation, unit, group and blocker - no keep flag, so a generator that judged the incumbent sound could only retype it. That is what the arms measure: 37 of these 50 members have an incumbent name that the reference's own list calls right, the committed run recorded changed_incumbent on all 87 held-out rows, and this regeneration retyped the incumbent's name on 33 of 50. A retyped name then faces the group and wording gates below, which is where 40 of the 50 rows died.

(b) Is the judge's verdict usable, or must the judge be a blind adjudication as the plan requires?

Not usable as committed. The judge's own rule is 'Return right when the submitted name is one of the right names and the definition states every definition point (and the unit agrees where a unit is given).' Group is not in the rule, yet judge_input hands it the reference group and the submitted group, and 18 of its 40 wrong verdicts cite group. Of 34 rows whose submitted group differs from the reference, 1 passed; of the 16 that match, 8 passed. Among the 31 rows that reproduced the reference's exact name and unit, 9 passed. The case file names no physics group at all: the only 'group' strings in its content are entity tokens such as 'beamlet_group' in the grammar vocabulary (13 of 50 rows), so the group the judge demands cannot be read off the input. It applies its own gate inconsistently: power_at_divertor_target_due_to_recombination was submitted with group 'Plasma-surface interactions' against 'divertor_physics' and passed ('The submitted name matches the reference answer'), the same mismatch it failed 33 times. It also fails a record for a point that only the incumbent's documentation states (2 rows). A blind adjudication is required, and blind must mean blind to the group as well as to the arm and the incumbent, with the name and the definition decided separately.

(c) Is the reference set's set of right names too narrow to score a regenerated name fairly, and how should a record be scored instead?

Too narrow. 48 of these 50 rows have exactly one right name, so the name decision is a string test: 3 rows are names I judge sound and the list does not allow (turn_count_of_passive_loop_element, collisionality_between_species, surface_incident_angle_of_magnetic_field_at_langmuir_probe), and a fourth (toroidal_parity) fails against the legacy spelling b_field_phi_sign, a name no generator can derive from the source. The record should be scored on two axes that --check keeps separate: identity (does the name denote the same base, locus and separation as the reference quantity, read against its neighbours) and specification (is each reference definition point stated, and does the unit agree). A name matching a list entry is evidence for identity, not the identity test itself; with 31 exact-name rows and 9 passes, the list is currently deciding the benchmark.

(d) Why the withheld-text control did not separate: was the enclosing-structure text actually in the case files the generator read, and did the members whose answer rests on it differ?

The text was there and the withholding was real: every case file renders its bound source's enclosing statements as 'enclosing <path>: <text>', and with enclosing_structure_text withheld the assembler writes no statements and prints 'the enclosing-structure text was withheld'. The control still cannot separate, for three measurable reasons. It is small: on the 87 held-out rows enclosing statements are a median 1.5% of the case-file characters (max 35%), and 20 of 87 rows have none at all, so for nearly a quarter of the population the two arms read the same input. Its effect is symmetric noise: 19 of 87 rows change verdict between the arms, 6 right-to-not-right against 5 not-right-to-right, which is a net -1 against a binomial spread of about 4 rows at 28/87. And it is not concentrated where the text is: 13 of the 19 flips carry enclosing text (median 2.1% share) against 54 of the other 68 (median 1.5%). Only 3 of the 87 reference answers rest on an enclosing structure at all, and of those the one in this read moved from wrong to blocked (hydrogen_density_at_limiter). The outcome metric is dominated by the group gate, which withholding does not touch.
