What has to change first

None of the five names is in the vocabulary this repository validates against, and codex owns no vocabulary data: the source is physics_domains.yml in the grammar library. The change is cross-repository and needs a release and a pin bump.

  1. imas-standard-names: add the five domains to imas_standard_names/grammar/vocabularies/physics_domains.yml
  2. imas-standard-names: regenerate PhysicsDomain and PHYSICS_DOMAIN_DESCRIPTIONS in imas_standard_names/grammar/tag_types.py
  3. imas-standard-names: cut a release and bump both imas-codex pins in pyproject.toml
  4. imas-codex: add the five domains to iter_codex/definitions/physics/domains.yaml with scope, includes, excludes and a precedence band, which tests/graph/test_physics_domain_guidance.py enforces
  5. imas-codex: move the 950 names with sn reclassify, one writer per name, then read the counts back
