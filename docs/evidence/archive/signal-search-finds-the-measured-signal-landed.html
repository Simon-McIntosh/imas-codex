§5 — embeddings follow the text they embed

Five nodes, merged in 5ab2c75db (embed-text measurement), 666828842 (description writer), 22f08a9ac (re-embed and census), 598090c4d (labels on the re-embedded graph) and cf396750c (one embed-text owner).

  • Decision. embed-text is locked on the description alone: measured in memory over 14,312 eligible signals, it beats name, description and unit on both arms and every metric (RRF nDCG@10 0.776 against 0.762).
  • Writer. write_signal_descriptions is the single writer of a FacilitySignal's description, embedding, embedded_at and embedded_text_hash, on all four description write paths. An individualisation write re-embeds, and the test fails against the previous writer. When the embedder returns no vector, the stored vector and hash are left untouched and the row stays marked stale, rather than being nulled and stamped current.
  • Census. One predicate, a missing or differing hash, selects the rows the sweep re-embeds and the rows the census counts. The sweep re-embedded 61,983 signals in 515 s; mismatches fell from 61,983 to 0. 3,410 signals with no description record an empty-text hash without a vector, by design. signal_embed_text is the one derivation the writer, sweep and census share.
  • Harness. The fresh vectors lifted 29 unlabelled candidates into the arms' top tens; they are graded (1,704 labels). The fused tool then scores 0.7773 mean nDCG@10 against 0.7920 on the stale vectors, 0.0147 lower and 0.0027 beyond the 0.012 spread §3 records. This is accepted: the stale vectors embedded superseded descriptions and cannot be restored, the in-memory measurement predicted the same level (0.7761), and the labels are identical before and after, so the shift is the fresh vectors' own ranking, about one question in 22.
  • Carried. The arm-table test asserts only that each arm beats the control, so the no-regression criterion is judged by hand; the live census test asserts only a non-negative count; and the frozen additive arm's order depends on the hash seed on score ties.
