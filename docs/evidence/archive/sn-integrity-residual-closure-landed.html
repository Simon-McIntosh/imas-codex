The supersede operator now signs and writes the successor

Landed 2026-08-22 — commit 1854c6d4, node n-supersedescalar, gate passed. 12 unique supersede-contract cases passed, 0 failed, 0 skipped across 11 disposable-graph cases; ruff check 0 findings, ruff format --check 2/2 clean.

A distinct-identity supersede authority must now sign mutation.arguments.successor_id and declare both the predecessor and that successor as StandardName participants, so both are locked and re-hashed before apply.
