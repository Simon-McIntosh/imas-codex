The review surface does not run on the local lane, and one model is the whole of it

Measured 2026-09-21 at 409809bff7538002648a5fd42a324f52a864b74b, by resolving every seat through the real registry rather than by reading pyproject.toml — which matters, because the file gives the wrong answer in the reassuring direction.

Exactly one model in the entire configuration resolves to the local endpoint. _MODEL_ENDPOINTS holds one key, local/deepseek-v4.1-flash, and the two seats that use it are sn-compose and sn-parent-enrich. Everything else — sn-docs, sn-refine, sn-escalation, sn-classifier, sn-prose-adjudicator, sn-release-notes, and both review axes — resolves no endpoint and is routed to a paid provider without the operator asking for one.

Both starting facts hold. A live GET /v1/models returns exactly one entry, deepseek-v4.1-flash. And the registry is keyed on the full seat string, shown by a negative control rather than asserted: the name the server actually serves, without its local/ prefix, resolves nothing and falls to the proxy — as does the previous sprint's seat spelling. One character of drift in a seat string silently moves a call onto a paid lane.

The profile trap is the finding a configuration read would have missed. [sn-review.names].models lists one local model and two paid ones, with a comment describing the first cycle as free. That list does not run: the accessor the pipeline calls resolves a profile first, and the hard-coded default at settings.py:1556 is a different section whose three members are all paid. Measured through the accessor, --target names with no flags is grok-4.5, gpt-5.6-luna and claude-sonnet-5 — zero local cycles. The free lane exists and has to be asked for.

--target docs is fully paid and structurally unable to be otherwise. Its section carries no model-route at all, and the registry binds a local member only when the node it sits in resolves an api_base, so adding a local model to that list would change nothing.

The embedding path is the one surface entirely on the local lane, and it needed checking rather than assuming because a paid embedding client exists in the same package: nothing outside that module constructs it, and the encoder resolves to a remote GPU server. The encoder is explicit that it refuses rather than falling back — but the audit around it wraps the whole preflight in a bare except Exception, so an unreachable embedding server produces a clean-looking audit over stale vectors. A review that cannot embed still reports. Layer 1 audits and consolidation reach no model at all.

Five silent fallbacks, four of them absent-value defaults — an unresolved model admitted to the proxy, a registry miss indistinguishable from an intentionally paid seat, the paid quorum as the profile default, the swallowed embedding failure, and a missing routing key. None requires the operator to ask for a paid provider. The single check that would close the first: a model carrying a local-lane prefix that resolves no endpoint is a configuration error, not a request for the proxy.
