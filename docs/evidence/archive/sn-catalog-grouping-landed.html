§3 — classification guidance for every physics domain

imas_codex/definitions/physics/domains.yaml is the file codex's prompt provider already pointed at. It had been deleted when the domain enum moved to ISN. It is revived as guidance only, keyed by ISN's values, and repeats none of ISN's values, one-line descriptions or categories.

  • Per domain: a scope; typical quantities, with DD path examples; and exclusions naming the neighbour each excluded quantity belongs to, with the separating rule.
  • Per ISN category: a scope sentence for a first-level choice.

It covers all 32 domains and all 10 categories. It was written from ISN, the IDS map and bounded samples of the graph's LLM descriptions, never from the labelled sets.

One example: equilibrium excludes a heat, particle or momentum flux, a diffusivity or a confinement time, which belong to transport. The rule is that equilibrium holds only the field's shape and the mapping to it, never a flow across it.

The prompt provider serves the guidance beside ISN's description and category. The head gate is 121 passed against 116 at base, with no added failure (merge 9d8882a2b; review 97/120).
