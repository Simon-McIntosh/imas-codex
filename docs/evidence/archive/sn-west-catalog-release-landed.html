WEST catalog release — cumulative evidence

This record consolidates what the sn-west-catalog-release plan proved while building a review surface a physicist can actually read. It is an evidence ledger, not a release claim: the fork candidate is a review artifact, and the human review plus the upstream leg remain ahead. Every result below is reconciled against the committed run ledger at docs/state/imas-codex/crew.json and the reports the runs left on disk under ~/.config/reckon/crew/reports/.

Every review-surface defect was fixed at the authority, never worked around

Four defects made the first candidates unreviewable, and each one was traced to the imas-standard-names package rather than patched in the codex exporter, on the lead's explicit direction. A physics domain could not be carried by a catalog entry at all, so the review site grouped every name under Uncategorized; the fix makes physics_domain a first-class required field of the entry model. The exporter was writing its own YAML, so review formatting could drift from what the schema accepted; the fix moves emission into the package's own dump_catalog_yaml. Prose then arrived as one unreadable line per paragraph; the fix emits description and documentation as folded blocks whose paragraphs fold near 80 columns while equations, display-math fences, list items and blank lines keep their authored layout, with a byte-identical reload proven over a 300-character paragraph carrying display math. Three physical bases were registered with the wrong structural kind, which is what put tensor beside a flux-surface-averaged gradient magnitude.

Stored kinds reconciled to zero disagreements, and an earlier sweep repaired

Structural kind is derived from the canonical identity, but the value stored on each name is a snapshot taken when the name was composed. A snapshot taken against a registry that mis-classified three bases is wrong in both directions, so the reconcile had to fire after the pin moved. The lead locked that ordering, and it mattered: a reconcile had already run at 16:49 UTC under the 0.8.2 pin and flipped 40 correct vectors to scalar among its 181 rows. The single unscoped drain under the 0.8.3 pin repaired them.

Negative result: four verified workers were lost to an exhausted metered quota

Late in the session every OpenAI-backed lane reported 100% weekly utilisation with a reset six days out, and the backend dropped four in-flight sessions mid-turn. One had already accepted six of ten staged names for 0.42 USD before it died. None of the four committed. The recovery was not to wait: each run was ledgered as an infrastructure failure with its partial outcome recorded, the trivial mechanical nodes were repointed at the locally served backend, and the judgement-heavy nodes at a frontier Claude backend registered for exactly this case. A distinct backend entry is required rather than an effort override, because a roster session must never cross models.

Two defects the cut exposed, both closed the same night

The release created the pull request and the tag, then exited 1 at its own preview-link invariant. The invariant was right and the transport under it was wrong: the body update shelled out to gh pr edit, which now fails against this repository with the Projects-classic GraphQL deprecation and leaves the body unchanged. Every batch release would have opened a pull request with no preview address for the reviewer to follow. The body update now issues a REST patch, proven by three new tests with 104 passing in the focused release suites.

The second defect was quieter. Twenty live names carried no physics domain at all, and since the field became required the exporter substituted a placeholder that catalog validation rejects — which is how one name left the batch as an invalid entry rather than as a physics judgement. The recovery took each name's domain from its bound data-dictionary source where one existed and from the configured classifier seat otherwise, never hand-picked. Null domains went from 20 to 0, every written value an enum member, each with exactly one matching domain edge and a recorded change; 4694 of 4694 names now carry a domain. Sixteen of the twenty were superseded or exhausted, which says no domain route had ever run over non-live stages.

What remains

The physicist review of pull request 11 is the human gate and nothing downstream of it can start early. After the review returns: the reviewed disposition folds back through sn approve, the upstream catalog pull request and its stable tag follow, and the undo rehearsal proves the fold is reversible. The 59 withheld names follow as a later additive batch under their recorded reason groups. The release recipe in imas_codex/standard_names/AGENTS.md now gates pin-before-reconcile with a runnable census and gates the candidate on the published bytes, so a session that has not lived through this one can cut the next candidate without rediscovering any of it.
