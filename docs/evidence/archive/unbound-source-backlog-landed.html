Twenty-four routes delete a producer edge; fourteen can leave an accepted name with none

Read-only on 2026-09-17 at fcc65951bc52d083b74461f10ffbfe39b97c2624. A PRODUCED_NAME edge is the only record of which source justifies a standard name, so every code path that deletes a PRODUCED_NAME edge was enumerated and classified by whether it can take an accepted name's last producer. 19 routes delete the edge and leave the name standing — the orphaning-capable class, of which thirteen can take an accepted name's last producer — and 5 delete a node. Of the node deletions only one matters here: deleting a name deletes the name, but deleting a source detaches every edge it carried, and the derived-parent cleanup does exactly that with no read of the stages it strands. The other four either delete the name itself, delete a source that by definition has no producer, or carry an explicit NOT (target)--() precondition. No graph mutation was performed.

Five attributes of the negative result belong in the record. The full audit lists every route with its file, line and refusal predicate.

  • The signed-manifest family is the largest class and the only one that is fenced on identity rather than stage. Five signed-manifest routes delete the exact edge a manifest names, with no predicate on the target's stage. That is correct for the route's purpose and it means a manifest naming a name's only producer will orphan it silently; the guard belongs at manifest construction and is not in the apply path.
  • A rename can still orphan today. persist_refined_name's empty-cohort refusal is exempted by edit_mode, and the caller guard in edit.py returns early when the observed cohort is empty — so the identity that is later accepted carries no producer while the predecessor is simply superseded and looks unremarkable.
  • The liveness reconcile is confirmed innocent. _TERMINAL_BINDING_NAME_STAGES is exactly superseded, exhausted, contested, and the cleanup supplies that set as its terminal stages, so an accepted target is a live binding and cannot reach the deletion.
  • A second, wider predicate disagrees with it. The semantic-source repair excludes only superseded and exhausted, so accepted is inside its reach. Two predicates both meaning "this name is no longer live" and they do not agree; that divergence wants a single definition rather than two call sites.
  • The live count is unchanged. Nine accepted names carry no producer, exactly the bound of 9 at 2026-09-15T18:20Z. Positive controls saw 5,130 of 5,130 identities carrying id and 5,493 PRODUCED_NAME edges across 5,393 distinct sources.
