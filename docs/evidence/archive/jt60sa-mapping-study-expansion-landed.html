It returns only what match_error_signals_to_imas finds behind sources that classify_error_signals identifies as error signals, so an error field with no error signal behind it stays unmapped. §7 — Hand-off rows carry the target's COCOS label

build_mapping_handoff in imas_codex/ids/handoff.py now fills cocos_label and the new cocos_label_source on every signal row. They come from the nearest node on the target's HAS_PARENT chain that carries cocos_transformation_type, with the target itself as hop 0. The binding's own cocos_label is no longer read. A target with no labelled node on the chain carries the DD absence token none for both keys. A target whose last segment is time always carries none, because a time coordinate is never COCOS-transformed.

The coordinator's review asked for two corrections, both delivered. The first made the target's own label win over its parent's; it was *1.. and is now *0... The second gave time rows none, after the live export showed 14 field/time rows inheriting one_like. Worker commits are fe3e7e479, 1fb670f33 and 0a61ff99e, merged at e48572d1b and d8a9227fc. On the merged head, tests/ids/test_mapping_handoff.py and tests/ids/test_error_derivation.py give 35 passed. Each correction has a negative control that fails when the rule is removed.

The worker's live export at 05:27Z gave every pickup-probe data row one_like from xml. imas-ambix's importer now reads cocos_label as a DD transformation label. A COCOS-dependent row (ip_like or psi_like) imports as a draft rule with sign unscored until JT-60SA's source COCOS is declared.

§1 — discover signals --focus

The signals stage now takes --focus, resolved through resolve_focus_items. An item may name a FacilitySignal by id or accessor, a SignalSource by id, or a source array by a data_source_path segment such as magPbTC10. Naming one member of a grouped source reaches the whole group. build_focus_predicate in imas_codex/discovery/signals/parallel.py applies the same filter to the enrichment claim, the check claim and both pending-work checks. An item that names nothing at the facility is refused with a usage error that names it. Worker commits 89389b7ea and 760ab572b are merged at 3787f8357. The merge was clean, and imas-codex-90's a7d0ba0ef, 4f19c2968 and 9927dc9eb survive in HEAD:parallel.py.

The negative control empties the predicate; seven tests then fail, among them the test that an unnamed source in the same facility stays unclaimed, for both claims. The live check ran the focus predicate against the graph rather than a full enrichment. It selected the 28 members of the two sources whose arrays are named magPbTC10, out of 10,432 discovered: the MDAC probe group and a PSRC twin. An array name can therefore match sources in more than one group, so a cohort that must be one group names its SignalSource id. --reset-to still ignores focus; that is §2.
