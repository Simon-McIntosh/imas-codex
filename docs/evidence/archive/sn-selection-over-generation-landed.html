§2 — Jev selects each grammar segment from the closed vocabulary

imas_codex/standard_names/segment_selection.py is an unwired prototype. For each grammar slot it asks Jev one Choice over that slot's closed ISN vocabulary, read through grammar_tokens_by_segment. Large vocabularies are walked as a beam of three, scored by the geometric mean of the per-level choices. The chosen tokens render through compose_canonical_ir, so a token the grammar lacks is recorded as that item's failure and never repaired (merge 00a070a95).

Its first review found a blocking defect: when every expansion of a beam node failed, the node was re-queued and asked again without bound, past 200 calls in a stubbed run. The repair narrows the beam instead. A second round moved rendering onto the existing compose_canonical_ir and put the new test file into the gate. Reviews 95, 112 and 118/120; the gate passes 39 at head. A follow-on test drives an empty slot through select_segments and shows the item records the failure with no rendered name (merge 22e130c4a, review 118/120). The measurement on golden A is in flight.

§4 — the compose comparator block can be reranked by Jev, off by default

rerank_name_comparators in imas_codex/standard_names/context.py reorders the compose prompt's comparator block by a Jev relevance judgement through rerank_pool under the sn-judge seat. Each item's order is fused across a batch by rrf_fuse_in_input_order, a new order-preserving variant beside rrf_fuse in imas_codex/search/fusion.py; the two share one mass accumulation, so the repository has one rank-fusion owner. Both compose paths call it only when a switch that is off by default is on. With the switch off, prompts are unchanged. The rerank's spend is charged under the seat it ran on, on both compose paths, and the charge is kept when a lease reservation fails. Any raise returns the embedding order. The embedding order surviving a failed rerank is pinned by the existing test_rerank_pool_keeps_the_pool_order_when_every_judgement_fails (merge 2112da115).

Four review rounds: 106 (truncated gate log, query untested), 98 (a second rank-fusion implementation, spend booked under the compose model and dropped when the budget is exhausted, no failure guard), 110 (the compose_worker path charged no lease) and 108/120. Every defect was answered by commit. Gate: 845 passed, 1 skipped at head. The nDCG@10 measurement on a coordinator-labelled set of 30 items is the next node; adoption waits on it.
