Identity is segment-aware, multi-role, and clean of five structural source bindings

An exact catalog-name/grammar-token spelling is no longer treated as a global collision. The exporter reads the runtime grammar segment map: an exact match in the quantity segment is a legitimate complete quantity name, while an exact match in any non-quantity segment is a hard collision with identity, token, segment, and source location. It also generates multi-valued roles rather than forcing overlapping identities into one exclusive class.
