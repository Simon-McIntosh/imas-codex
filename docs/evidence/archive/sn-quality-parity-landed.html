An objective gate vector, and a holdout large enough to use it

Documentation quality had only one measure: a reviewer's subjective score. That number cannot say which content a template or context change improved, so no change could be defended on evidence. Two nodes closed that gap in the same wave.

The scorer discriminates. imas_codex/standard_names/docs_gates.py returns an ordered ten-bit vector: the seven operative normative gates, link hygiene, and two independent word bounds. Measured against the holdout, the poloidal_magnetic_flux catalog row scores 10/10 and a three-word stub scores 4/10, failing six gates — so the vector separates real documentation from filler rather than merely detecting non-emptiness, which is all the previous content-gate test proved.

The excluded gates are pinned by a test, not by convention: NORMATIVE_GATE_NAMES holds exactly seven entries and DOCUMENTATION_GATE_NAMES is asserted to contain none of typical_values, measurement_methods or general_measurement. Sign convention is treated as conditionally satisfiable, because COCOS applicability cannot be inferred from prose alone; where a convention is emitted, its canonical final-paragraph form is checked.

The documentation content gates, and why two were dropped

The plan required mandatory typical values and a general measurement or calculation section. The live faithfulness policy forbids both, to prevent plausible but ungrounded filler, and permits measurement content only where it is constitutive or discriminating — enforced by test_normative_documentation_policy.py and a dedicated prose-adjudicator seat. Both scouts flagged the conflict independently; the currency audit ruled the plan claims wrong.

Locked 2026-08-23 in favour of the live policy. The reasoning that decided it: the policy is a refinement of the plan's intent rather than a rejection of it, since it already admits measurement content exactly where it carries physics. The rejected alternatives both cost more than they returned — a grounded-only synthesis needs a per-path value source the DD does not carry for most paths, so its gate would degrade into the very filler the ban exists to stop, while inverting the policy outright would make roughly 2,400 doubly-accepted names non-conformant on two gates. The operative gate set is therefore definition, governing equation, variable definitions in prose, semantic scope and exclusions, essential relationships, sign convention where COCOS applies, and inline name: cross-references.
