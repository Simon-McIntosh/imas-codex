# Standard Name non-acceptance tail census

Measured read-only against the production `codex` graph on 2026-08-23. This census covers every live `StandardName` that has never reached `accepted`, plus every `exhausted` name. The graph-wide stage census contained only `accepted`, `drafted`, `exhausted`, `pending`, `reviewed`, and `superseded`, so the predicate `name_stage IN [pending, drafted, reviewed, exhausted]` omits no other live stage. No model was called and no LLM budget was spent.

**RESIDUAL 0:** `144 + 72 + 1 = 217`, exactly the measured census population. A producing source is counted once within a disposition. A source is “stranded” when it produces a census identity but has no `PRODUCED_NAME` edge to any accepted identity. Eleven stranded sources occur in both redraw and steering because they bind more than one tail identity; therefore the per-disposition stranded counts intentionally do not sum. Their union is 431 distinct sources.

## Selection criteria

The partition is ordered and mutually exclusive. It uses graph authority, not name spelling or lifecycle state alone:

1. **Correctly-abandoned** when the identity has no incoming `PRODUCED_NAME`, no structural child, and no denormalized `source_path` or `source_paths`. This is stricter than “zero edges”: `toroidal_angle_of_along_pellet_path` has a missing producer edge but retains the exact DD path, so its physics is still recoverable and it remains under steering.
2. **Needs-steering** when any of these is true: validation is not `valid`; `refine_stop_reason` records `attempts_exhausted` or `successor_collision`; or a completed, non-shortfall names-axis review has no reviewer score at or above 0.85. These rows need corrected context, an operator fold/reattachment, or a reword. Repeating the same-name draw is not supported by the current evidence.
3. **Redraw-eligible** for the remaining valid identities: a `review_quorum_shortfall` (for which same-name `sn rescore` is the explicit recovery); a valid unreviewed identity awaiting its first draw; or an identity for which at least one recorded names-axis reviewer already scored the same spelling at or above 0.85. `sn rescore` must preserve the exact identity; this class is not authority to reword. Drafted rows already at the same-name review gate need ordinary review, not an unnecessary restage.
