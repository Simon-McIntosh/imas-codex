## Evidence and decision method

Each JSON row cites the exact census artifact, census commit and plan version, DD source identity and DD version, live candidates, prior scalar, one survivor, removed targets, disposition, authority, rationale, and an independent row SHA-256. Each family carries its complete source list, exact source-to-survivor dispositions, survivor/disposition/authority counts, and a family SHA-256 over those row signatures.

The primary authority is the DD path itself: owner (`ion`, `neutral`, `plasma`, hardware), locus (`aperture`, `detector`, `flux_surface`), component (`phi`/toroidal, `z`/vertical, `parallel`, `perpendicular`), and process tokens must survive in the name. Exact live DD documentation decides the small set whose leaf is under-specified: external-flux averaging, total equilibrium mass density, NBI source surface, flux-limiter Z, and detector wavelength frames. The worked bremsstrahlung example in the plan rejects the invented time derivative. Ordered sample positions do not enter identity, so `x1_width` and `first_point/z` retain aperture width and line-of-sight coordinate identities without ordinal wording.

- The 55 `atomic_mass` / `neutral_species_atomic_mass` rows split by explicit DD ownership: paths containing `/neutral/` retain the neutral-species identity; ion paths and paths without explicit neutral ownership retain generic atomic mass rather than inferring neutrality.
- `dd:summary/gas_injection_prefill/beryllium/value` retains `prefill_count`, while the lithium sibling retains `accumulated_lithium_prefill_count_due_to_gas_injection`; the catalog edit had incorrectly projected the lithium identity onto beryllium.
